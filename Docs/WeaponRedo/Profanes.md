# 亵渎系列 (Profanes) 武器重做设计文档

> 管辖文件：`Items/Weapons/Profanes/*.cs`（7 件）+ 新建 `Effects/ProfaneFleshPulse.fx`、`Effects/ProfaneGazeEye.fx`。
> 职业跨度：近战 ×2（肢解刃 / 肉旋）、远程 ×3（搐筋弓 / 脏器枪 / 肉瘤）、魔法 ×2（肉典 / 眼球杖）。

## 1. 现状诊断（八透镜逐件）

| 武器 | 主要问题 |
|---|---|
| ProfaneDismemberer 亵渎肢解刃 | 唯一有三段挥砍骨架的件，但 Execute 用 SmoothStep（波浪感，无"斩击"爆点）；挥砍拖尾是 GlaciateWave 原地盖章（糊）；**PreDraw 每帧 `ModContent.Request` 贴图**（违反性能护栏）；刀身命中无复合反馈（只撒 Dust）；无大招时刻 |
| GluttonousFleshrang 贪噬肉旋 | 吸血回旋镖骨架好，但全程匀速无重量感；命中反馈尚可；无主动决策点；"贪噬"只体现在数字吸血，没有"吃胖"的身体恐怖演出 |
| TwitchingTendonBow 搐筋弓 | 名为"筋腱"却是匀速平射连发弓——张力幻想完全缺席；每发固定副产物（2 飞刃）无决策；每 3 发眼球弹的节奏不可感知 |
| VisceraSpitter 脏器喷吐枪 | 五连发 SMG 手感成立，但 25 发一颗脏器弹毫无预告（玩家感知不到蓄压节奏）；射击无后坐 |
| BurstingTumorBomb 爆裂肉瘤 | **飞行弹幕 hitbox 124×124 远大于视觉**（公平性红线）；无烹煮/蓄力决策；`TumorBlastVFX.PreDraw` 每帧 ImmediateLoad Request 贴图（性能护栏）|
| GazingFleshGrimoire 凝视肉典 | 每次施法 10 颗弹 ×（拖尾 + 双次开合批）= 每帧大量批重启；巨眼弹只是换皮 EyeLaser 贴图，"凝视"没有演出载体 |
| AberrantEyeStaff 畸变眼球杖 | channel 引导只是自动连发，无 ramp-up / 心跳积蓄感；触手弹幕可读性可以但系列配色不统一 |

**系列级共性问题**：
1. 配色语言不统一——七件武器各自取色（外层 (74,5,26)/(86,16,8)/(92,4,30)/(96,8,14)/(102,10,12)/(68,3,9) 混用）。
2. 没有贯穿系列的"血肉脉动"节律；部分弹幕有各自的 sin 脉冲，频率相位随机。
3. 除 Ichor 外没有系列专属机制身份；7 件武器互不对话。
4. 无旗舰着色器、无处决/大招时刻。
5. 获取途径：七件均无配方/掉落登记（独立物品），进度位（Purple 稀有度、伤害段）保持不变即可。

判定：**全系列全面重做机制与视觉**（保留各件的基本骨架与职业定位）。

## 2. 系列主题与幻想感

**"凝视 → 剖检 → 摘取"**。亵渎线武器是活的：它们心跳、蠕动、凝视、进食。给玩家的体验是"操纵一件不该存在的活体器械"——恐怖感来自**形状语言与节律**（心跳缩放、肌腱抽搐、瞳孔追踪、爆裂前的收缩静默），而非满屏红雾。

三条系列贯穿线：
1. **心跳节律**：全系列共享 72 BPM"咚-咚—"双搏波形（`ProfaneCommon.Heartbeat`）。弹幕呼吸式缩放、辉光明暗、蓄力音效层都锁到这条波上；蓄力时心率随进度加快（音高上行）。
2. **剖检印（系列机制）**：各武器的"重击"给敌人叠加剖检印（上限 5 层，头顶缝合眼标记）。叠满第 5 层的瞬间自动触发**摘取**——头顶睁开一只金瞳巨眼（凝视）、猛然闭合（收缩静默）、随后血肉爆纹（处决 AOE，伤害=触发武器面板 ×2，治疗 20HP，LethalRed 定调 + 短暂染屏）。这是每件武器都能到达的"演出峰值"，近战叠层最快。
3. **统一配色**：外暗 FleshDark(92,8,24) / 中间 FleshMid(170,24,34) / 内亮 BloodBright(248,64,96) / 肌腱苍白 SinewPale(235,190,170) / 凝视金瞳 EyeGold(250,208,130)（金色只给"眼"语言，与血红分工保证可读）；处决用 ACMWeaponBurst.LethalRed。

## 3. 逐件机制设计

### 3.1 ProfaneDismemberer 亵渎肢解刃（近战旗舰）
- 三连击保留（横斩→上挑→下劈），挥砍波形按 MOTION.md 重修：
  - Prepare 22%：pow(6) 迟滞后拉（几乎不动→最后几帧猛然吸回，反向运动）；
  - Execute 48%：**poly(14) ease-out** 斩击（几乎全部角位移在前几帧），刀波在 Execute 12% 处随斩击帧释放；
  - Unwind 30%：过冲 +0.06 rad 后五次方回摆。
- 挥砍轨迹改为**刀尖历史点 ribbon 拖尾**（WeaponVFX.DrawRibbonTrail），废弃盖章式残影。
- 刀身命中反馈栈：ACMWeaponBurst(Profane 0.8) + 震屏 1.8 + 分层湿裂音（音高随连击序号上行）+ 玩家 1.5px 后坐；叠 1 层剖检印。
- 下劈：伤害 +30%（保留）、刀波 ×1.5、震屏 8、**叠 2 层印**——近战的处决发动机。
- 刀波用 `ProfaneFleshPulse`（方向模式）绘制：肌纤维沿行进方向蠕动 + 心跳收缩。
- 修复：贴图静态缓存；连击 40 帧未续则重置为横斩。

### 3.2 GazingFleshGrimoire 凝视肉典（魔法副旗舰）
- 左键扇形 10→7 颗血弹（单发伤害 ×10/7，总量不变；批次成本 -30%），施法 2px 后坐 + 湿裂音。
- 每 4 次施法：凝视巨眼——`ProfaneGazeEye` 着色器程序化巨眼（飞行中眼睑展开、瞳孔追踪最近敌人、接近后 uLock 收缩锁定、爆裂前闭眼静默），爆裂 8 触手；**直击 +2 印**。

### 3.3 AberrantEyeStaff 畸变眼球杖（引导法杖）
- 引导 ramp-up：持续引导 90 帧内触手 2→3 道、散布收窄 35%、弹速 +30%；心跳音随 ramp 加速（45f→28f 间隔，音高上行）——蓄力的"活体苏醒"感。
- 每 6 次：畸变眼球（GazeEye 着色器小尺寸渲染），**直击 +2 印**；爆裂环形血弹保留。

### 3.4 GluttonousFleshrang 贪噬肉旋（近战回旋镖）
- 命中 +1 印；返程 ×1.8 保留。
- **饱食机制**：单次飞行命中 ≥3 次后接住 → 获得"饱食"buff 6 秒（治疗 15、打嗝湿裂音、镖体膨胀 ×1.28、伤害 ×1.2、吸血上限 25→35）——"吃胖"的身体恐怖演出即数值反馈。
- 掷出瞬间玩家 1px 后坐 + 出手闪光（launch is a set）。

### 3.5 BurstingTumorBomb 爆裂肉瘤（投掷炸弹）
- **孕育（烹煮）机制**：按住攻击 → 手上肉瘤膨胀（55 帧到满，scale 1.0→1.55，心跳间隔 40f→14f 加速、音高上行、静脉辉光），松手掷出；满蓄自动掷出。蓄力加成：伤害 ×(1+0.55×蓄力)、碎片 6→10、爆炸半径 ×(1+0.35×蓄力)、初速 ×(1+0.3×蓄力)。
- 修复公平性：飞行 hitbox 124→30（视觉对齐），AOE 判定只属于爆炸弹幕（半径与冲击环视觉同步，上限 210px）。
- 爆炸直击 +2 印；爆炸加 FleshPulse 径向血肉膜。
- 修复：TumorBlastVFX 贴图静态缓存；着弹反弹时挤压变形（squash 1.2/0.8）。

### 3.6 TwitchingTendonBow 搐筋弓（蓄力弓）
- **改造为手持蓄力弓**（原生 held proj，channel）：握弓 8f（肌腱爬行音）→ 拉弦 8~45f（箭矢后拉 14px、弦用 DrawBeam 双段绘制、60%/85% 两次心跳）→ **满弦"痉挛"**（弓体抽搐 ±2px 6 帧 + 筋腱绷断声 + 金瞳一闪）。
- 松手释放：<30% 弱射（0.45×，惩罚乱点）；30~99% 标准脊椎箭（1.0×）；**100% 痉挛箭**：脊椎箭 3.6×、穿透 5、+2 螺旋飞刃（0.6×）、命中肋骨爆裂（4 枚侧向骨刺）、+1 印；每第 3 次满弦射出畸变眼球箭（3.5×，GazeEye 渲染，直击 +2 印）。
- 弹药在释放时消耗一支。

### 3.7 VisceraSpitter 脏器喷吐枪（爆裂枪）
- 五连发 SMG 保留（useTime 3 / anim 15）。**蓄压可读化**：25 发循环的最后 5 发心跳加速 + 枪口辉光增长 + 音高逐发上行 → 第 25 发喷出脏器弹（玩家 3px 后坐、震屏 5、双层湿裂音）。
- 脏器弹呼吸缩放锁心跳波形；**直击 +2 印**；爆炸加 FleshPulse 血肉膜。

## 4. 系列内梯度

- 朴素层（共享原语即可）：VisceraSpitter、AberrantEyeStaff、GluttonousFleshrang——统一拖尾/柔光/冲击环 + 心跳节律 + 印记参与。
- 中间层：BurstingTumorBomb、TwitchingTendonBow——烹煮/拉弦蓄力演出 + 借用 FleshPulse/GazeEye 单点使用。
- 旗舰层：**ProfaneDismemberer**（FleshPulse 刀波 + 处决摘取的主要触发者）与 **GazingFleshGrimoire**（GazeEye 巨眼的完整"凝视三段律"）。摘取处决（全屏染屏走名额契约、仅 10 帧）是系列共享的大招时刻。

## 5. 视觉技术方案

- 复用：WeaponVFX（拖尾/柔光/冲击环/震屏）、ACMWeaponBurst（Profane 27 / LethalRed 15）、ACMShaders.DrawBeam（弓弦、触手连线）、ACMShaders.NoiseTexture、ACMAsset 遮罩。
- 新建系列专属着色器（均 ps_3_0，以 `WeaponVFX.GetEffect` 按名获取，不注册进 ACMShaders）：
  1. `ProfaneFleshPulse.fx`——血肉蠕动膜/波：噪声域扭曲肌纤维 + 蔓状血管 + 苍白膜边 + uPulse 心跳收缩；uMode 0=方向波（刀波）、1=径向膜（爆炸/摘取/烹煮）。
  2. `ProfaneGazeEye.fx`——凝视之眼：噪声撕裂状眼睑 + 布满血丝的巩膜 + 金瞳虹膜纤维 + uLock 竖瞳收缩/红环/震颤 + uGazeDir 视线追踪。
- 摘取处决序列（ProfaneHarvestBurst，26 帧）：0-6f 金瞳睁开（凝视）→ 7-10f 猛然闭合、粒子切断（收缩静默）→ 11f 起爆（血肉膜 + LethalRed burst + 震屏 9 + 染屏 0.12 强度 ≤10 帧，走全屏名额）。

## 6. 平衡与定位

- 获取途径、稀有度（Purple）、职业定位全部不变；各件面板伤害/攻速不变（肉典单发调整但总面板不变）。
- 新增输出来源与论证（目标 ±15% 内）：
  - 剖检印摘取：伤害 = 触发武器面板 ×2.0 的 190px AOE。以最快的肢解刃计：5 层 ≈ 4 次挥砍（下劈 ×2），每循环 +2800 摊到 4 swing ≈ +12% 有效 DPS（换取近身风险与目标专注）；远程线特殊弹命中才叠印，触发频率约为近战一半（+5~8%）。治疗 20HP/次为生存价值。
  - 搐筋弓改蓄力：旧理论 DPS ≈ (主箭+双刃+眼球摊销)/16f ≈ 187/f；新满弦循环 ≈ 45f 产出 3.6×+双刃+肋爆 ≈ 6800 ≈ 151/f 纯单体（-19% 理论），但穿透 3→5、满弦命中率远高于散射双刃的实战命中，加上印记收益，实战期望在 -10%~0% 区间；速射惩罚（0.45×）是防无脑连点的设计税。
  - 爆裂肉瘤烹煮：满蓄 55f+32f 换 ×1.55 伤害 +4 碎片 ≈ 与连掷持平（+0~8% 满蓄期望），决策点为"安全窗口烹煮 vs 立刻压制"。
  - 饱食（肉旋）：×1.2 伤害 6 秒，需单程 3 命中（多目标/大体型才稳定触发），期望 +8% 内。
- Ichor 保留为系列通用 debuff，不改变外部平衡关系。

## 7. 性能与多人预算

- 修复两处每帧 `ModContent.Request`（肢解刃 PreDraw、肉瘤爆炸 VFX）。
- 肉典弹幕 10→7 直接降低最重的批重启热点；小血弹保留双层拖尾但 subdivisions 3。
- 心跳为纯数学函数（无分配）；印记数据为 GlobalNPC 实例字段（int×2），零层数时绘制直接跳过。
- FleshPulse/GazeEye 每次绘制一次开合批，仅特殊弹幕（巨眼/刀波/爆炸/处决）使用，同屏个位数。
- 染屏仅摘取处决 10 帧、强度 0.12，走 `RequestFullscreenSlot` 名额契约。
- 多人：印记只在 owner 客户端累计并由 owner 生成同步的摘取弹幕（与仓库既有 `_castCount` 模式一致）；治疗/震屏/音效均 owner/本地路径；弹幕伤害类型经 ai[1] 在各端一致解析。
