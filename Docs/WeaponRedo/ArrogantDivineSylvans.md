# 傲世神木系列重做设计文档 (ArrogantDivineSylvans)

> 大峥(大椿·万木之祖)关联的高阶自然线，7 件武器 + 1 个系列染屏件。
> 配色语言：**金边翠芯**(金=大椿之冠的神威天光，翠=大椿之心的生命年轮)。
> 主题常量：`ACMWeaponBurst.ArrogantSylvan`(26) / `DivineWood`(25)。

## 1. 现状诊断(逐件要点)

以共享简报 §3.1 八条透镜逐件诊断。系列整体已有一轮"半重做"痕迹(已接入
WeaponVFX ribbon / ACMWeaponBurst / ScreenTint 染屏契约 / ArenaRunic 地纹 / DrawBeam)，
**视觉底子尚可，但机制身份与手感层面问题系统性存在**：

| 件 | 主要问题 |
|---|---|
| 世界种 Bomb | 匀速 Swing 抛出即忘，无任何决策点；分裂→爆炸→16 蛇全是数量堆叠，一次投掷可产生 100+ 弹幕；每爆 50 dust；震屏 10+10 双入口叠调超预算 |
| 穿林弓 Bow | "DNA 双螺旋"实为敷衍的横向抖动；世界树之矢只是加粗 LightShot 无三段感；矢命中 50% 再爆 6 螺旋叶(污染)；无限穿透+40% 减速数值强但零表现 |
| 落叶风暴 Chakram | 系列机制最佳(投掷→风暴→内爆→回收 + channel 决策)，**但风暴伤害判定是整个 290px 圆盘，视觉只有一枚旋镖——判定与视觉严重不对齐**；每 3 命中触发裁决在 6f 免疫下失控(3+ 次/秒 ×16 花瓣)；掷出无前摇 |
| 斩天巨刃 Greatblade | 已是手持弹幕三段挥砍，但 Prepare 仅 3.2 帧(18f×0.18)形同虚设；Execute 用 SmoothStep——是"波浪"不是"斩击"(MOTION.md：strike 需 poly(8+) ease-out)；无回拉反向运动；残影常亮不 gate；输出全在派生弹幕上刀身存在感低 |
| 连天铳 Musket | **「万棘狂涌」是死机制**：`IncrementFury()` 从未被任何代码调用，tooltip 承诺的 50 命中大招不存在；文案"五连发"实为 7 连发(2/14)；火器零后坐力零枪口反馈 |
| 万藤杖 Staff | "藤蔓链鞭"用原版铁链贴图(Chains[13])出戏；`Item.channel=true` 但 channel 无任何作用；新星在"速度<2"时触发时机不可读；每 16 帧固定生成 4 触手(污染) |
| 山海典 Tome | 每次使用 20~28 片叶=弹幕机关枪(72 叶/秒 + 50% 双花瓣)，可读性与性能都失控；每叶命中都 spawn 一个 Burst 演出弹幕(同帧 20 个)；"每 3 次使用"漩涡≈1 秒一次——全程峰值=没有峰值；漩涡死亡再喷 12 叶 |
| ScreenTint | 已走 ApplyPaletteTint(内部含名额契约 + MythologyConfig 开关)，**合规**，仅需参数化增强 |

共性问题(八透镜横切)：
1. **机制身份**：全系列 Poisoned+Venom 复制粘贴，没有系列专属机制。
2. **命中反馈栈**：有 Burst 但震屏几乎处处 `ShakeScreen(10~12)` + `AddScreenShake(8~10)` 双入口叠调，幅度超"爆炸 4-6 / 大招 8-12"预算。
3. **轨迹语言**：金翠双色 ribbon 已现雏形，但十几种 hard-code 颜色散落各文件，无集中常量。
4. **演出峰值**：大招触发频率过高(Tome 1 秒/次)或不存在(Musket 死机制)，没有"节奏高点"。
5. **性能卫生**：7 种同质"追踪小弹"类，每个每帧全 NPC 最近敌扫描(百弹幕×200NPC=每帧 2 万次距离计算)；爆炸类 30~50 dust 一次性喷射。
6. **音效**：单层 SoundID、pitch 固定，无分层无随机。
7. **着色器**：全系列 0 个专属 ps_3_0(高阶线允许旗舰+次旗舰各一)。

结论：**全面重做手感/反馈/节奏/性能，保留各件已验证的机制骨架**(Chakram 四相、Greatblade 三连斩、Bow 每四发、Musket 连锁弹射、Staff 链鞭、Tome 扇形叶、Bomb 分裂种)。

## 2. 系列主题与幻想感

神话原型：《庄子·逍遥游》"上古有大椿者，以八千岁为春，八千岁为秋"。傲世神木是大椿体内
亿万年灵韵凝成的精华——玩家挥舞的不是木头，是**一段被压缩的万年生长史**。

给玩家的体验：**每一次攻击都是一次"播种→浇灌→绽放"**。命中敌人是在其体表刻下**年轮烙印**
(浇灌)；系列的每件武器都有一个明确的"引爆动作"让烙印**绽放**(金翠年轮环自敌人体表炸开)。
玩家在"持续浇灌"与"择机引爆"之间做主动决策——这就是系列的机制身份。

配色纪律(全系列统一，集中为常量)：
- 金(神威)：暗金 `(200,150,40)` / 亮金 `(255,235,150)` —— 永远在**外沿/边缘**；
- 翠(生命)：深翠 `(30,130,60)` / 亮翠 `(185,255,150)` —— 永远在**内芯/核心**；
- 拖尾一律 `WeaponVFX.DrawRibbonTrail(外宽暗金, 内窄亮翠)` = "金边翠芯"。

## 3. 系列共享机制：年轮烙印(写入 ArrogantSylvanScreenTint.cs)

- `ArrogantSylvanPalette`(静态常量类)：上述金翠四色 + 拖尾双色 + 白热芯。
- `ArrogantSylvanBrandNPC : GlobalNPC`(InstancePerEntity)：`Stacks`(0~5) + 衰减计时(8s)。
  命中叠层；PostDraw 在敌人脚下画小年轮弧(层数越多环越亮，5 层白热提示"可引爆")。
- `ArrogantSylvanBloom.Detonate(...)`：owner 端读层数 → 生成 `ArrogantSylvanBloomBurst`
  一次性绽放弹幕(伤害=引爆基准×0.32×层数，半径 90+34×层数)→ 清零层数。
  ≥5 层绽放追加金翠染屏定调(ScreenTint)+ 震屏 6。伤害经弹幕网络同步，多人安全
  (层数为各端本地视觉/判定缓存，伤害权威由 owner 端生成的同步弹幕承载)。
- `ArrogantSylvanTargeting`：共享节流索敌。目标索引缓存在弹幕字段，每 6 帧重扫一次，
  目标死亡立即重扫——替换 7 处每帧全 NPC 扫描。
- `ArrogantSylvanScreenTint` 参数化：`ai[0]`=强度档(0=技 0.10 / 1=旗舰绽放 0.135)。

各件引爆动作(演出峰值统一挂在"绽放"上)：

| 件 | 叠层动作 | 引爆动作 |
|---|---|---|
| 巨刃 | 横斩/上挑命中 +1 | **天崩下劈**命中引爆 |
| 旋镖 | 风暴/回程命中 +1 | **内爆坍缩**波及引爆 |
| 火铳 | 荆棘针命中 +1 | **种子迫击炮**爆炸波及引爆；≥3 层绽放时枪自动回赠 8 枚追踪荆棘(修复"万棘狂涌") |
| 长弓 | 主箭/螺旋叶命中 +1 | **世界树之矢**命中引爆 |
| 世界种 | 藤蛇/子种命中 +1 | **蓄满母树种**主爆引爆 |
| 万藤杖 | 鞭身/鞭头命中 +1 | **鞭至最远点"咬合"新星**引爆 |
| 山海典 | 叶刃命中 +1 | **叶暴漩涡**每 30 帧脉冲引爆范围内烙印 |

## 4. 逐件机制设计

### 4.1 斩天巨刃(旗舰·近战) —— 三连斩重锻
- 保留 横斩→上挑→天崩下劈 循环与派生弹幕，全部重写挥砍波形(96 帧循环解剖学)：
  useTime 18→26(巨刃应有的重量)，Prepare 30%(8f，**回拉 -18% 行程**，quad in-out，刀尖收敛金尘)
  → Execute 30%(8f，**poly(12) ease-out**——几乎全部角行程在前 2-3 帧完成，斩击帧播放
  低频 Item71+高频 Item1 双层音，pitch ±0.15) → Unwind 40%(10f，过冲 5% 后 quint 回正)。
- 残影/弧光 ribbon 仅在 Execute 亮(速度门控)；命中窗口=CanDamage 仅 Execute(已对齐)。
- 天崩下劈落点：地裂(ArenaRunic 保留)+ **GrowthRing 年轮环着色器** + 引爆烙印 + 震屏 8(单入口)。
- 决策点：前两斩快速叠层，第三斩慢而重——玩家可以用前两斩"浇灌"多个目标再用下劈收割。

### 4.2 落叶风暴(次旗舰·近战) —— 判定对齐 + 坍缩大招
- 四相骨架保留。**判定重做**：风暴期杀伤区=以 `_spiralRadius` 为中心的**环带(±75px)**+镖体，
  用 **Vortex 旋涡着色器**把环带画成清晰的金边翠芯藤叶风暴环——判定与视觉严格对齐。
- 前摇：掷出瞬间玩家手臂后拉由 useAnimation 前 6 帧承载(itemAnimation 门控)+掷出 recoil 音。
- 万木裁决改节奏阀：不再每 3 命中触发，改为**风暴每 45 帧环带脉冲一次**(8 叶沿切向甩出+烙印叠层)。
- 内爆坍缩=大招：坍缩收束(粒子向心 + Vortex 环带急速收缩)→ 1 帧静默 → GrowthRing 绽放
  + 波及引爆烙印 + 震屏 6；回收接住震屏 4。命中每次 +1 层。

### 4.3 连天铳(远程) —— 死机制复活 + 火器手感
- 文案与实弹统一为五连发：useTime 2 / useAnimation 10(5 发/轮，射速 30 发/s 与原 7/14 完全一致)。
- **每发后坐**：owner 端 `player.velocity -= dir*0.55`(仅空中明显)+枪口 GlowBurst+弹壳金尘。
- 「万棘狂涌」修复闭环：荆棘针命中叠烙印；**迫击炮爆炸波及引爆烙印**；由本枪引爆且层数
  ≥3 时，自动从玩家射出 8 枚追踪荆棘(重用 MusketSerpent)——tooltip 兑现，机制可见。
- 每 25 发三枚迫击炮保留(可读节奏)，炮落点用 GrowthRing 小环；藤蛇 10/6→6/4 枚(降污染)。

### 4.4 穿林弓(远程) —— 真·DNA 双螺旋 + 生长之箭
- 主箭(叶枪)保留 DrawBeam 金芯翠边；**螺旋叶刃重写**：4 片两两成对，围绕主箭飞行轴做
  真螺旋(相位差 π，半径 26px 余弦投影)，30 帧后解旋追踪——从任何角度看都是双螺旋。
- 每 4 发世界树之矢=三段感载体：spawn 后 **18 帧聚能凝形**(速度×0.12，藤纹 ribbon 自箭尾
  生长、汇聚金尘)→ 1 帧静默 → **poly(8) 爆发**至 1.5×原速(震屏 3+双层音)→ 命中/终点
  GrowthRing 绽放 + 引爆烙印。矢不再 50% 喷螺旋叶(删除污染源)。
- 主箭命中减速 40% 保留但补表现：目标脚下 6 帧翠色根须 dust 缠绕。

### 4.5 世界种(远程投掷) —— 蓄力播种
- 改 channel 蓄力：**快甩**(不蓄，节奏≈原版)或**持球蓄力 60 帧**打出"母树种"(×1.5 伤害、
  爆炸半径 +40%、子种全带小绽放环、主爆引爆烙印)。新增手持弹幕 `ArrogantSylvanSeedHold`：
  蓄力时种子在掌心生长(scale 1→1.5、翠→金渐变、噪声抖动 charge²)，蓄满白闪+音效提示，
  松手抛出(蓄满时震屏 3)。
- 主爆/子爆重做：GrowthRing 年轮环 + 荆棘领域(DissolveBurn 生长保留)；藤蛇 16→8 枚、
  子种蛇 8→4 枚、dust 50→24(粒子∝动能，但设上限)。
- 决策点：快甩铺场叠层 vs 蓄力单点收割。

### 4.6 万藤杖(法术) —— 真·藤鞭
- channel 生效：按住时鞭头以 0.10 lerp 持续追鼠标方向(驱鞭)，鞭头行至最大链长(560px)或
  松手 → **咬合**：鞭头 elastic 张开 10 帧(overshoot 1.3×)→ 猛咬 snap → GrowthRing 新星
  + 引爆烙印 + 震屏 5 → 回收。触发时机=鞭到最远点，完全可读。
- 链身重做：铁链贴图 → `BuildRibbonStrip` 金边翠芯 ribbon 链身，叠加**行波**(命中/咬合时
  自鞭头注入一个脉冲沿链传回，弹簧衰减 ×0.88/f —— MOTION.md §4 whip chain)。
- 触手节流：仅 channel 维持期每 24 帧最多 2 根(重用 Tendril，走共享索敌)。
- 鞭身本体具伤害(链线段判定)，命中 +1 层。

### 4.7 山海典(法术) —— 数量→质量
- 每次使用 20~28 片 → **7 片大叶刃**(扇形 ±40°)，每叶带金边翠芯 ribbon 拖尾 + 更大贴图缩放，
  螺旋→追踪骨架保留(走共享索敌)；命中 +1 层；命中 Burst 按 3 帧节流(不再每叶一个)。
- 花瓣重定位：不再 50% 随机喷，改为**绽放的视觉伴生**——烙印绽放时环舞 3 花瓣(小伤害)。
- 叶暴漩涡=大招：每 **6** 次使用(≈2.4s)凝聚一次；用 **Vortex 着色器**(与旋镖共享)画旋涡；
  每 30 帧脉冲一次：拉扯 + 波及引爆烙印；消散不再喷 12 叶。生成时染屏定调保留。

## 5. 系列内梯度

- **低阶件**(火铳/山海典/世界种快甩)：只用共享原语(ribbon/GlowBurst/冲击环/Burst)。
- **中阶件**(长弓/万藤杖)：共享原语 + GrowthRing 着色器复用(矢绽放/鞭咬新星)。
- **旗舰双件**(巨刃=旗舰、旋镖=次旗舰)：各配专属着色器使用点(GrowthRing 下劈定标 /
  Vortex 风暴环带)+ 大招时刻(下劈满层绽放染屏 / 坍缩绽放)。
- 染屏(全屏名额)仅 4 个触发点：≥5 层绽放、世界树之矢发射、每 25 发炮击、漩涡生成——
  同帧 ≤1 由名额契约自动仲裁。

## 6. 视觉技术方案

复用共享件：`WeaponVFX.DrawRibbonTrail/DrawProjectileTrail/DrawGlowBurst/DrawShockwaveRing/
ApplyDissolveBurn/AddScreenShake`、`ACMShaders.DrawBeam/ArenaRunic/WorldDecalParams/
DrawScreenSpaceDecalStandalone`、`ACMWeaponBurst(ArrogantSylvan=26)`、`ACMAsset` 遮罩。

新建系列专属 ps_3_0 着色器(仅 2 个，多点复用，不给小件堆 shader)：
1. **ArrogantSylvanGrowthRing.fx** —— 年轮绽放环(屏幕空间 decal，不占全屏名额)：
   同心年轮细环(sin 环纹) + 角向藤纹噪声扰动 + 生长前沿(uProgress 扩张，前沿白热) +
   金边翠芯径向配色。使用点：下劈地标、烙印绽放、母树种主爆、鞭咬新星、世界树之矢终点、迫击炮小环。
2. **ArrogantSylvanVortex.fx** —— 神木风暴环带(屏幕空间 decal)：极坐标旋转藤叶流
   (theta+r·twist-t·spin 采样噪声) + 环带 mask(内外沿 smoothstep) + 金边翠芯 + 脉冲参数。
   使用点：旋镖风暴环带(=伤害判定可视化)、山海典漩涡。
   两者按 `WeaponVFX.GetEffect("ArrogantSylvan...")` 按名取用，不注册进 ACMShaders。

## 7. 平衡与定位(获取途径/进度位/职业不变)

配方(傲世神木×15+前置神木件@秘银砧)、Purple 稀有度、售价全部不动。DPS 论证：

| 件 | 原 | 新 | 变化 |
|---|---|---|---|
| 巨刃 | 1700/18f = 94.4/f | 2300/26f = 88.5/f | -6%(名义)；烙印绽放补回，重击感↑ |
| 火铳 | 300×7 发/14f | 300×5 发/10f | 射速伤害完全相同(30 发/s×300) |
| 长弓 | 1400/14f | 1400/14f；矢 2.5× 每 4 发 | 0%；删矢的 50% 螺旋叶(约 -8% 名义)由烙印补回 |
| 世界种 | 1800/22f | 快甩 1800/22f；蓄满 2700/~68f | 快甩 0%；蓄力是选择项(单点聚焦付出节奏代价) |
| 旋镖 | 1500 圆盘判定 | 1500 环带判定 | 判定面积约 -45%(公平性修正)；环带脉冲叶+烙印补偿 |
| 万藤杖 | 1400 + 每16帧4触手 | 1400 + 鞭身伤害 + 每24帧2触手 | 触手 -50%；鞭身线段判定+咬合新星补回，波动≤10% |
| 山海典 | 1500×24 叶(单体受 8f 免疫墙) | 1700×7 叶(10f 免疫) | 单体实际 1500×7.5hit/s=11250 → 1700×6=10200 (-9%) |

烙印绽放(0.32×层数×引爆基准，8s 衰减)是系列新增伤害源，估计贡献 +8~12% 有效 DPS——
与上表各件名义 -6~-9% 对冲后系列整体 DPS 变化在 ±10% 内。

## 8. 性能与多人预算

- 索敌：全部小弹幕走 `ArrogantSylvanTargeting`(6 帧重扫+目标缓存)，每帧扫描量降 ~85%。
- 弹幕量：藤蛇 16→8、迫击蛇 10/6→6/4、Tome 24→7、矢螺旋叶(删)、触手 4/16f→2/24f、
  Burst 演出节流(3 帧内不重复)。dust 一次性喷射全部 ≤24 并带 `noGravity`。
- 着色器：2 个新 .fx 经 `WeaponVFX.GetEffect` 静态缓存；decal 绘制不读 screenTarget、
  不占全屏名额；染屏走 `ApplyPaletteTint`(名额契约+强度≤0.15+MythologyConfig 开关)。
