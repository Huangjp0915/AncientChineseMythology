# 亡魂EX系列（RevenantEXs）重做设计文档

> 地府线第三梯队（LunarCraftingStation + 尸体碎片/魂之残片/幽冥石），亡魂系列（Revenants）的觉醒升级版。
> 主题从基础版的"审判"升格为"弑神业障"。8 件：万魔录 / 引魂弓 / 无间业刃 / 勾魂枪 / 噬魂炮 / 碎魂雷 / 冥罗杖 / 屠神刀。

## 1. 现状诊断（八条透镜逐件）

系列共性：上一轮已接 `WeaponVFX` / `ACMWeaponBurst` / 共享着色器（命中反馈栈、拖尾、演出弹幕都在），**视觉底子及格**；但机制身份全部是基础版的"数量×N 换皮"（5 符文、5+3 箭、3 刃、10-16 霰弹、3 冥球、3 斩波），**没有任何主动决策点、没有大招节奏、没有"觉醒"的体感**。演出峰值全绑在"暴击时"（随机、不可预期、不可运营）。数值互相失衡严重（同梯队名义伤害 220 ~ 5650）。

1. **CodexofMyriadDemons 万魔录**：一眼身份×（就是快速泼 5 追踪弹）；三段感×（useTime 8 匀速）；反馈✓；轨迹✓；深度×；峰值=随机暴击链雷；每次施法 5 弹 + 23 尘性能偏挥霍。
2. **DamnedSoulguide 引魂弓**：每秒最多 48 支箭的粒子噪音，箭本身毫无重量；暴击链爆随机；"引魂"主题没有机制落点（引什么魂？）。
3. **InfinityKarmaBlade 无间业刃**：名叫"无间"（Avici，业报永续轮回）机制却是普通回旋镖×3；2560 名义伤害 + 无限穿透 + cd6 理论超模；缺"轮回"语言。
4. **OblivionSoulhook 勾魂枪**：唯一已有三段（Prepare/Thrust/Retract）手持突刺，底子最好；但突刺距离 60px 与"极大突刺范围"名不符实，前摇 2f 无重量，无连段变化。
5. **SoulEatingCannon 噬魂炮**：霰弹身份成立、后坐/炮口闪已有；但 10-16 发随机数量、`Item.staff[Type]=true` 挂错、无装填/资源循环、无大招。
6. **SoulShatteringUnderworldBomb 碎魂雷**：两段爆已有；但描述"开启黄泉之门"完全没有门，子雷是原地随机散开；投掷无手感差异。
7. **StaveofNetherEclipse 冥罗杖**：描述"罗网束缚区域持续造成伤害"，实际只有一次性 debuff + 纯视觉法阵——名不符实；三球均质无主次。
8. **YamasDeicide 屠神刀**：处决（<15% 非 Boss 斩杀）是全系列唯一真身份点✓；但原生 Swing 匀速挥舞毫无巨刃重量，暴击 AOE 与处决全是被动。

结论：**全系列机制重做 + 演出升格**（视觉复用已接好的共享原语，旗舰加 2 个专属 ps_3_0）。

## 2. 系列主题与幻想感

**"弑神业障"**：基础版是判官批红勾魂（执法者），EX 版是执刑者亲手挥落天罚——玩家不再是"审判的旁观者"，而是**业障的载体**：杀戮积攒业障，业障满溢则短暂"业劫觉醒"，武器显露真形。神话原型：阎摩罗阇（Yama）弑神断业、无间地狱（Avici）永劫轮回、黄泉之门、万魔归录。

**贯穿机制——业障溢出（系列共享）**：持系列任意武器命中敌人积累业障（0~100，存 `ModPlayer`），满溢自动触发 **业劫觉醒 8 秒**：全屏短促定调演出 + 玩家身周业焰轮，期间每件武器进入**各自不同的觉醒形态**；觉醒结束业障清零重新积累。战斗中约 12~18 秒一轮，形成系列统一的"呼吸-爆发"波形。

颜色语言：主体 AbyssPurple(11)（暗冥紫），业障/觉醒用 SoulFire(10)（青黄魂火）点缀，处决/大招 LethalRed(15)（致命红），黄泉门用 FengduVoid(13)（虚空黑紫）。

## 3. 逐件机制设计

通用：业障积累速率按武器节奏配平（详见 §6 表）；觉醒期武器拖尾掺入红紫、命中演出升档。

1. **万魔录**（魔法书）：左键改 **2 枚重万魔符**（追踪、命中反馈更重，替代 5 枚轻符）；**每第 5 次施法**书页翻涌 12f 前摇后放出**魔首大符**（2.2×，穿透+2，命中必触发万魔法阵链雷——把原"随机暴击链雷"改为可运营节奏）。觉醒：每次施法从身后斜两侧额外飞出 2 枚魔影符（0.5×，不耗蓝）。
2. **引魂弓**：改 **3 支引魂箭/发**（伤害集中）；箭命中同一目标叠**引魂印**（跟踪最近目标，`ModPlayer` 存层数），**6 印**时该目标头顶降下**黄泉引渡柱**（BeamGrad 魂柱贯穿，2200 名义伤 + 击飞），印清零——集火决策点。觉醒：每箭命中分裂 2 支小渡魂箭（0.4×，追踪）。
3. **无间业刃**（旗舰①）：改 **单把大业刃**投掷，命中后在敌间**无间弹射**（最多 8 次，每次弹射刃速重置 + 业焰拖尾变宽），弹尽飞回；**接刃**获 1 层业刃印（最多 3，头顶不显示、以手上刃光示意）；3 印时下一投为**无间劫刃**：刃钉在敌群中心自旋展开**业焰轮**（专属着色器 `RevenantEXKarmaWheel`，驻场 2.5s 高频 tick），随后炸回。觉醒：投掷变三刃齐出（血缘回归），每刃弹射 +2。
4. **勾魂枪**：保持手持三段，但重排波形——Prepare 拉长至 6f/攻速（pow3 late-snap 后拖 26px、尖端聚魂粒子收束），Thrust 用 poly(8) 急速击出且**突刺距离 60→130px**（兑现"极大突刺"），Retract 6f 弹性回收带过冲（130→-10→0）；**三连突刺连段**：第 3 刺变**勾魂大刺**（1.35×，距离 170px，勾魂治疗加倍）。击杀寂灭爆发保留。觉醒：全段提速 30% + 满伸展放出短程勾魂波（0.6×穿透波）。
5. **噬魂炮**：霰弹**固定 12 发**（去随机），开火后坐增强；命中/击杀吸魂充能**魂膛**（0~6 格，`ModPlayer`）；**右键**消耗全部魂膛发射**魂爆聚束炮**（单发大弹 = 880×(2+魂膛)，大爆 + 虚空扭曲）——攒魂换大炮的资源循环。摘掉错误的 `staff[Type]`。觉醒：散布收窄一半（聚焦化）+ 魂膛获取翻倍。
6. **碎魂雷**：主雷爆炸改为**撕开黄泉之门**（竖向门框：双 BeamGrad 门柱 + ArenaRunic 牢笼穹顶 + 门内 FengduVoid 吸入），3 枚子雷**从门中喷出**砸向前方扇形（原为原地随机散开）；门驻留 1.2s 期间对穿过的敌人挂魂火。觉醒：门喷子雷 +2 枚。
7. **冥罗杖**：改 **1 主球（2600）+ 2 侍球（730）**，主球命中展开**真实伤害罗网区**（260px 圆域实体弹幕，区内敌人减速 + 每 20t 一跳 650 名义 tick），罗网 3s 后**月蚀坍缩**（半径收拢 → 中心 0.8× 坍缩爆 + 冲击环）。觉醒：罗网半径 ×1.35、tick 间隔 20→14。
8. **屠神刀**（旗舰②）：改**手持巨刃弹幕**（原生 held proj），三连段挥舞曲线（anticipation 40% 平滑入出反向蓄力 / strike 16% poly(14) 急扫 + 扫掠采样防隧穿 / recovery 44% 轻回拖）：段1 竖劈、段2 反手回撩、段3 **大回环**（1.5×、宽刃气）；每段掷 1 道断业刃气（0.65×）。处决保留（<15% 非 Boss 斩杀 + DissolveBurn 崩解 + **专属着色器 `RevenantEXDeicideRift` 弑神裂隙**短促全屏撕裂）。觉醒首刀变**阎罗一刀**：30f 举刀过头蓄力（汇聚业焰、玩家缓行、尾段 22% 静默）→ 一帧斩落（本体 2×）→ 全屏横贯刃气（3×）+ DeicideRift 全屏裂隙 + 震屏 11（系列最高的大招时刻，走全屏名额契约）。

## 4. 系列内梯度

- 朴素件（共享原语即可）：噬魂炮、碎魂雷、冥罗杖、引魂弓——拖尾/冲击环/柔光/既有共享着色器（BeamGrad/ArenaRunic/GenericWarp）。
- 中阶：万魔录（第 5 发大符法阵）、勾魂枪（连段魂流）。
- 旗舰：**无间业刃**（专属业焰轮着色器 + 劫刃驻场大招）、**屠神刀**（专属弑神裂隙全屏着色器 + 阎罗一刀）。
- 系列级峰值：业障溢出瞬间的觉醒演出（全屏短促染屏 + 业焰轮，走名额契约，全系列共享一份代码）。

## 5. 视觉技术方案

复用：`WeaponVFX.DrawProjectileTrail/DrawRibbonTrail/DrawShockwaveRing/DrawGlowBurst/DrawRadialBloom/ApplyDissolveBurn/ApplyPaletteTint`、`ACMShaders.DrawBeam/ArenaRunic/GenericWarp/ElementalScreenTint`、`ACMWeaponBurst`（AbyssPurple/SoulFire/LethalRed/FengduVoid/GhostGreen/NetherGrudge）。

新建（均 ps_3_0，系列名前缀，用 `WeaponVFX.GetEffect` 按名取）：

1. `Effects/RevenantEXKarmaWheel.fx` —— 业焰轮（屏幕空间 decal，s0=共享噪声，不占全屏名额）：旋转辐条火轮 + 噪声火舌外缘 + 呼吸环。用于劫刃大招驻场、觉醒时玩家身周业焰环。
2. `Effects/RevenantEXDeicideRift.fx` —— 弑神裂隙（全屏后处理，s0=screenTarget，s1=噪声，**占全屏名额**）：沿任意方向线段撕裂屏幕（SDF 线距 + 法向撕扯位移 + 裂隙内红黑神血 + 裂缘辉光 + 色散）。用于屠神刀处决（0.4s）与阎罗一刀（0.7s）。

新弹幕全部 `Texture => "InnoVault/Assets/placeholder"` + 程序化绘制；不新增任何贴图；新弹幕名用 `Language.GetOrRegister` 代码内注册（不新增 hjson 弹幕键）。

## 7. 性能与多人预算

- 弹幕生成全部走 owner 客户端（`Shoot` / `OnHitNPC` owner 侧 + `Main.myPlayer == owner` 守卫）；业障/魂膛/连段/印记全部存 `ModPlayer`（owner 本地演算，产物弹幕自然同步）；震屏/染屏只在绘制路径。
- 全屏后处理仅 3 处且全走名额契约：觉醒溢出染屏（≤0.15、24f）、DeicideRift（处决 24f / 阎罗一刀 42f）、既有 OblivionVoidFinisher/SoulShatterBlastFX 保留。KarmaWheel 是 decal 不占名额。
- 粒子预算：万魔录/引魂弓弹幕数减半后 dust 同步减压；霰弹固定 12；所有新增每帧 dust ≤3/弹幕。着色器全部静态缓存（`WeaponVFX.GetEffect`）。拖尾受 `MythologyConfig.Trail` 降级（走共享方法天然生效）。
