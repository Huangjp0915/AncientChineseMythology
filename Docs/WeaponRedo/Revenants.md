# 亡魂系列 Revenants 重做设计文档（地府线第二梯队）

> 管辖文件：`Underworlds/Items/Weapons/Revenants/` 下 8 件武器 + 新建 `Effects/Revenant*.fx`。
> 定位：肉山后中期（精金/神圣锭阶段，Pink 稀有度），配方 冥狱锭×8 + 魂魄碎片×8 + 幽冥石×28 不变。
> 系列存在 EX 升级版（RevenantEXs，另一代理负责）；本文档只立基础版身份，标注机制钩子。

## 2. 系列主题与幻想感

**因果判决**。亡魂线的神话原型是地府司法体系：判官执笔记名（生死簿）、勾魂使者索命、孽镜台照罪、阎罗王朱笔勾决。玩家体验应当是"**每一击都在记账，账满之日就是宣判之时**"——攻击不再是均匀的伤害流，而是持续累积的**业力**与周期性到来的**判决爆点**。

系列贯穿机制：**业秤（Karma）**
- 任何亡魂武器命中敌人积累业力（普通 +1，重击 +2/+3），上限 **7 层**（七七审期之数）。
- 业满即时**宣判**：天降朱红判决印记（专属着色器），造成触发该击弹幕伤害 **×1.5** 的小范围结算重击；业力清零，目标 90 帧"既决"（不可再积累）。
- 业力在敌人身上以青黄魂火苗可视化（层数越高越密，第 6 层起混入朱红预警）。
- 八件武器以**不同方式消费/加速业力**（见 §3）：霰弹快速堆层、居合处决消费、镜刃蓄影返还……宣判是系列的统一"鼓点"，各武器决定敲鼓的节奏。

配色语言（消费 ACMWeaponBurst 常量）：
- 基调 **SoulFire(10)** 青黄魂火（灵魂/业力）与 **AbyssPurple(11)** 暗冥幽紫（冥府本体）；
- 勾魂/引渡用 **GhostGreen(12)**；
- 判决/处决一律 **LethalRed(15)** 朱红（判官朱笔——全系列只有"宣判瞬间"可以出现的颜色，稀缺性即可读性）。

## 3. 逐件机制设计

业秤共享框架写入 `CodexofFate.cs`（生死簿=业力账本，语义归位）：
- `RevenantKarmaGlobalNPC : GlobalNPC`（InstancePerEntity）：`karma` 层数 + 既决冷却，仅 owner 客户端读写（多人各自记账，互不干扰）；`DrawEffects` 按层数出魂火苗（≤1 dust/2 帧）。
- `RevenantKarma`（静态）：`AddKarma(npc, amount, srcProj)` 加层与满层宣判；宣判 = 生成 `KarmicVerdictStrike`（真伤害弹幕，AoE 130px，正常联机同步）+ `KarmicVerdictFX`（判决印记演出：RevenantJudgmentSigil 着色器 + 天降判决光柱 + LethalRed Burst + 震屏 4）。

### 3.1 生死冥罗录（魔法书，"记名"）
- 左键：2 发**命运符文**（追踪保留，转向更平滑）；每**第 4 次施法**翻页完成，追加 1 发**朱批**（LethalRed 快直线弹，伤害 ×1.6，命中 +2 业并必定触发链电演出 FateJudgmentField）。数施法次数 = 决策点（贴脸时留朱批打硬直）。
- 命中 +1 业。链电改为朱批专属（不再依赖暴击随机）。
- 节奏：18f/施法不变；朱批出现帧有翻页脆响 + 书本红光一闪。
- EX 钩子：朱批计数与链电形式可被 EX 扩展为"判词连页"。

### 3.2 判官勾魂枪（近战长枪，"勾魂"）
- **三连段突刺**：刺（行程 42px）→ 刺（52px）→ **勾**（行程 78px 弧形上挑回拉，命中 +2 业并把非 Boss 敌人向玩家勾拽 6px/f×8f）。连段计数存 ModItem 字段，Shoot 时经 ai[2] 传入（owner 侧安全）。
- 三段感：前摇回拉 -10px（quad in-out）→ 突刺 poly(8) ease-out → 收招 quintic 回位；第三段前摇多 4 帧、抖动 ±1.5px。
- 命中吸魂：固定 3 HP（替换原 6-14 随机）；若该击触发宣判，额外汲取 12 HP（勾魂 = 判决的生命结算形式），绿魂丝 BeamGrad 从敌飞向玩家 20 帧。
- 兑现"灵魂剥离"：被勾中（第三段）的目标获 ShadowFlame 且移速 -30%（Slow）。

### 3.3 孽镜回旋刃（近战回旋镖，副旗舰，"照罪"）
- 飞行命中时**蓄影**：把每次 damageDone 的 35% 记入镜中（上限 300）。镜影 ≥180 时下一次投掷变为**业镜断罪投**——主刃 + 2 道折影平行刃（折影为独立轻量弹幕，0.4× 伤害、不返回），主刃首个命中处一次性**返还全部镜影伤害**（LethalRed 结算 + mini 判决印，+3 业）。
- 决策点：普通投喂镜 → 断罪投收账；打 Boss 循环节奏约 3 普 1 断。
- 视觉：普通态银白镜面（RevenantKarmaRibbon 刃迹低热度），蓄满态刃体泛紫红、折影重像；断罪返还瞬间镜面碎裂演出（BlankStar 碎片 + 冲击环 + 判决印记 mini）。
- 暴击镜像反射（旧机制）删除，Ichor 减防保留。

### 3.4 冥府幽火铳（远程霰弹，"焚魂"）
- 固定 **5 发**扇形（±9° 均匀 + 微抖），弹速 +40%（extraUpdates 2 火舌感）；修复 `Item.staff` 残留。
- **后坐三段感**：开火瞬间玩家反冲 3.5px/f、枪口上抬，8 帧内恢复。
- **蓄压双管**：每第 4 次射击进入蓄压（枪身魂火脉动 12f 预兆），该发变为 **8 发宽扇 + 1.5× 后坐 + 震屏 3**——per-4 大招节奏。
- 命中 +1 业/弹（霰弹是全系列最快的堆层器 = 它的身份；单弹伤害相应最低）。
- 兑现"焚烧灵魂"：蓄压发命中的目标 ShadowFlame 时长翻倍。

### 3.5 冥岩爆魂雷（远程炸弹，"劫火"）
- **主动引爆**：场上已有己方雷时，再次使用武器不投新雷、而是立即引爆全部已有雷（owner 侧置 ai + netUpdate 同步）。决策点：贴脸炸 or 预埋炸。
- 爆炸兑现 tooltip：留下 **幽火场**（240f，每 20f 一跳 22% 弹幕伤害 + 每跳 +1 业，同屏 ≤2 片，新雷顶掉最旧）。
- **爆魂结算**：爆炸对业 ≥4 的目标伤害 +8%/层（爆炸即它的宣判形式，随后正常触发宣判）。
- 引信/爆炸演出保留（已达标），幽火场用地面火舌 BeamGrad 低幅摆动 + SoulFire dust。

### 3.6 黄泉幽冥杖（魔法杖，"渡川"）
- 能量球改**川流蛇行**（正弦摆动 + 长 ribbon，黄泉之川的语言）。
- 兑现 tooltip：命中或消亡时展开**幽冥漩涡**（300f；110px 半径；每 15f 一跳 30% 弹幕伤害；把非 Boss 敌人向心吸 0.6px/f；每跳 +1 业；**吸魂**：每跳治疗玩家 1 HP，同屏漩涡 ≤2）。
- 每帧 RadialBloom 申请全屏名额的浪费改为 DrawGlowBurst（名额留给宣判/处决）。
- 直击伤害 52→46（漩涡补齐，见 §6）。

### 3.7 黄泉引魂弓（远程弓，"引渡"）
- **引魂灯逻辑**：箭矢对业 ≥1 的目标启用强追踪（0.12 lerp / 500px），对未记名目标仅弱追踪（0.03）——"引魂弓引的是已被勾名的魂"。
- 每**第 4 箭**必出双箭（副箭 0.6×，替换原 1/3 随机，弓臂灯光渐亮预告）。
- **渡魂**：击杀业 ≥1 的敌人释放 2 枚渡魂魄（30% 伤害小追踪弹，命中 +1 业，同屏 ≤6）——击杀链循环。
- 命中 +1 业。

### 3.8 阎摩断业刀（近战大刀，主旗舰，"断业"）
改造为手持弹幕大刀（噬觉挥舞曲线全自定义）：
- **左键三连段**（连段计数存 ModItem 字段）：
  - 横斩 26f：前摇 10f（quad in-out 回拉 -0.9rad）→ 爆发 4f（poly(9) ease-out 扫 2.4rad）→ 收招 12f（quintic）；
  - 回斩 26f：反向同构；
  - **过顶大劈 34f**：前摇 14f（举刀过顶 + 刀身热度渐亮）→ 爆发 5f 劈落 → 释放宽幅**断业剑气**（0.7× 复用现类）+ 落点冲击环 + 震屏 3；命中 +2 业。
- **右键·勾决居合**（兑现 tooltip 的处决承诺）：48f 使用周期。前摇 16f 拔刀蓄势（刀身 uHeat→1、周身收束粒子、末 4 帧静默）→ **瞬身 11f**（向光标方向 24px/f 位移斩，路径全判定）→ 收刀 18f。路径上：
  - 业 ≥4 的敌人受**断业判决**：伤害 ×(1.8 + 0.12×层数)，业力全部清零（消费型宣判——不走共享宣判，是它专属的结算形式）；
  - 非 Boss 且生命 <15% 的记名（业≥1）敌人**直接处决**（公平化的"一击必杀"）；
  - 无业目标只受 1.1× 普通居合伤。
- **大招时刻**（处决斩中目标瞬间）：帧停感 pre-silence（粒子截断）→ RevenantJudgmentSigil 全尺寸判决印记 + 刀痕 RevenantKarmaRibbon 朱红残留 20f + ApplyPaletteTint 朱红染屏 0.12/约 25f（走全屏名额）+ 震屏 8。

## 4. 系列内梯度

- **朴素件**（共享原语即可）：幽火铳、引魂弓、爆魂雷、幽冥杖、冥罗录——拖尾/柔光/冲击环 + ACMWeaponBurst 主题色 + 共享判决印记。
- **豪华件**：勾魂枪（三连段勾拽 + 魂丝）、孽镜刃（折影投 + 镜影返还）。
- **旗舰**：断业刀——手持挥舞曲线 + 处决居合 + 染屏大招，独占两个专属着色器的最高档用法。
- 判决印记着色器全系列共享（每次宣判可见），保证低阶件也有"系列级"的峰值瞬间。

## 5. 视觉技术方案

复用：`WeaponVFX.DrawProjectileTrail/DrawGlowBurst/DrawShockwaveRing/DrawRadialBloom/AddScreenShake/ApplyPaletteTint`、`ACMShaders.DrawBeam/ArenaRunic/GenericWarp`、`ACMWeaponBurst`（SoulFire/AbyssPurple/GhostGreen/LethalRed）、`ACMAsset` 遮罩。

新建系列专属 ps_3_0 着色器（前缀 Revenant）：
1. **RevenantJudgmentSigil.fx**（屏幕空间贴花，经 `DrawScreenSpaceDecalStandalone` 调用）：阎罗判决印——方形官印外框 + 内圈勾决朱笔环 + 竖向判词刻痕 + 噪声业火溢边；`uStamp` 控制"盖印"动画（落印挤压 → 印痕定格 → 边缘业火散逸）。消费方：共享宣判 FX、断业刀处决、孽镜断罪返还（mini）。
2. **RevenantKarmaRibbon.fx**（TriangleStrip 条带，BuildRibbonStrip 顶点契约同 BeamGrad）：业镜/断业刃迹——镜面拉丝高光 + **折影重像**（uv 双像偏移叠加）+ `uHeat` 热度（青黄→朱红白热）+ 噪声业火斑驳。消费方：断业刀挥舞刃迹与居合刀痕、孽镜刃迹。

## 6. 平衡与定位

获取途径/配方/稀有度/职业定位全部不变。宣判为系列新增伤害源（每 7 次命中约 +1.5× 一击 ≈ 有效 DPS +18%），故基础数值小幅下调对冲，目标**含宣判总 DPS 较原版 +5%~12%**（原版三件机制未兑现、系列整体偏弱，属重做合理回升）：

| 武器 | 原伤害/节奏 | 新伤害/节奏 | 论证 |
|---|---|---|---|
| 冥罗录 | 58×2 发/18f | 52×2 发/18f + 每 4 施法朱批 83 | 基础 -10%，朱批 +7%，宣判 +18% → 净 +12% |
| 勾魂枪 | 72/22f，吸 6-14 | 66/连段(22f,22f,26f)，第三段 1.25×，吸固定 3 | 均段 ≈ 原 DPS -6%；吸血期望 10→约 4.5/击（防超模），宣判回条补偿 |
| 孽镜刃 | 62，暴击 1/3 反 1/3 | 58，蓄影 35%（阈值 180 / 上限 300）断罪返还 + 折影 0.4××2 | 旧反射期望 ≈ +3%；新返还约每 2 投 +260 ≈ +9%，需接刃运营 → 净 +8% 内 |
| 幽火铳 | 42×(3-5)/32f | 36×5/32f + 每 4 发蓄压 8 弹 | 原期望 4 弹 168/齐射 → 新 180 + 蓄压 25% → +13%（含堆层最快的系列职责） |
| 爆魂雷 | 78 爆炸 | 74 爆炸 + 幽火场 22%×12 跳 + 爆魂加成 | 主爆 -5%；幽火场挂满 ≈ +2.6 跳伤/雷；实战（非挂满）净 +10% 内 |
| 幽冥杖 | 52 单发 | 46 直击 + 漩涡 30%×20 跳(300f) | 单目标持续输出 +11%（漩涡不可叠>2 片限制上限） |
| 引魂弓 | 56，1/3 双箭(0.6×) | 56，每 4 箭双箭(0.6×) + 击杀渡魂 30%×2 | 双箭期望 +20%→+15%（确定化）；渡魂只对清群生效 → Boss 战净 +4% |
| 断业刀 | 86/26f + 0.7× 剑气 | 86 连段(1×,1×,1.15×+剑气) + 居合消费业力 | 左键均值 ≈ +5%；居合伤害以业力为燃料（自身命中攒 4 层需 ~3 秒），非白嫖 |

处决斩杀线（非 Boss <15% HP）与原版 tooltip 的"一击必杀"相比更公平且有条件（需记名）。

## 7. 性能与多人预算

- 业力计数：GlobalNPC per-entity 两个字段，owner 客户端本地读写（OnHitNPC 天然 owner 侧），**不做网络同步**——多人各自记账各自宣判，宣判伤害走正常弹幕同步。
- 宣判/结算弹幕均 `Main.myPlayer == owner` 生成；演出弹幕 damage=0。
- 粒子上限：业火苗 ≤1 dust/2 帧/敌；漩涡 ≤2 片、幽火场 ≤2 片、渡魂魄 ≤6；所有新弹幕拖尾走 MythologyConfig.Trail 降级（DrawRibbonTrail 内建）。
- 全屏后处理仅三处走名额：共享宣判 RadialBloom（burst 内部自会退化）、爆魂雷 GenericWarp（已有）、断业刀处决染屏；幽冥杖每帧 bloom 浪费改除。
- 着色器经 `WeaponVFX.GetEffect` 惰性缓存；无每帧 Request/RenderTarget/LINQ。
