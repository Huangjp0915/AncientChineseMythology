# 幽冥系列（Umbrals）武器重做设计文档

> 地府线第一梯队（肉山后入门，LightRed，SoulFragment + UmbralStoneItem 合成）。
> 定位：比主世界武器更具"冥府仪式感"，但比亡魂/亡魂EX/酆都三个后续梯队朴素克制。
> 负责代理：幽冥系列 worker。管辖文件见 §8。

## 1. 现状诊断（八条透镜逐件）

此前已有一轮轻补强（全员接入 ACMWeaponBurst 命中辉光 + WeaponVFX 拖尾），但普遍停留在"视觉贴膜"层：

| 武器 | 主要问题 |
|---|---|
| 刑天之斧 | 原生 Swing 匀速挥舞（透镜2✗）；机制全被动（低血增伤+破甲，透镜5✗）；无大招时刻（透镜6✗）。"无首战神"的神话身份只剩 tooltip。 |
| 血魔剑 | **数值离群**：155伤@12帧 ≈ 775 名义 DPS，是本梯队其余件（120-160）的 5-6 倍，还高于下一梯队全部武器；注释自称"大剑较慢"实为最快。匀速挥舞、无连段结构；吸血血丝视觉已达标。 |
| 判官笔 | 3 发随机散射追踪弹=换皮数值棒（透镜1✗）；"判官朱批定罪"的身份完全没立住；弹体视觉（朱批符印）已达标。 |
| 冥骨弓 | 1/3 随机额外箭是纯 RNG，无节奏无决策（透镜5/6✗）；箭体冥火拖尾已达标。 |
| 噬魂矛 | 已有三段手持突刺但用 SmoothStep（波形软，透镜2△）；回血是 1/4 随机触发（不可读不可预期）；**伤害偏高**（152@24，梯队第二离群）。 |
| 魂灯杖 | 已是真 minion（灯体程序化绘制达标）；但灯只会匀速点射，无演出峰值、无"引魂灯指引"的身份钩子（透镜1/6✗）。 |
| 索魂匕 | 双匕设定但投掷完全同质（透镜1✗）；1/3 随机双掷；处决机制+索魂链演出已达标保留。 |
| 阎罗锤 | 普通回旋镖弧线，"惊堂木裁决"身份缺失（透镜1✗）；命中符环演出已达标；无节奏高点。 |

**性能卫生**：现有实现均已用静态缓存/预算震屏/名额契约，无每帧 Request；本次重做延续。

## 2. 系列主题与幻想感

玩家刚击败血肉墙、踏入地府线的第一套法器。幻想感：**你不是拿到八件兵器，而是接过地府官僚体系的八件"职能法器"**——战神的斧、判官的笔、阎罗的槌、引魂的灯、索魂的匕、噬魂的矛、冥骨的弓、血魔的剑。每件都有一个 3 秒内可感知的**仪式钩子**（画押定罪 / 惊堂一拍 / 灯引魂火 / 喂魂大刺……）。

**统一视觉语言**：幽蓝（Shadow #6EB4EB 系）为系列底色承载"阴"，每件叠一个身份强调色：
- 刑天斧：怨红（LethalRed 10/15 号主题）——战神之怒
- 判官笔：朱砂红（自定义朱红，非致命红语义——朱批墨迹）
- 阎罗锤：审判金（Gold）
- 魂灯杖：青黄魂火（SoulFire 10 号）
- 冥骨弓：骨白+冥蓝（Bone 32 / NetherGrudge 14）
- 噬魂矛：冷蓝魂火（NetherGrudge 14）
- 索魂匕：幽紫（AbyssPurple 11）
- 血魔剑：暗血红（Profane/LethalRed）

克制原则（入门层）：普通攻击只用拖尾+柔光+小冲击环；大招时刻才允许径向泛光/法阵 decal；全屏染屏仅刑天斧大招 4 帧。

## 3. 逐件机制设计

### 3.1 刑天之斧（旗舰）——"无首怒斩"
- **改造为原生手持弹幕**（XingTianAxeSwing），自定义三段挥舞曲线（26f 周期）：
  - 前摇 12f：回拉 -0.95 rad，二次 in-out（可读蓄势）；
  - 爆发 5f：poly(14) ease-out 扫至 +1.95 rad（一瞬到位的"劈"）；
  - 收招 9f：五次方 in-out 回中，带 6px 后坐。
  - 只在爆发段+收招前2帧有伤害判定（判定与视觉严格对齐）。
- **怨气资源**：命中 +12（低血狂暴时 +18），上限 100；斧刃红焰粒子密度随怨气广播进度。
- **大招"无首怒斩"**：满怨气后下一挥自动变为怒斩——前摇加深至 16f、scale ×1.35、爆发 poly(20)；爆发帧释放**怨气冲击波**（XingTianWrathWave，前进的弧形撕裂波，0.9x 伤害 AoE），配 4 帧血色染屏（走全屏名额）+ 震屏 8。
- **刑天不屈**保留：<50% HP 伤害up（原被动），狂暴时挥速 +12%、命中演出放大。
- 决策点：残血站桩换爆发 vs 稳健输出；怨气攒满时机管理。

### 3.2 判官笔——"朱批定罪"
- 左键 3 发朱批笔画弹保留（散射角 15°→9°，中距更易全中）。
- **朱批标记**：命中施加「朱批」层数（GlobalNPC 计数 + 敌人头顶朱红批字视觉），满 **4 层**触发**定罪**：天降朱红判决竖笔（JudgmentVerdictStroke，自敌人头顶劈落的 BeamGrad 竖束 + 顿笔爆），造成 2.0x 伤害并清层。
- 决策点：集火同一目标快速定罪 vs 散射铺场。

### 3.3 阎罗锤——"惊堂一拍"
- 投出后**命中首个敌人或到达最远点**时进入 Slam 状态：悬停上抬 10f（前摇，旋转减速对齐）→ 垂直下砸 → **惊堂一拍**：金色审判冲击波 + ArenaRunic 金环（符环挪至砸点）+ 0.9x AoE 判决脉冲（YamasVerdictSlam，附带混乱）→ 回旋返回。
- "肃静！"节奏：拍案瞬间震屏 5 + 低音 Item14 + 高音 Item4 分层。

### 3.4 魂灯杖——"引魂大火"
- 幽灯 minion 保留；每喷 **6 发**魂火弹，第 6 发变为**引魂大火**（1.5 倍体积、更亮），命中爆裂为 3 枚 30% 伤害的小魂火寻敌分裂弹。
- 灯体开火加 3px 反冲（质量感），大火前 20f 灯芯亮度渐升（充能可读）。

### 3.5 噬魂矛——"喂魂大刺"
- 三段突刺曲线锐化：前摇 8f 后拉 -14px（pow4 late-snap"吸气"）→ 爆发 5f poly(8) → 收招 8f 五次方。
- **魂灵资源**：命中 +1 魂（上限 4），魂灵 wisp 环绕枪杆可见；满 4 魂下一刺自动变为**吞魂突刺**：突刺距离 ×1.9、1.6x 伤害、命中吞魂回 12 HP + 冷蓝爆发环。随机回血改为确定性资源循环。

### 3.6 冥骨弓——"引魂齐射"
- 移除 1/3 随机额外箭；改为**固定节奏**：每第 4 射为**引魂齐射**——3 支无重力、强追踪、发光的魂骨箭（NetherboneSoulArrow）扇形射出。
- 节奏可听化：第 1-3 发音高阶梯上行（骨磬），第 4 发低音齐鸣。

### 3.7 索魂匕——"左右开弓"
- 投掷**交替左右手**（出手位置左右偏移 ±10px、旋向相反）；每第 3 投为**双匕交叉**：两匕以 ±12° 出射并在飞行中向中线收束交叉（X 轨迹）。
- 处决机制保留（<15% 血非 Boss 1/5 索命 + 索魂链演出）。

### 3.8 血魔剑——"血怨三段"
- **数值重整 + 三段连击**：斩1 → 斩2 → **重斩**（scale +0.25、挥速 0.8x、1.4x 伤害、释放 0.8x 血浪弹 BloodfiendCrimsonWave 短程穿透）。
- 吸血保留（5%，暴击双倍），血丝回流视觉保留；血浪命中亦触发吸血线。

## 4. 系列内梯度

- **朴素层**（共享原语即可）：冥骨弓、索魂匕、魂灯杖——拖尾+柔光+Burst，无 decal。
- **中间层**：判官笔（定罪竖束 BeamGrad）、血魔剑（血浪 ribbon）、噬魂矛（喂魂 wisp+裂隙）、阎罗锤（ArenaRunic 金环复用）。
- **旗舰**：刑天斧——系列唯一专属着色器 + 唯一染屏大招。

## 5. 视觉技术方案

- **新建着色器（仅 1 个，ps_3_0）**：`Effects/UmbralGrudgeWave.fx`——屏幕空间弧形怨气撕裂波（角向噪声撕裂环 + 双色梯度：怨红芯/幽蓝外缘 + 行进方向弧形裁剪）。由 XingTianWrathWave 在 PreDraw 经 `DrawScreenSpaceDecalStandalone` 管线绘制（不读 screenTarget，不占全屏名额）；着色器经 `WeaponVFX.GetEffect("UmbralGrudgeWave")` 获取。
- 复用：`ACMShaders.DrawBeam`（定罪竖笔/矛身光束/索魂链/血丝）、`ArenaRunic`（惊堂金环）、`WeaponVFX.DrawRibbonTrail/DrawProjectileTrail/DrawGlowBurst/DrawShockwaveRing/DrawRadialBloom/ApplyDissolveBurn/ApplyPaletteTint`、`ACMWeaponBurst`（SoulFire/GhostGreen/Shadow/Bone/AbyssPurple/NetherGrudge/LethalRed/Gold 主题）。
- 染屏：仅刑天怒斩 4 帧（强度 0.13，占名额，DakkiBook 同款配方）。

## 6. 平衡与定位

获取途径、配方、稀有度、职业定位全部不变。名义 DPS 论证（60fps，全弹命中口径）：

| 武器 | 原 | 新 | 变化 | 论证 |
|---|---|---|---|---|
| 刑天斧 | 62@28=133 | 62@26=143 + 每~9挥一次 0.9x 波 | ≈+8~14% | 挥舞周期微快 + 大招 AoE，边界内 |
| 判官笔 | 48×3@22=393(全中) | 36×3@22 + 4层定罪2.0x | 全中+12% / 单中+12% | 基伤下调换定罪节奏，两端均 ±15% 内 |
| 阎罗锤 | 58@28 | 54@28 + 每投 0.9x 拍案 AoE | 单体≈+10% | 基伤 -7% 换 AoE 脉冲 |
| 魂灯杖 | 35/38f | 35/38f + 1/6 发分裂 3×30% | ≈+13% | 期望增益边界内 |
| 噬魂矛 | **152@24=380** | 128@24，5 刺均含 1 次 1.6x | ≈-6%（vs 原名义） | **梯队离群修复**：原伤高出本队均值 2.5 倍；回血从随机改确定 |
| 冥骨弓 | 42@22×1.33箭 | 42@22×(3+3)/4箭=1.5 | +12.5% | 随机改节奏，期望微升 |

## 7. 性能与多人预算

- 弹幕生成全部走 owner 判定（`Shoot` 钩子 / `Projectile.owner == Main.myPlayer` / `Main.myPlayer == owner`）；连击/怨气/魂灵计数存 ModItem 实例字段（仓库先例 AbyssalDragonblade），跨端行为经 `Projectile.ai[]` 传递（大刺/大挥/大火标记随弹幕 netsync）。
- 朱批层数存 GlobalNPC instanced int：`OnHitNPC` 在 owner client 与 server 一致推进，定罪弹幕仅 owner client 生成——层数逻辑各端自洽。
- 绘制均在 PreDraw/PostDraw；震屏走预算（普通命中 ≤2.5 / 拍案 5 / 怒斩 8）；wisp/粒子有上限；拖尾受 `MythologyConfig.Trail` 降级；同屏怨气波 ≤1（大招频率天然限制）。
- 新着色器静态缓存经 `WeaponVFX.GetEffect`，无每帧 Request。
