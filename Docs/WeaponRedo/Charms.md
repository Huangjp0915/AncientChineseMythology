## 1. 现状诊断 (八条透镜逐件)

九件里只有 2.5 件是"武器", 其余是占位性质的作弊级饰品 ("传说中的物品" 占位 tooltip):

### 1.1 鸡符咒 ChickenCharm (饰品, Red)
- 佩戴 = 无限飞行 + 直接改写 `velocity.Y` 的三态悬浮 + 免坠伤。**一眼身份**: 无 (纯功能挂件); 无任何视觉/机制/演出; 与"武器系列"定位完全脱节。作弊级数值 (无限 wingTime)。判定: **全面重做为主动武器**。

### 1.2 牛符咒 CowCharm (饰品, Red)
- 佩戴 = +40 防御 +80% 全伤害。纯数值棒, 明显是开发期作弊件; 挂 Buff 仅为图标。判定: **全面重做为主动武器**。

### 1.3 狗符咒 DogCharm (饰品, Red)
- 佩戴 = 每秒 +50 生命 +50 魔力回复。同上, 纯数值棒。判定: **全面重做为主动武器**。

### 1.4 龙符咒 DragonCharm (远程武器 300, Red)
- HoldUp 直射激光, 每次使用扣 30 HP (90 HP/s, 可以把玩家榨死), 命中/撞地生成爆炸——**爆炸半径 12 格砸方块+背景墙** (联机 griefing 级缺陷, 必删)。
- 有人近期补过表现层 (BeamGrad 光束 + Gold Burst + 起手血光), 但机制身份仍是"直线弹+爆炸"换皮; 无三段感、无大招时刻; `[Obsolete] UseItem` 直改 statLife 且能触发 KillMe。判定: **保留"血祭召龙"身份, 全面重做为系列旗舰**。

### 1.5 马符咒 HorseCharm (饰品, Red)
- 佩戴 = 清除全部 debuff + **免疫一切 debuff** (逐帧写满 buffImmune)。作弊级。判定: **全面重做为主动武器**。

### 1.6 猪符咒 PigCharm (魔法武器 168, Red)
- channel 引导激光: 从玩家中心射向鼠标, 逐帧砖块步进截断。底子最好的一件 (有状态机/魔力循环/近期表现层)。
- 缺陷: `penetrate=1` 且 OnHitNPC 直接 `Kill()` → **光束打中一个敌人就消失** (荒谬); 未设 `usesLocalNPCImmunity`; 三套 8 帧动画贴图已被表现层重做废弃但状态机还在为它跑; 无蓄力深度、无峰值。判定: **保留 channel 光束身份, 机制补全 + 重做**。

### 1.7 兔符咒 RabbitCharm (饰品, Red)
- 佩戴 = 最高跑速 15 + 松键立刻归零水平速度 (手感诡异)。判定: **全面重做为主动武器**。

### 1.8 蛇符咒 SnakeCharm (使用物, Red)
- 左键给自己挂 `int.MaxValue` 时长的隐身 Buff, 右键解除。纯功能开关, 无演出。判定: **全面重做为主动武器** (保留一丝"隐匿"血统作为右键伏击机制); 使用时顺手清除玩家身上遗留的永久隐身 Buff (存档迁移礼貌)。

### 1.9 鼠符咒 RatCharm (钥匙物品, Blue)
- 几乎无功能: UseItem 空转, `ConsumeItem` 在被选中时返回 true (一旦可用会把钥匙吃掉——隐患); 真正作用是**手持它右键圣主雕像触发事件** (`ShengZhuStatueTile.RightClick` 读 `HeldItem.type`)。判定: **重做为主动武器**, 钥匙职能不动 (雕像逻辑在外部按持有判定, 与左键攻击不冲突), 删除危险的 ConsumeItem。

### 共性诊断
- **系列一致性**: 零。九件之间除了名字没有任何视觉/机制语言; 六件复制粘贴同一段 PreDrawInWorld。
- **命中反馈栈 / 轨迹可读性 / 演出峰值**: 除龙/猪近期补的表现层外全部为零。
- **性能卫生**: 马符每帧全量遍历 buffImmune 数组; 龙符爆炸逐格 KillTile; 其余无热点。

## 2. 系列主题与幻想感

**道教符箓 + 十二生肖灵兽**: 每张符都是一张"黄纸朱砂符", 使用 = 道士掷符。统一视觉语言三拍:

1. **符纸展开** —— 黄纸从折叠中展开, 边缘微焦, 飞行时纸片翻飞、身后拖一条细朱砂走线;
2. **朱砂笔画走线** —— 飞行途中符面笔画自上而下"被写完" (符头三清三横 → 中脊 → 敕令纹), 写完即引爆条件成熟;
3. **印章起爆** —— 到达目标点, 一方朱印"啪"地盖下 (方形印玺 + 白闪 + 冲击环 + 轻震屏), 纸燃尽, 对应生肖灵兽自朱砂笔画中化形而出, 完成一段**短促演出**后消散。

灵兽本体统一用"**朱砂笔画化形**"语言: 兽影由 2~4 条书法笔画 ribbon (外宽暗 + 内窄亮) 勾勒, 不用任何新贴图 —— 一笔成兽, 各生肖配色不同、笔画语言相同。龙符为旗舰: 灵兽升格为专属着色器绘制的雷龙真身, 且有走全屏名额契约的"雷龙劫"大招时刻。

**神话原型**: 符箓敕令 (道教)、金鸡报晓驱邪、天狗噬咬、玉兔捣药、万马奔腾、灵蛇缠身、血书符咒 (朱砂调血, 龙符以血为引)。

## 3. 逐件机制设计

九件共用投掷骨架 (`CharmPaperProj`): Swing 掷出 → 纸片朝目标点飞行 (~0.5s, 微弧线+翻飞) → 命中敌人/砖/到点 → 印章起爆 (符纸本体造成 1 次全额伤害) → 化形灵兽。以下"演出"均指灵兽段。

| 符 | 一句话身份 | 机制 | 帧数曲线 (前摇-爆发-收招) | 决策点 |
|---|---|---|---|---|
| 鼠 (Blue) | **群鼠窃金** | 化形 5 只鼠灵, 乱窜弱追踪, 各 1 穿透; 命中溅金屑 (窃金视觉) | 散开 6f → 各自 jitter 追踪 ≤150f → 咬中即散 | 密集投掷铺鼠海 vs 省蓝 |
| 牛 (Red) | **蛮牛攻城** | 单头巨牛横贯冲撞: 大判定框、重击退、可穿透一路 | 显形 14f → 刨地反冲 22f (pow(t,3) 后撤) → 1f set 34px/f 冲 24f (×1.02/f 递增) → ×0.72/f 急刹 8f 消散 | 对准走廊/怪堆再掷 |

### 3.1 雷龙劫 (旗舰大招, 每第 4 掷)

第 4 张符掷出时纸面转赤金 (uInk 变金、拖尾变粗), 起爆不召普通雷龙, 而是 `DragonCharmExplosion` (类名保留, 职能重铸为大招控制器):

1. **蓄** (40f): 落点浮起大朱印法阵 (CharmTalisman 印章模式, 300px, 展开+旋转), 向心汇聚电尘 (velocity ∝ 距离), 震屏随 t² 渐起, 汇聚在 ~75% 进度骤停 —— 尖叫前的吸气;
2. **落** (10f): 巨龙真身 (专属 CharmDragonBody 着色器, 60px 宽 ribbon) 自天顶穿印而下, 1 帧过屏级速度;
3. **劫** (18f): 印上炸开 —— 2 段 150% AoE (260px, 分段 8f 间隔) + 3 根雷柱 (BeamGrad 竖束, 4f 交错, 均在 AoE 半径内, 伤害与视觉严格对齐) + 全屏径向泛光 (名额契约) + 起爆 4f 内 PaletteTint 金紫定调 (强度 0.13 ≤ 0.15) + 震屏 9 + Thunder 音;
4. **偿** (机制): 雷龙劫首次命中回 20 HP —— 血债血偿, 闭合血祭循环。

## 4. 系列内梯度

- **朴素件** (鼠/兔/蛇/马): 共享原语 (双层 ribbon 笔画 + GlowBurst + ShockwaveRing + Burst) + 系列符纸着色器, 无其他专属 shader;
- **中档件** (牛/鸡/狗/猪): 同上 + 更完整的三段运动曲线与音高分层;
- **旗舰** (龙): 系列符纸着色器 + **专属 CharmDragonBody 着色器** + 雷龙劫全屏时刻 (名额契约 + ≤0.15 染屏)。
- 符纸/朱印视觉九件完全同构 (同一 shader, 仅换 uGlowColor/uCharmId 笔画布局) —— 系列记忆点。

## 6. 平衡与定位

- 配方/稀有度/价格/获取不变。**六件饰品 → 主动武器是本次系列使命的定位重铸** (原饰品全是作弊级占位: +80% 全伤/全 debuff 免疫/无限飞行, 无平衡基线可回退); 龙符保持远程、猪符保持魔法 (职业不回退), 其余七件定为魔法 (符箓=道术, 耗蓝)。
- **龙符爆炸砸方块**: 删除 (griefing + 联机安全), 换为纯伤害 AoE — 记为修复而非平衡变更。
- 蛇符旧"永久隐身"删除; 右键蛇蜕保留 2.5s 短隐匿 (утility→机制化)。使用时清除玩家遗留的永久 SnakeInvisibilityBuff。

|---|---|---|---|
| 鼠 | 70×5 鼠, 32t (1.9/s) | ~330 (鼠命中 2~3) | 群体分摊, Blue 位最弱 ✓ |

## 7. 性能与多人预算

- **多人安全**: 全部弹幕生成走 owner 端 (`Shoot` / `Projectile.owner == Main.myPlayer`); 目标点经 `ai[1]/ai[2]` 随生成同步; 变体旗标编码进 `ai[0]`; 大招计数/爬坡为 item 实例/localAI 状态 (仅 owner 消费); 灵兽状态存 `ai[]`/`localAI[]`; 血祭扣血在 owner 端 Shoot 内 (CanUseItem 门槛 >60 防杀); 震屏/染屏/泛光只在绘制路径。
- **性能**: 两个新 shader 经 `WeaponVFX.GetEffect` 缓存; 同屏灵兽约束 — 鼠 ≤5/掷、马 ≤9 (寿命 50f)、犬全场 ≤3、雷龙劫同 owner 同屏 1; 笔画 ribbon 顶点 ≤ (16 点 × subdiv 3) × 2 层; dust 节流 (每帧 ≤4/灵); 无热路径 LINQ/大数组分配 (spine 数组复用); 拖尾受 `MythologyConfig.Trail` 降级; 全屏后处理仅雷龙劫瞬间, 走 `RequestFullscreenSlot`。
- **震屏预算**: 掷符 0 / 朱印 1.5 / 牛撞·兔捣·嗝爆 2-3 / 雷龙劫 9 (§C.2 大招 8-12 内)。
