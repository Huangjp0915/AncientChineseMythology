# 酆都系列武器重做设计文档（Fengdus · 地府线终局梯队）

> 管辖文件：`Underworlds/Items/Weapons/Fengdus/*.cs`（8 件）+ 新建 `Effects/Fengdu*.fx` + 本文档 + 两个 hjson 中本系列键区。
> 对应神话原型：酆都大帝/阴天子的帝阙威仪 + 九幽虚空 + 罗生门噩梦。全模组演出天花板梯队之一。

## 1. 现状诊断（八条透镜逐件要点）

| 武器 | 主要问题 |
|---|---|
| 极寒渊薮九幽判官轮 | 轨道+自动冲刺有身份，但投掷后**零决策**（全自动）；冲刺是 lerp 追踪无 snap；配色纯冰蓝（Water 主题）与酆都黑紫完全脱节 |
| 酆都万劫寂灭黑帝刀 | 系列旗舰却是**原生匀速 swing**（无前摇/爆发/收招），本质"刀气机枪"（每 14 帧 5 道弹幕）视觉噪音大；combo 状态存 ModItem 实例字段不可靠；暴击(28%)每次全屏连锁过于频繁 |
| 地狱冥龙吐纳寂灭炮 | 名为"吐纳"却无蓄力吸吐循环，单键连按；配色橙红普通火（Scorch）不是冥焰；印记引爆的 SimpleStrikeNPC 未包 owner 判定 |
| 冥府至尊判官司命杖 | 5 发随机散射读作杂乱；烙印累积×1.5 回响是好机制但玩家**无法主动引爆**；配色鬼绿+金与酆都脱节 |
| 噩梦罗生门万咒葬神典 | 罗生门 4 秒持续 GenericWarp **违反全屏名额"短暂定调"契约**，且允许 3 扇门同屏竞争；机制单薄（放门即忘），无"万咒"层数概念 |
| 混元吞天万羽坠神弓 | 终局弓却无蓄力，机制=射箭开箭雨的常规套路；"万羽"无实体表达 |
| 暗影寂灭终极奇点炸弹 | 系列内基础最好（引力阱→内爆→连锁，配色黑紫贴题），但缺内爆前静默/收缩（充能语法缺最后一拍），无提前引爆决策；Detonate 伤害未包 owner |
| 虚空断罪永劫穿心矛 | 唯一有三段的（Prepare2f/Thrust5f/Retract3f）但前摇过短、SmoothStep 突刺不锐（应 poly(8+)）；无大招节奏；配色亮蓝跑偏；裂隙 2 秒持续 warp 又一处名额违规 |

**重做力度判定**：八件均已接入 WeaponVFX/ACMWeaponBurst（近期中等水准），视觉底子在但**机制深度、手感曲线、配色统一性、名额纪律**四项不达终局标准 → 全系列机制中改 + 主题统一 + 手感曲线重铸；刀、书两件全面重做为旗舰。

## 2. 系列主题与幻想感

**"你手持的是阴天子亲授的酆都权柄"**——每件武器都是一道地府法统：判官轮是敕令、大刀是帝诏、司命杖是朱笔勾魂、罗生门是噩梦之门、奇点是虚空吞噬。玩家体验三层幻想：

1. **虚空黑紫**（系列底座）：所有轨迹/辉光以黑紫为基调——虚空吞噬光线，暗色"洞"比亮色"光"更有终局感;
2. **帝阙威仪**（判决时刻）：帝金色只在"判决/敕令/处决"瞬间出现（诏书带、金边符印），平时不见金——稀缺性即威仪;
3. **罗生门噩梦**（大招定调）：全屏噩梦涌入只在大招瞬间 ≤30 帧，短促而慑人。

**统一配色语言**（消费 `ACMWeaponBurst.FengduVoid(13)` / `AbyssPurple(11)` / `LethalRed(15)`，呼应 YinEmperor 配色）：

- 虚空黑紫三阶：暗 `(25,8,40)` / 中 `(120,60,200)` / 亮 `(180,120,255)`
- 帝阙金：`(230,190,90)`，高光 `(255,230,160)`（呼应阴天子 ImperialGold/DragonVeinGold）
- 致命红 `(250,40,56)`：仅处决/引爆预警（红=即将伤害，遵守 TelegraphColors 契约）
- 魂青 `(80,200,220)`：魂系点缀（矛的回魂、炮的冥魂），呼应 SoulLanternCyan

每件在黑紫底座上保留一个个性偏移：判官轮=霜紫、黑帝刀=帝黑金、冥龙炮=冥焰红芯、司命杖=判官金朱、罗生门=噩梦红、坠神弓=混元紫白、奇点弹=纯虚空、穿心矛=虚空魂青。

## 3. 逐件机制设计

通用手感基线（全系列）：命中 = `ACMWeaponBurst.Spawn(FengduVoid)` + 音高随机 ±0.15 + 震屏 ≤2；大招 = 专属着色器 + 全屏短暂定调（≤30 帧，走名额契约）+ 震屏 6-11。

### 3.1 极寒渊薮九幽判官轮（近战·敕令飞轮）

- **左键（首掷）**：掷出判官轮，进入环绕轨道（保留骨架）。
- **左键（轮在场）＝敕令冲刺**（新决策点）：不再生成新轮，而是命令轮向光标方向冲刺。owner 端把冲刺向量写入 `velocity` + `ai[2]=1` 同步。
- 冲刺曲线重铸：反拉 6 帧（`pow(t,8)×40px` 反向，末帧突然吸入）→ 1 帧 `velocity=dir*35` snap（+尖啸 pitch 0.4）→ 冲刺中 ×1.02/f 递增 → 命中/16 帧后 ×0.62/f 硬刹回轨。自动冲刺保留但降频至 52 帧。
- **第 5 次命中＝九幽判决**（保留节奏）：轮驻停 26 帧，展开 `FengduVoidRift`(mode0) 霜紫裂口 + 冻结 AOE + 霜爆定调（FrostJudgmentFlash 配色改霜紫）。
- 配色：拖尾外 `(50,20,110)` 深紫 / 内 `(200,225,255)` 霜白；尘 PurpleTorch+IceTorch 混合。

### 3.2 酆都万劫寂灭黑帝刀（近战·旗舰一 · 手持弹幕全面重做）

改造为 **channel 手持弹幕**（`ImperatorBladeHeld`，按住连击、松开收刀），combo 存 `proj.ai[0]`（天然同步）。

- **三连击循环**，每击自定义挥砍曲线（基准 42 帧，攻速缩放；MOTION §1 波形）：
  - 前摇 ~42%：quadratic in-out 背摆 −1.0 rad（第三击 −1.35 rad、周期 ×1.35）
  - 爆发 ~12%：**poly(16) ease-out** 甩至 +1.5 rad——伤害窗仅在此段（CanDamage 严格对齐），挥弧 ribbon + 残影仅此段显形（速度门控）
  - 收招 ~46%：quintic in-out 回位
- 第 1/2 击（劈/撩镜像）：爆发帧释放 3 道黑帝斩气（±8° 扇形，伤害 ×1.4）。
- **第 3 击＝万劫寂灭诏**：过顶重劈，爆发帧释放 1 道大刀气（×2.2）+ 光标处虚空漩涡（ImperatorVoidEruption ×2.5，含 FengduVoidRift 小裂口）+ 漩涡上空垂下 `FengduImperialDecree` 诏书带（40 帧展开）。震屏 5。
- 处决保留（非 boss <25% 斩杀）：LethalRed 爆发 + 敌顶小幅诏书 + 全屏审判红 24 帧。
- 连锁审判改为**仅第三击暴击**触发（削频）。
- 音效：前摇 70% 低 whoosh → 爆发帧 Item71（第三击 Item119 叠低频）。

### 3.3 地狱冥龙吐纳寂灭炮（远程·蓄力吐纳炮）

改造为 **channel 蓄力手持**（`HellwyrmCannonHeld`）：按住＝"纳"，松开＝"吐"。

- 蓄力 0-90 帧三档（0-29 轻吐 / 30-69 中吐 / ≥70 满纳）。
- "纳"视觉：炮口 converging streaks（`vel=(muzzle-pos)*0.085` 各向异性拉伸），密度 ∝ `sqrt(charge)` 且 **72% 后剪除**（末段静默＝吸饱）；炮身随蓄力后错 `charge²×8px`，满档 ±1px 抖动；蓄力音每 12 帧 pitch 递升。
- "吐"：龙息波伤害 ×0.9/×1.9/×3.4，宽 ×1/×1.4/×1.8；后坐 4/9/15 + 震屏 2/4/6。满吐波头附加"冥龙魂首"核（程序化辉核，命中必印）。
- 印记引爆保留（红色倒计时=预警语言），满吐印记引爆 ×2.5；引爆伤害包 owner 判定。
- 配色：波体黑紫 `(140,50,220)` 底 + 冥焰红 `(255,80,90)` 芯；印记 LethalRed。

### 3.4 冥府至尊判官司命杖（魔法·朱笔勾魂）

- **左键**：2 发"朱笔勾魂弹"（双列螺旋对称正弦轨迹，替代 5 发随机散射），命中叠**司命烙印**（`FateMarkProj.ai[2]`＝层数，上限 6，每层记录伤害并刷新时限）。烙印层数以环绕符印圈数可读。
- **右键＝司命判决**（新决策点，AltFunction）：主动勾决全部烙印——每个烙印敌顶降下 `FengduImperialDecree` 帝诏带（22 帧展开→8 帧顿→勾决斩帧），伤害＝累积伤害 ×(1.2+0.15×层数)（满层 2.1×，高于 3s 自动引爆的 1.5×，奖励主动 timing）+ 金紫染屏 15 帧（ApplyPaletteTint）。烙印不存在时右键不可用。
- 3 秒自动引爆保留为兜底（×1.5）。所有引爆伤害包 owner 判定。
- 配色：外黑紫 / 内帝金拖尾，朱笔红弹头；符环金紫（替换鬼绿）。
- 伤害 3800→8000（2 发 vs 原 5 发，见 §6）。

### 3.5 噩梦罗生门万咒葬神典（魔法·旗舰二）

- **左键（无门）**：光标处召唤罗生门（同屏唯一 1 扇），门体用 `FengduVoidRift`(mode1 竖门) 绘制；**删除 4 秒持续 GenericWarp**（名额违规），门的扭曲感由门体着色器内部纹理承载。
- 门持续 5 秒：吸引敌人 + 每 45 帧伸出 3 根噩梦触手（配色暗红紫）；触手命中叠**咒层**（`RashomonCurseMark` 挂敌，上限 8 层，紫红咒纹可读）。
- **左键（门在场）＝收门清算**（新决策点）：门先 12 帧收缩 40% + 粒子全剪（**前静默**）→ 闭合帧：所有咒层敌人按层爆发（每层 ×1.2 门伤，owner 端）+ `FengduNightmare` 全屏噩梦定调 24 帧 + 震屏 8。门自然到期同样清算。
- 决策点：多攒咒层 vs 提前收门转移目标。

### 3.6 混元吞天万羽坠神弓（远程·蓄力弓）

改造为 **channel 蓄力手持**（`DeicideBowHeld`）：

- 三档拉弓（0-24 快射 / 25-59 二档 / ≥60 满弦）。快速点击＝1× 轻箭（保底 DPS）。
- 拉弓视觉：身后"万羽阵列"显形（4/8/14 支羽箭虚影 converging 聚位），**72% 后停止新增**（静默张力），满弦弓身 ±1.2px 微颤 + 弦光。
- 释放：主箭速度 20/26/34、伤害 ×1/×2.2/×4.5；羽箭阵列每 2 帧一支尾随齐射（×0.35，微前置预瞄）。
- 满弦主箭命中：撕开混元之门（`FengduVoidRift` mode0 小裂口 + ChaosRainZone 羽箭坠落）+ `FengduNightmare` 16 帧低强度。
- 配色：混元紫白（黑紫底 + 白金芯）。

### 3.7 暗影寂灭终极奇点炸弹（远程·提升补强）

- 骨架保留（投掷→引力阱 60 帧→内爆→连锁奇点）。
- **左键（阱在场）＝提前引爆**（新决策点）：伤害 ×(0.6+0.4×蓄力进度)——聚怪充分 vs 立即伤害。场上限 2 枚。
- 引力阱本体改 `FengduVoidRift`(mode0，uTear 随进度增) 替换三层 SoftGlow。
- 内爆补最后一拍：**末 10 帧粒子全剪 + 视界收缩 40%**（collapse）→ 1 帧白紫闪 → 内爆定调 + 三层时差冲击环（0/4/8 帧）+ 震屏 11。
- GenericWarp 引力透镜保留（60 帧短暂合法），强度曲线改 `charge³`。
- Detonate 伤害段包 owner 判定（演出段全端）。

### 3.8 虚空断罪永劫穿心矛（近战·连刺循环）

改造为 **channel 连刺**（按住持续刺击，松开收矛），连刺计数存 `ai[0]`：

- 曲线重铸（攻速缩放）：Prepare 10f（`pow(t,2.2)` 渐加速后拉 −34px，末 2 帧微顿＝吸气）→ Thrust 6f **poly(10) ease-out** 至 +190px（前 2 帧走完 ~78%，snap 帧配尖啸 + 残影）→ Retract 9f quintic 回位。
- **每第 4 刺＝永劫穿心**（大招节奏）：前摇 ×1.5（后拉 −50px + 矛身金纹充能 + ±1.5px 抖动）→ 突刺距离 300px、判定宽 1.5×，命中点撕开 `FengduVoidRift` 小裂口（30 帧）+ 线上所有敌人受创，裂隙强化版（`VoidRiftLine.ai[2]=1`）留存并脉冲。
- 裂隙持续 warp 删除：GenericWarp 仅大刺裂隙前 40 帧内合法运行。
- 无视防御、命中回血（30-80）保留；大刺命中回血 ×2。
- 配色：黑紫底 + 魂青芯（拖尾外 `(60,20,110)` / 内 `(140,230,235)`），击杀回魂尘魂青。

## 4. 系列内梯度

- **朴素件**（共享原语为主 + 专属 shader 复用）：判官轮、奇点弹、穿心矛

## 5. 视觉技术方案

**复用共享件**：WeaponVFX（拖尾/柔光/冲击环/径向泛光/溶解/染屏）、ACMShaders.DrawBeam（锋线/裂隙）、ACMWeaponBurst（命中栈）、ACMAsset 遮罩。

**新建系列专属着色器（3 个，全部 ps_3_0，命名前缀 Fengdu，用 `WeaponVFX.GetEffect` 按名缓存获取）**：

1. **`FengduVoidRift.fx`** —— 虚空裂口（屏幕空间 decal，载体同 ArenaRunic：满屏噪声 + SDF 裁剪早退出）。
   参数：`uTime/uCenter/uRadius/uIntensity/uAspect/uTear(撕裂度)/uMode(0=圆形奇点,1=竖门)/uColorEdge/uColorGlow/uSeed`。
   视觉：中心纯黑虚空吞底 → 锯齿撕裂边（角向噪声扰动）黑紫电弧 → 外圈向心流线吸积辉。mode1 为竖椭圆门 + 门内噩梦纹下涌。
   消费方：奇点阱、罗生门门体、判官轮判决、刀第三击漩涡、矛大刺裂口、弓混元之门。**同帧 decal 绘制限 ≤2 张**（静态帧计数器）。
2. **`FengduImperialDecree.fx`** —— 帝诏卷轴带（TriangleStrip 带状，顶点契约同 BeamGrad：uv.x 沿长）。
   参数：`uTime/uIntensity/uUnroll(展开进度)/uColorSilk/uColorTrim/uColorGlyph/uGlyphFreq`。
   视觉：黑紫缎底 + 两侧金边 + 中央方印符文列（网格化噪声阈值）+ 展开前沿金色亮线 + 端头收口。
   消费方：刀第三击/处决诏书、司命杖右键判决带。
3. **`FengduNightmare.fx`** —— 罗生门噩梦全屏定调（后处理，s0=screenTarget，s1=噪声，**必走 RequestFullscreenSlot，≤30 帧**）。
   参数：`uTime/uIntensity/uCenter/uAspect/uPull/uTint/uVeil`。
   视觉：屏幕边缘噩梦暗纹蠕动涌入（fbm 双八度）+ 轻向心收缩采样 + 径向色差；**中心 40% 保持清晰**（可读性阀门）。
   消费方：罗生门清算、弓满弦命中、（可选）奇点内爆。

## 6. 平衡与定位

获取途径（RevenantEX 前置件 + Corpsefragments×20 + SoulFragment×50 + UmbralStone×100 @ 月亮传送门砧）、稀有度 Purple、职业定位全部不变。DPS 论证（60fps 名义值，不含 DoT/印记增益）：

| 武器 | 原基线 | 重做后 | 变化 |
|---|---|---|---|
| 黑帝刀 | (5×0.8×12800)/14f ≈ 219k/s（刀气机枪） | 42f 周期均值 (3×1.4×12800×2 + 2.2×12800 + 2.5×12800)/126f ≈ 197k/s + 本体接触 | ≈ −10%（换得单发质量与可读性） |
| 判官轮 | 自动冲刺 40f 一轮 | 自动 52f + 玩家敕令补频 | 主动操作下 ≈ +5%，挂机 −20%（鼓励操作） |
| 冥龙炮 | 12200/22f ≈ 33.3k/s | 轻吐 0.9×/20f ≈ 33k/s；满吐 (3.4×12200)/(90+12)f ≈ 24.4k/s + 宽 1.8×多目标 + 印记 ×2.5 | 单体持平，群体/印记流 +10~15% |
| 司命杖 | 5×3800/14f ≈ 81k/s | 2×8000/14f ≈ 69k/s + 判决倍率 1.5→2.1 | 名义 −15%，烙印循环补回（净 ≈ 0） |
| 罗生门 | 门 tick + 触手（3 门叠加） | 单门 + 咒层清算（8 层×1.2×） | 单门场景 +15% 内，多门叠加不再可行（这是修正非 nerf：3 门本就是名额违规产物） |
| 坠神弓 | 5400/20f ≈ 16.2k/s + 箭雨 | 点射持平；满弦爆发 (4.5+14×0.35)×5400/103f ≈ 29.6k/s | 点射 0%，蓄力峰值为主动投入回报 |

## 7. 性能与多人预算

- 粒子：环境 ≤6/帧/弹幕，爆发一次性 ≤40；蓄力粒子 72% 剪除点同时是性能剪除点。
- 着色器全部静态缓存（`WeaponVFX.GetEffect` 按名缓存）；FengduVoidRift 同帧 ≤2 张（静态 `_lastFrame` 计数）；FengduNightmare/PaletteTint/GenericWarp 全走 `RequestFullscreenSlot` 且 ≤30/60 帧。
- 拖尾全走 `WeaponVFX.DrawProjectileTrail`（受 `MythologyConfig.Trail` 降级）。
- 多人：弹幕生成全走 Shoot/owner 判定；`SimpleStrikeNPC` 一律包 `Main.myPlayer == owner`；蓄力/combo/咒层状态全存 `Projectile.ai[]`（同步字段）；`Main.MouseWorld` 只在 owner 路径读取；震屏/染屏只在本地绘制路径。
- 全部演出弹幕 `damage=0, friendly=false`，`Kill` 语义不产生额外判定。
