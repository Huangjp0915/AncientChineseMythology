# 牛头马面 (NiutouMamian) 重做设计 V3

> 单元: `NPCs/Boss/NiutouMamian/` — 地府双 Boss 组合 (WoF 后早期困难模式)。
> 方法论: boss-fight-choreography SKILL (七大本能) + PACING §5 多 Boss 分工 + 共享简报硬性约束。

## 1. 现状诊断

1. **状态机原始且有死路隐患**: 数字 `ai[3]` 状态 + 巨型 if 链; 马面半血前只有"1 波齐射 → 240 帧干等"的空转 (违反"Boss 不得等自己的表"); 搭档索引 `NPC_MaMian_Count` 仅在 SpoawnProj 本地设置, 多人/复活后指向任意 NPC。
2. **失重失速**: 牛头冲锋 `velocity *= 1.2` 指数爬升、无反向蓄势、无硬刹 (0.95 惯性漂 80 帧)、转身瞬间翻转; 淡出→瞬移出现无 portal 遮掩; 马面全程一条 lerp 悬停, 零后坐力零次级运动。
3. **数值恶心但不可读**: DarkGreenProj 命中挂 29 种 debuff; EyeProj 命中 30 秒半防半血半输出; DarkGreenBoomProj 1500 伤 `p.Hurt` 直判 250px 无清晰预警; 半血领域 60% 减速常驻 550px —— 双 Boss 战里"双向夹击不可逃"。
4. **多人不安全**: 弹幕生成无 `MultiplayerClient` 判定; `Main.LocalPlayer` 出现在 AI 路径; ChainProj 直接改写玩家位置并把镜头 zoom 拉到 4.6; SpoawnProj 客户端生成 NPC。
5. **演出缺失**: 入场只有 320 帧黄尘打转; 换阶段无任何节拍无清弹; 双双阵亡无死亡演出。唯一亮点是"一方死亡→同伴引魂复活+尸位反制圈" (V2), 保留强化。
6. **视觉低级**: 本体 = 原图 + tint 残影 + 1.08x 发光; 无专属着色器。

**力度判定: 全面重做** AI 编排与视觉; 保留全部 public 类名、掉落、复活反制机制、勾魂机制、UnderworldField 身份层接入点。

## 2. 设计主题与幻想感

**"押解亡魂的地府双吏"**。牛头 = 力之吏 (赤炎熔红, 锁链蛮力, **重**), 马面 = 魂之吏 (幽紫鬼绿, 魂火符令, **快**)。
玩家要学的核心不是拼 DPS, 而是**读岗位**: 同一时刻永远一个"缠斗者"贴身压迫、一个"炮台"远程控场, 且**两吏按节拍换岗** — 换岗对穿本身就是全场最可读的标点。血量联动 (引魂复生 + 尸位反制) 讲的是"二吏同命"的关系故事。

配色语言 (TelegraphColors): 致命=Lethal 纯红; 牛头主题=Flame/Execution 熔红; 马面主题=NetherViolet/GhostGreen; 安全=Safe 翠玉。

- 死者 `CheckDead` → 同伴变引魂者 (默认无敌, 8.5s); 尸位生成反制圈 (NetherGate 法阵, 翠玉色): 玩家站入 → 引魂者可被伤害。引魂链 (BeamGrad) 连接引魂者与尸位。复活成功: 死者 50% 血淡入 + 魂火爆发; 被打断 (引魂者被击杀): 直接双亡结算。

## 5. 三大演出脚本

**入场** (SpoawnProj 重写, ~150f + NPC Intro ~120f):
0f 地面涌鬼绿魂火, 鬼门法阵 (NetherGate shader, 红紫阴阳双分) 从 0 展开 → 90f 门心两道魂柱 (BeamGrad 竖光) 升起, 震屏 4 渐强 → 150f 门破 (粒子迸发+震屏 8), 生成双 NPC → NPC Intro: 各自从门位弹出到玩家两侧高位, 60f **完全静止对视** (菜单式威压) → 同帧齐吼: 震屏 10、染屏跳变、冲天魂火。

**P2 换阶段** (~170f, 全程可被伤害但不攻击, 触发时清双方弹幕):
先半血者怒吼后仰 → 两吏向屏幕两肩位回撤 (35f) → 之间结出锁链光桥 (BeamGrad, 60f 渐亮) + 各自体表主题色光环爆发 (SoulFlame shader uFlash) → 链上滑过一盏魂灯从牛头到马面 (关系叙事: 权柄交接) → 光桥碎裂为粒子, 双吏同时向玩家逼近一步 (dash 8f) 落幅。

**P3 阎罗令** (~92f, 一次性): 天幕染屏跳深 + 红印晕影常驻升起 (vignette) → 两吏合流至玩家上方齐位 → 10f 屏息 → 同帧怒吼 + 震屏 12 + 处决色魂火新星 → 落位, 狂怒参数生效 (冲击帧留给终幕死亡, §9 唯一性)。

**死亡** (最后一名, ~150f; 引魂被断的"速朽"变体压缩至 58f): 清弹 → 失控: 身体带旋上飘, 断续喷黑烟+魂火 (密度∝进度) → 60f 锁链崩断 (铁屑射散+金属音+垂链甩尾) → 100f 起泛光收缩 → 132f **全屏白闪 4f (本战唯一冲击帧)** + 震屏 14 + 魂火喷泉 → 150f 服务器 StrikeInstantKill 真死掉落。

## 6. 视觉技术方案

**新建专属着色器** (ps_3_0, ModContent.Request 静态缓存于 NiuMaHelper, 不注册 ACMShaders):
1. `Effects/NiuMaNetherGate.fx` — 鬼门法阵: 阴阳双半环 (uColorA 熔红 / uColorB 幽紫) 反向旋转 + 符环 + 开门度 uOpen (中心撕裂亮缝)。用于: 入场之门、复活反制圈 (翠玉参数)、N3 落点、C2 结链中点法印。屏幕空间 SDF, 载体=共享噪声全屏绘制 (廉价装饰层, 不占全屏名额)。
2. `Effects/NiuMaSoulFlame.fx` — 本体魂火描边: s0=NPC 贴图, s1=噪声; alpha 邻域梯度检出轮廓 → 轮廓上叠向上流动火焰噪声 (牛头红/马面紫绿), uFlash 受击/演出闪白, uCharge 蓄力增辉。两吏本体绘制统一走它。

**复用共享件**: DrawBeam (预警线/锁链光/引魂链/光桥), ArenaRunic (忘川潮水域), RadialBloom (凝视蓄力/死亡收光, 走全屏名额), ElementalScreenTint (染屏, NiuMaScreenSystem 已有, 升级加 P3 红印晕影层), ACMAsset (SoftGlow/LightShot/EmberShards/Smoke)。

**升级 NiuMaScreenSystem**: 保留 Publish 染屏; 新增 (均为廉价 overlay 层, 不读 screenTarget): ① `PublishVignette` P3 处决红晕影; ② `AddGateDecal` 世界空间鬼门法阵登记 (环形缓冲 ≤4, PostDrawTiles 绘制于实体下层); ③ `FlashWhite` 全屏白闪 (MagicPixel 直画, 2~10f, 本战 ≤2 次)。

**次级运动**: 两吏身下各挂 2 条 Verlet 垂链 (ACMUtils.VerletStep, 纯客户端视觉), 冲刺/急停时链条甩尾 — "重量=反作用"。速度门控残影 (仅爆发帧), 发射后坐力 (魂火 6px / 链锤 22px)。

## 7. 性能与多人预算

- 弹幕生成/状态切换仅服务器 (`Main.netMode != NetmodeID.MultiplayerClient`), 切换时 `netUpdate=true`; 状态承载于 `ai[0..3]` (state/timer/substate/duty), 搭档按 type 扫描+whoAmI 缓存校验。
- 镜头/染屏/粒子/垂链纯本地 (`Main.dedServ` 守卫); 删除 ChainProj 的 zoom 4.6 (镜头介入上限 1.35 且限入场/死亡)。
- Effect 静态 Asset 缓存; 无每帧 new; dust 每帧上限 ~40; 全屏后处理只经 RadialBloom 契约入口; 染屏/法阵/晕影均为非 screenTarget 廉价层。
- 掉落/召唤/downed 标记/复活机制不回退。弹幕伤害重校: 弹 22~40, 接触基线 30, 冲撞窗口 95 (原 200~1500 离谱值废除)。
