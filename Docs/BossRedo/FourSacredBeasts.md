**风格统一约束**（三兽通用，硬性）：
- 全部继承 `SacredBeastBase`（确定性轮替 + Windup/Strike/Recover 预警子状态机），**共享层本轮冻结不改**（只准调用，不准改动——玄武虽不继承基类，但 Qinlong/Baihu 依赖其行为）。

- 震屏一律走 `ACMUtils.AddScreenShake`（统一预算）：落地 4–6 / 相变·大招 8–12 / 入场·死亡 ≤16。

- 多人安全：AI 决策只依赖 `npc.ai[]`/同步字段，弹幕仅服务器生成，视觉字段仅客户端。

## 1. 现状诊断

### 1.1 共享层（SacredBeastBase / FX / Element）
- 骨架健康：确定性轮替、预警子状态机、主题色板、网络同步齐备。玄武**不**继承基类（独立实现），因此共享层的使用方只有三兽——本轮策略：**冻结共享层**，三兽的新助手一律写进各自文件夹，避免并行冲突。
- `SacredBeastFX` 是着色器守卫层（CPU fallback），可以继续用，但三兽的高级视觉应直接走 ACMShaders 硬化 API + 各自专属着色器。

### 1.2 青龙（Qinlong）
1. **没有蛇身**——中国龙最核心的视觉（长蛇形身躯）完全缺失，只有一张单帧贴图按速度转向。玄武都有 Verlet 蛇链，真正的蛇形龙却没有，是全单元最大视觉欠账。
2. **全程 Lerp 悬停**：所有状态的位移都是 `velocity = Lerp(...)`，没有一个冲刺，没有反向蓄势，没有硬刹车。「速度即对比」完全缺席——龙不游、不甩、不跃。
3. 零专属着色器；雷电视觉是直线 DrawBeam（无分叉、无天空闪光）；`QinglongThunderBolt`（紫色调，离色板）已成孤儿类无人引用。
4. 三大节拍薄弱：入场=Lerp 降落 120 帧；换阶段=原地吸尘；**没有死亡演出**（瞬死掉尘）。
5. Bug：`UpdateRotation` 用 `MathHelper.Lerp` 插值角度不做 WrapAngle，跨 ±π 时会整圈打转。
6. 招式设计本身合格（安全缝、风域推搡、天气承诺都可读），保留机制、重做执行。

### 1.3 白虎（Baihu）
1. 「猎手循环」概念好，但**扑击没有前摇语言**：直接 `velocity = dir * 46` + 0.93 衰减，没有伏低、没有反向蓄势、没有 late-snap，40+ px/f 的速度反而读不出快（没有对比）。
2. Stalk 恒速绕圈——正是 skill 失败模式「orbiting at long range reads as disengaged」。
3. 金与音的元素身份薄：BaihuSonicRoar 只在震地踏里当判定环用，SoftGlow 点阵拼环；没有独立的音啸攻击；没有金属光泽、没有爪痕视觉（SlashBurst 素材闲置）。
4. 零专属着色器。P3「落地形态」其实还是悬停 Lerp（GroundedHover），震地踏没有真正的踏地动作。
5. 铁壁的缺口是随机角度，与「虎啸朝向宣告」的文案不符——机制没讲故事。
6. 入场=侧面 Lerp 飘入；换阶段=吸尘；**没有死亡演出**（只有 shake 16）。

### 1.4 朱雀（Suzaku）
1. **涅槃重生**概念已立（CheckDead 拦截 → 灰烬 → 复生），但执行只有尘埃 + PaletteLUT 调色：没有坠地、没有心跳递进、没有爆燃日轮——全组最佳假死题材只用了三成。
2. **没有焰翼**：一只 170px 的四帧小鸟贴图，没有任何程序化火焰翅膀/热浪，火之圣兽的"体积感"缺失。
3. 俯冲：Lerp 升空 → 直线 42px/f——没有折翼滞空的静默节拍，没有拉起动作。Hub 悬停是正弦扫动，无振翅物理。
4. 零专属着色器（PaletteLUT/ArenaRunic 等全是共享件）。
5. 入场=Lerp 降落；真死（涅槃后二杀）无演出（裸 PunchCamera 25，超预算且无编排）。
6. 弹幕族（Ember/Feather/SunPillar/SolarBeam）质量尚可，保留，只做小幅增强。

### 1.5 其他
- `Items/FourSymbolsTablet` 是占位 stub：**当前全仓库没有任何召唤四圣兽的途径**（`NPCType<四兽>` 只被各自天幕引用）。「四象归位」组曲既是演出机会也是功能补全。
- 四兽掉落表、downed 标记齐全，不可回退。

## 2. 设计主题与幻想感

- **青龙——「东方苍龙，行云布雨」**：玩家在一条真正的长龙织出的风雷之网里找缝隙。龙永远在动：游曳如书法笔画（慢顿-快甩），盘环成笼时它的身体就是墙，终局它呼来雷暴，让天空替它出手。危险来自空间被风推着变形，安全来自读懂"龙在哪，缝就在哪"。
- **白虎——「西方金虎，啸震山河」**：被一头会伏低、会假动作、会绕背的猛虎狩猎。它大部分时间不攻击——蓄势本身就是威慑；出手只在一瞬，锋利到只有一条红线的宽度。音啸是它的空间控制，金属是它的质感。三阶段它落地成形，每一步都震出大地的回响。
- **朱雀——「南方朱雀，浴火涅槃」**：天上悬着一轮会俯冲的太阳。它的火不是弹幕密度，是"垂直压强"：影子预警、折翼骤落、拉起时大地已燃。它死过一次——灰烬寂静、心跳复燃、日轮爆燃归来，是整个天界最盛大的一次"假死"。真死则安静而挽歌式：火尽星沉。
- **玄武（不动）**：北方守势堡垒，与上面三兽构成「游走 / 垂直 / 水平 / 原地」四种空间语言的完整对位。

## 5. 入场 / 换阶段 / 死亡三大演出脚本

### 5.1 青龙
- **入场「穿云见龙」(~170f)**：天幕先起风（Sky 渐绿）→ 背景 3 次龙影掠过（fake-Z 剪影缩放 0.4–0.6、每次伴远雷）→ 第 3 次后龙从屏幕侧面**高速破入**（80px/f）、头顶硬刹（×0.6/f），蛇身甩尾归位 → 仰首长吟 + shake 14 + 全屏翠光。
- **换阶段 P2 (~90f)**：龙盘成圆制动 → 天空瞬暗 0.4s → **一道 QinglongLightning 分叉巨雷从天劈中龙身**（白闪 + shake 11）→ 龙身通电（ribbon 亮度脉冲），雷暴底色常驻。
- **换阶段 P3 (~110f)**：龙首尾相衔盘成环（衔尾蛇姿态，锚点圆轨）→ 环心聚风 → 风环爆发清弹 + shake 12 → 散开时全身风纹流动。
- **死亡「化雨升天」(~200f)**：拦截 CheckDead 一次 → 清全场敌意弹 → 龙缓慢螺旋盘升（半径渐缩、蛇身拉长淡化为雨丝）→ 期间闪电以递减间隔劈落（40→10 帧，pitch 递升）→ 最后一道巨雷正中 → 白闪 0.3s → 龙身碎为翠玉光雨（Dissolve 弹开）+ QinglongGale 顺势消散 → 真实死亡结算（掉落/downed 不变）+ shake ≤16。

### 5.2 白虎
- **入场「裂空而来」(~150f)**：屏外一声虎啸（天幕微暗）→ 空中浮现三道 BaihuClawRend 爪痕撕裂（错帧亮起）→ 白虎从裂痕中跃出、120px/f 砸地（shake 12、尘暴）→ **静止 60 帧凝视玩家**（威慑=静止）→ 起身入循环。
- **换阶段 P2 (~90f)**：仰天长啸 → BaihuSonicRing 三环外扩**清弹** → 金属尘沙向鬃毛汇聚（银辉 MetalSheen 常驻淡入）。
- **换阶段 P3「白虎落地」(~120f)**：跃至高空 → 0.5s 悬滞（粒子骤停静默）→ 流星坠地（velocity 46、白闪 + shake 14、全场 ArenaRunic 裂地纹）→ 落地后 40 帧低吼蓄势，进入落地形态（全程清弹）。
- **死亡「金断啸终」(~160f)**：拦截 CheckDead → 清弹 → 踉跄两步（速度扰动 + 火花）→ 向玩家方向奋力一跃但中途力竭坠地滑行（无伤害）→ 起身昂首**最后一啸**：三重音环 + 屏幕白闪 → 身体经 DissolveBurn 溶解成银色碎片流向西方 → 真实死亡结算 + shake ≤16。

### 5.3 朱雀
- **入场「日轮开屏」(~150f)**：天幕先染赤 → 一轮**日冕盘**（SuzakuSolarFlare decal，本体隐形在内）从高空缓降 → 日轮收缩-爆开，朱雀展翼冲出（焰羽环 + shake 12）→ 双焰翼（FireWing）点燃定格。
- **换阶段 P2 (~90f)**：空中后仰翻身一周，甩出焰羽环，翼焰亮度上档。
- **换阶段 P3 (~120f)**：短蓄力 + 日冕环爆（克制——真正的高潮留给涅槃）。
- **涅槃重生（假死高光，~260f）**：HP=0 → **顿帧 6f**（速度归零、粒子骤停）→ 翼焰逐羽熄灭（20f）→ 自由落体真坠地（尘土闷响 + shake 8）→ **灰烬寂静 100f**（PaletteLUT 去饱和、灰烬上升、全场静音感）→ **心跳复燃 60f**：微弱红光以 1Hz 脉动，间隔按手调数组 40→8 帧加速、pitch 递升 → 收束粒子硬切 + 一拍黑 → **爆燃 20f**：日轮全屏绽放（SolarFlare + RadialBloom）、双层焰环、竞技场火柱点燃、PaletteLUT 甩红、shake 14（全场最强）→ 凤凰以满焰翼升起，40 帧缓冲后入涅槃循环。
- **死亡「火尽星沉」（真死，~150f）**：拦截第二次 CheckDead → 清弹 → 焰翼逐段熄灭（FireWing 强度阶梯下降）→ 身体缓缓下沉、余烬逆重力上升（挽歌式安静，与涅槃的轰烈对比）→ 最后一次微弱暖光脉动 → 本体化作一粒上升余烬熄灭 → 真实死亡结算 + shake ≤10。

### 5.4 四象归位（FourSymbolsTablet 组曲，协调者实施）
- 四象碑从 stub 升级为可用召唤物：使用后按方位序**青龙(东)→朱雀(南)→白虎(西)→玄武(北)** 依次召唤；前一兽被击败后 ~240f 间奏（方位色泛光 + 战斗播报文本）再召下一兽。
- 控制器为 `FourSacredBeasts/` 根下新 ModSystem（`FourSymbolsRiteSystem`），只做「监视存活 → 间奏 → 生成下一兽」，**不改任何兽的 AI**；服务器权威、断线/Boss 消失自动终止仪式。
- 任一四兽在场时四象碑不可用。每兽掉落照常。

## 7. 性能与多人预算

- 蛇身/焰翼/残影全部客户端（`Main.dedServ` 早退），字段不同步；AI 只写可同步槽位。
- 顶点带：青龙蛇身双层 ≤ (14×3×2×2) 顶点/帧；白虎音环 ≤ 96 顶点/环×3；无每帧 new 纹理/Effect（静态缓存 + `ACMShaders.NoiseTexture` 共享噪声）。
- 全屏后处理同帧 ≤1：朱雀内部优先级 PaletteLUT(涅槃) > HeatHaze；青龙 Gale、白虎全部走 overlay/decal 不占名额 → 四象归位连战时名额无冲突。
- 弹幕上限：音啸每环 1 个弹幕实体（环形判定复用 BaihuSonicRoar 模式）；青龙死亡演出落雷为纯视觉 decal + 单次伤害弹幕≤6。
- 多人：三兽死亡演出用 CheckDead 拦截 + 状态机播放，结束后服务器端真实击杀；`netUpdate` 在每次状态转换触发（基类已做）。
