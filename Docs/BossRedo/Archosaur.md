## 1. 现状诊断

以 choreography skill 七大本能与失败模式清单为透镜：

1. **三大演出节拍全缺**。入场只有一声音效（OnSpawn 播放 Summon），Boss 凭空出现在玩家身边；换 P2 只有 45 帧 i-frame + 一声吼；死亡瞬间消失。没有任何"事件感"。
2. **动作失重、无速度对比**（本能 #1/#2/#3）。全程 8 字 Lissajous 匀速盘旋；唯一的俯冲是"发光 2 秒 → 30px/f 直线 ×1.005"，无反向蓄势（counter-motion）、无硬刹车、无残影、无后坐力；齐射时头部纹丝不动。蠕虫身体没有任何次级运动（鞭波/甩尾），像一串匀速珠子。
3. **战斗是平的，不是波**（本能 #5）。P1 四招固定顺序轮转，P2 除了分身没有任何新招；没有招式池随血量增长，没有"扣在低血量的王牌"。破绽窗口 6 秒里 Boss 减速发呆——玩家无事可躲、Boss 明显在等自己的计时器（PACING 自检第 3 条直接命中）。
4. **分身读法与公平不足**（核心课题）。分身生成是一行 NewNPC，没有"从本体撕出"的因果演出；分身 27px/f 俯冲只有粒子汇聚预警、**没有冲刺线 telegraph**；分身存活期间本体照常打完整轮换，尾雷+分身俯冲可同屏双 striker（PACING §5 明确反模式）。真身/幻影只靠一层冷色 tint 区分，无高对比读法。
5. **接触伤害无门控**。`NPC.damage = 1000` 全程常开（含 80 节身体），盘旋剐蹭即近乎秒杀，与"伤害窗口与视觉严格对齐"底线冲突。
6. **世界层反馈单薄**。StormSystem 只是一层 ElementalScreenTint 压暗；雷暴 Boss 没有闪电、没有雨、没有随攻击触发的天空事件（本能 #7）。
7. 结构上健康的部分（保留骨架）：状态转移全部 ai[]+netUpdate 服务器权威；尾雷有超时保底；雷巢中点可破节点、逆雷向心是好机制；替身=破绽钥匙的循环成立。**判定：全面重做编排与视觉，保留机制骨架与网络模式。**

## 2. 设计主题与幻想感

**「雷暴中的双影龙神」**。祖龙残魂是盘古开天后第一条龙的残念，栖于雷暴之中；它已经"死过一次"，因此能把魂魄撕成两半作战。玩家体验三层幻想：

- **雷暴是它的身体**：入场时雷暴先于龙到来，天空闪电随攻击落下，死亡时雷暴随之散去（世界层 = Boss 的一部分）。
- **真身与幻影**：真身鎏金瞳、金青电弧；幻影冷灰蓝、半透明、带静电噪点闪烁，且**幻影的预警线永不转红**（全模组语言：红=致命）——读法练习被编进颜色语言而非说明书。
- **蛇形的重量**：长蛇冲刺前整条向后倒吸（late-snap 反向蓄势），刹车时鞭波沿 80 节身体传到尾尖——一次输入，一秒有机余韵。

配色：主题雷电青白 `TelegraphColors.Lightning`，真身金 `(255,214,120)`，幻影灰蓝 `(150,180,220)`，致命预警只用 `TelegraphColors.Lethal`。

## 4. 招式编排表

时长均为 60fps 帧。公平底线：致命预警 ≥36f 且必转红；换阶段清弹；所有状态有超时保底出口；接触伤害按状态门控（见 §4.9）。

### 4.1 残雷齐射 ThunderVolley（P1/P2/P3）
- **前摇 72f**：悬停减速（速度 ×0.94/f），汇聚粒子（径向吸入 + 切向环绕两族），密度 ∝ √t 且 **72% 处硬切静默**（尖叫前的吸气）；头部辉光三次方增长。
- **爆发 1f**：9 发扇形（64°）残雷弹直射，头部**后坐 7px/f**；雷鸣 + 震屏 5。
- **收招 26f**：刹车 ×0.9 回盘旋。
- P2/P3 变体：二连射（第二轮 +14f，扇形错半格）。
- 公平阀：扇形零随机；玩家 <200px 时扇形角放大 1.35×（留出贴脸逃逸缝）。

### 4.2 贯穿俯冲 SkyPierce（P1/P2/P3）
- **前摇 66f**：先快速占位玩家侧上方 480px（到位即跳时间，不空等）；后 30f 反向蓄势 `offset = -dir * pow(t/30, 8) * 240px`（late-snap 倒吸）；**T-36f 起红色冲刺线**（DrawBeam，渐强，带铅瞄 `target + vel*12`）。
- **爆发 10f**：`velocity = dir * 52`，每帧 ×1.03 复利（→ ~68px/f）；发射帧雷裂声 + 震屏 7；**残影仅在速度 >24 时绘制**（速度门控修饰）。
- **刹车 18f**：×0.68/f 硬刹 + 甩尾鞭波沿身传播（SegmentWave 冲量）。
- 循环 ×2（P3 ×3，速度 +15%），二段从另一侧入。
- 公平阀：发射时距玩家 <340px 则降速起步 (52→40)；冲刺伤害窗口仅在速度 >24 时开启；总时长上限 = 循环数×94+20f 保底出口。

### 4.3 尾雷行波 TailStorm（P1/P2/P3）
- **前摇 42f**：头部拉平（把身体带成玩家上方一条横弧）；**预波 20f**：段节从尾到头依次微闪——"电荷沿脊柱行进"的因果预告。
- **释放 96f**：12 根落雷柱按 `段序 × 8f` 波次落下；每根自带 40f 导引线（青白 → 末 30% 转红）→ 16f 雷击（新闪电 ribbon 渲染）。
- **收招 30f**。超时保底：`42 + 8×15` 帧强制离开（保留原设计）。
- 公平阀：波次方向固定（尾→头）可预读；雷柱间距 = 段距 ≥110px 可穿行。

### 4.4 雷巢 ThunderNest（P1；P2 六芒变体）
- **布阵 26f**：三颗雷巢球**从龙口射出**、弧线飞往玩家周围 270px 三角位（因果可见，替代原先凭空出现）。
- **蓄力 180f**（保留）：三条链电张力线渐强，中点可破节点（HP 1600，打碎该链失效）；末 0.25s 转红。
- **雷击 24f** + 收招。
- **P2 六芒变体**：幻影存活时，幻影同帧向旋转 60° 的三角位吐出三颗**幻影巢球**——三条幻影链**灰蓝、微透明、永不转红、永不造成伤害**，雷击帧化烟消散。六条链里只有三条真——用颜色语言训练真幻读法。
- 公平阀：节点破坏即安全；链电只在两端间线段判定（宽 18px）。

### 4.5 双龙对冲 TwinCross（P2，幻影存活时）
- **就位 ≤70f**：真身取玩家左上锚 `(-520,-260)`，幻影取右上锚 `(+520,-140)`（异高 → 两条冲刺线永不交汇于同点，天然逃逸缝 ≥120px）；双方到位即跳时间。
- **前摇 36f**：双龙同时反向蓄势 + 各自红线 telegraph（幻影的线更细更淡但**这次会转红**——幻影俯冲是真伤害，线的语义跟伤害走）。
- **爆发**：真身 T+0 冲（52px/f），幻影 T+14f 错拍冲（46px/f）——错拍给二次反应窗。
- **收招 24f** 双刹车。总上限 170f。
- 公平阀：两线夹角保证；错拍 14f；期间尾雷/巢等其他弹幕源静默（单 striker 规则）。

### 4.6 幻影自主俯冲（P2 幻影常态）
- 保留"绕到对侧 → 俯冲"骨架，重做：换位 90f（含到位早退）→ **反向蓄势 22f + 红线 telegraph 36f** → 俯冲 44f（46px/f，×1.02/f）→ 刹车。
- **节流（单 striker 阀门）**：仅当宿主处于 Roam/Volley/Nest（低压招）时才允许起手；宿主俯冲/对冲/尾雷期间幻影只做外围环绕（presence）。
- 幻影被击破 → 宿主触发逆雷（§4.7）。

### 4.7 逆雷 + 破绽窗口 ReverseThunder + SoulWindow（P2）
- 幻影破碎瞬间：灰蓝爆花 + 宿主清空自家弹幕（防叠杀）。
- **逆雷 100f**：外环 11 道逆雷预警（红导引线指向圆心）→ 向心汇聚 17px/f（躲位向外，反直觉招保留）。
- **破绽窗口 300f**（原 360f 发呆 → 重做为"可读的献祭时刻"）：真身金光暴露（受伤 ×1.6），减速漂移，**每 45f 从身体溢出一圈无害金色魂光**（视觉节拍器：告诉玩家窗口还在）；窗口最后 60f 金光闪烁加速（即将关闭的读法）；窗口结束脉冲 + 恢复。
- 公平阀：窗口期接触伤害 0；窗口期幻影不重生；逆雷汇聚到中心 40px 内自毁。

### 4.8 P3 新招

**雷渊螺旋 MaelstromSpiral（P3 主压制）**
- **起手 40f**：龙吼 + 拉到玩家外围 640px 轨道；天空闪电频率上调。
- **盘绕 400f**：绕玩家盘旋（轨道中心以 0.02 惰性跟随玩家——软栓绳），半径 640→400 线性收缩；每 36f 从 3 个等距段节垂直落雷（40f 预警），**每波固定留 1 个 70° 旋转安全扇区**，扇区中央以玉色 Safe 光点标注；同时段节挂弧（视觉压力）。
- **破圈 30f**：龙向外甩尾破圈散开（鞭波冲量）+ 全部剩余雷柱预警消散。
- 公平阀：安全扇区必存在且被标注；雷柱可穿行；收缩下限 400px；接触伤害 0.6×（身体是笼壁不是刃）。

**贯天雷柱 HeavenPierce（P3 处决级华彩，每袋至多一次）**
- **标记 30f**：红色 X 标记弹幕生成、滞后跟踪玩家；龙升至玩家上方远处并仰啸。
- **蓄力 60f**：标记 75% 时**锁定**（变粗变亮 + 双侧次生雷柱位置同时画预警线）；龙反向下沉蓄势；蓄力粒子 72% 硬切。
- **冲天 35f**：龙垂直冲天 70px/f 消失于屏幕上方（可见的"离场"）。
- **静默 25f**：屏幕只剩锁定 X 与预警柱的脉冲——爆发前的收缩。
- **贯下 ~26f**：龙在屏幕外瞬移至锁定 X 正上方 1400px（屏外瞬移合法），以 78px/f 携雷贯下——龙体即闪电（沿路径叠加闪电 ribbon）；触地帧：RadialBloom 0.9 + 震屏 13 + 左右 ±260px 两根**已预警**的次生雷柱落下。
- **收招 90f**：慢速回升，接触伤害 0，风暴回落（呼吸拍）。
- 公平阀：X 锁定后不再跟踪（跑离即安全）；次生柱提前 85f 画线；玩家 >2000px 时直接跳收招（栓绳）。

### 4.9 接触伤害门控（全阶段公平阀）

基准接触伤害从 1000 下调至头 260 / 体尾 200（原 1000 剐蹭即秒杀，与伤害窗口对齐原则冲突；弹幕伤害 90~140 维持现状量级）。门控倍率由头部按状态发布、全段继承：

| 状态 | 头 | 身体 |
|---|---|---|
| 俯冲/对冲/贯下（速度 >24） | 1.0 | 0.75 |
| 盘旋/蓄力/尾雷/巢 | 0.45 | 0.35 |
| 雷渊螺旋 | 0.6 | 0.6 |
| 入场/相变/窗口/死亡 | 0 | 0 |

## 5. 入场 / 换阶段 / 死亡三大演出脚本

**入场 A_Intro（210f）**（出生点：玩家上方 1150px 屏外）
1. 0–30f：雷暴强度 0→0.85 骤起；t=8 / t=22 两道天空闪电（远、闷）。
2. 30f：第三道巨雷正劈出生点（屏内可见天空白闪 1.0 + 雷鸣）；龙从闪电中以 58px/f 贯出。
3. 30–84f：S 形贯下（velocity.X 正弦编织 ±14），残影全开、雨声起。
4. 84–102f：×0.72/f 硬刹悬停于玩家侧上方。
5. 102–162f：**60f 完全静止凝视**（金瞳渐亮，唯一动作是缓慢呼吸幅度）——威压=静止。
6. 162f：仰啸（Roar + Summon 音效叠加）+ 震屏 9 + 天空白闪 0.65；162–210f 收势入 Roam。
- 全程无敌、零接触伤害。多人：位置在 OnSpawn 服务器端设定，状态经 ai[2] 同步。

**相变 P2 A_PhaseSplit（118f，60% 触发）**
1. 0–20f：急减速定身；低吼；**清空本 Boss 弹幕**。
2. 20–78f：全身段节电弧痉挛（密度 ∝ √t），头部微幅抖动渐强；**66f 处粒子硬切 → 12f 静默**。
3. 78f：**撕裂帧**——幻影蠕虫在本体位置生成、被"拽"向玩家对侧（有行进过程非瞬移）；白闪 1.0 + 冲击波 + 震屏 11；真身反冲 8px/f。
4. 78–118f：真身反冲衰减、幻影就位；双方 60f i-frame。

**相变 P3 A_PhaseMerge（110f，25% 触发）**
1. 0–30f：双龙减速；幻影定身、通体白化（幻影着色器 uDissolve 渐升）。
2. 30–80f：幻影化作光流飞回真身（40px/f 渐加速，金色光带连接两者）；触及即散为金屑。
3. 80f：吸收爆闪——真身金光暴涨 + 震屏 9 + 清弹；全身段节挂弧开启（P3 常驻视觉）。
4. 80–110f：收势。幻影已死时走 40f 短版（真身自聚雷光）。全程无敌。

**死亡 A_Death（230f，CheckDead 拦截）**
1. 0–40f：定身抽搐；段节从尾到头每 3f 依次白闪 + 电弧爆花（80 节的死亡波）。
2. 40–140f：头部缓慢仰起（角度插值），天空闪电频率拉满（每 ~18f 一道），龙身亮度渐白；雷暴 storm 1.0。
3. 140f：**全场唯一的最重拍**——巨雷白柱从天贯中头部（闪电 ribbon 全宽 + RadialBloom + 白闪 1.0 + 震屏 16）。
4. 140–200f：龙身溶解上升金屑（alpha 渐隐 + 光尘），雷暴快速回落。
5. 200f：真实死亡（life=0 → OnKill：downed 标记 / 音效 / 原有逻辑全保留）。
- 死亡期间幻影若存活：立即化光消散（不触发逆雷）。

## 6. 视觉技术方案

**新建专属着色器（全部 ps_3_0，Archosaur 前缀，在 ArchosaurVFX 内静态缓存，不注册 ACMShaders）：**

1. `ArchosaurStormSky.fx` — 全屏雷暴氛围 overlay（自开合批画占位像素，走 `ACMShaders.DrawFullscreenOverlay` 模式，s1 绑共享噪声；不读 screenTarget、不占全屏后处理名额，与现行 ElementalScreenTint 用法同类）：双层 fbm 云海压暗 + 斜向雨丝（快速滚动 streak 噪声，强度门控）+ `uFlash` 天空白化（闪电时刻）+ `uWindow` 破绽金化 + 暗角。替代现在的 ElementalScreenTint 占位调用。
2. `ArchosaurLightning.fx` — 顶点条带闪电（PS-only，配 `ACMUtils.BuildRibbonStrip` 直带、SpriteBatch Immediate 顶点绘制，同 `ACMShaders.DrawBeam` 的既定模式）：带内程序化折线核心（噪声位移中心线）+ 分叉亮斑 + 高频闪烁 + `uSeed` 每道随机形态。用于：尾雷/次生雷柱、贯天雷柱、死亡巨雷、雷巢链电强化。
3. `ArchosaurPhantom.fx` — 幻影头显形着色（s0=NPC 贴图, s1=噪声）：去饱和冷灰蓝化 + 横向静电撕裂抖动（扫描线位移）+ 边缘噪声溶解 `uDissolve`（出生 1→0，吸收 0→1）+ 透明脉动。只上幻影头部（每帧 2 次开合批，可控）；幻影身体段用便宜方案：冷色 tint + 确定性透明闪烁 + 偶发 ElectricArcSheet 加性电弧条。

## 7. 性能与多人预算

- **着色器**：3 个新 Effect 全部惰性 ImmediateLoad 一次静态缓存（Xuanwu 模式）；`!Main.dedServ` 守卫；卸载置 null。
- **全屏**：StormSky overlay 每帧 ≤1 次（占位像素 overlay，不读 screenTarget）；RadialBloom 走 `RequestFullscreenSlot` 名额契约；受 `MythologyConfig.FullscreenShadersEnabled` 总闸。
- **顶点/批次**：闪电 ribbon 单道 = 1 次开合批（同 DrawBeam 现状）；同屏雷柱 ≤6 道在击打帧重叠；幻影头着色 2 次开合批/帧；段节电弧为普通 sprite 加性绘制无额外批。
- **粒子**：每帧 dust 上限 ~40（蓄力 ≤5/f、雨/环境交给 shader 而非 dust）；死亡波每 3f 一段 ×8 dust。
- **分配**：无每帧 new 纹理/Effect/RT；bolt 事件列表复用 List 容量；洗牌袋数组重用。
- **多人**：状态机 `ai[0]=Phase, ai[1]=SubSignal, ai[2]=Attack, ai[3]=CloneIdx` + `netUpdate`；计时器 localAI 各端确定性自增（沿用现状模式）；弹幕/NPC 生成全部 `Main.netMode != MultiplayerClient` 判定；幻影读取宿主 ai 同步态决策；`Main.LocalPlayer`/演出标量只在绘制路径。CheckDead 服务器权威。
- **掉落/进度**：OnKill 的 downed 标记、Boss 清单、无掉落表现状 —— 全部不动（仅演出前移到 CheckDead）。
