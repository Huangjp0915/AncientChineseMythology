# 赢勾（Yingou）重做设计文档 —— Boss 重做工程 V3

> 单元：`NPCs/Boss/Yingous/`（Yingou 主体 / YingouHand 双刃 / YingouFireBall 尸火 / SaberHell·SaberKiller 刀阵 / YingouSky / YingouScreenSystem）
> 题材：四大僵尸始祖之一·赢勾，黄泉守将。鬼面具（召唤物"鬼面具"）、掉落"鬼牙"刀与镇魂棺材钉——形象为青面獠牙的鬼王面具，额烙金"王"字，左右各悬一柄锯齿冥刃（YingouHand 贴图实为巨刃）。

## 1. 现状诊断

1. **无血量阶段结构**：六个"阶段"按计时器固定轮播（PatternSetA→SpiralDread→SaberHell→FrenzyDash→BladeScatter→RecoverDash→循环），第一分钟即见全部内容，低血量无任何新招——没有"扣押内容"，战斗没有未来可期待。
2. **三大演出节拍缺二**：无死亡演出（直接暴毙）、无换阶段演出（没有阶段可换）；入场仅"漂入+粒子+吼"，缺静止拍与世界反馈。
3. **全程平铺噪声**：ProcessAggressiveActions 每 20~35 tick 无差别插入手部花活，贯穿所有阶段，压迫与呼吸无波形；且手部 `NPC.damage = 0`，所有近身"侵略动作"实际零伤害——看着危险实则装饰，读感混乱（伤害窗口与视觉完全不对齐）。
4. **手部运动失重**：全程 `Center += (desired-Center) * k` 软跟踪（k=0.15~0.7），无弹簧延迟、无反向蓄势、无收招过冲与余摆；斩击主体用 SineInOut——没有 poly(8+) 快照，"挥砍"读作"漂移"。
5. **速度无对比**：FrenzyDash 预告悬停角度全随机（可悬在玩家正下方 720px 甚至屏幕外发动），冲刺 32px/f 持续 45f 仅 ×0.987 缓减——持续中速而非瞬时爆发+硬刹。
6. **多人隐患与死代码**：YingouHand.ProcessRingCast 未做 netmode 判定直接 NewProjectile（客户端幻影弹、伤害硬编码 220）；handPlayer 抓取直接改写玩家位置（因手部 damage=0 实为不可达死代码）；pending* 标志、aitype、seed/random、FlowerySlash/ThrustCombo/DefensiveSwirl/AggressiveLunge、Pattern_RotatingBlades 的 localAI 后设（MP 不同步）等大量死代码/坏代码。
7. **已有可保留资产**：V2 预警词汇（ArenaRunic 地纹环、DrawBeam 预告线、RadialBloom 高潮泛光、ScreenSystem 冥刃染屏）方向正确；SaberHell→SaberKiller"预告线→真刃回扫"的线阵机制颇有特色，值得升级为高光素材；尸火弹的螺旋→减速→追踪三段个性可留。

**力度判定**：核心编排、运动质感、阶段结构均不达标 → **全面重做** AI 编排与手部运动系统，保留并升级 V2 预警词汇、刀阵机制与全部对外契约（类名 / 掉落 / downed 标记 / YingouSky 注册 / SaberKiller 与玩家武器 SaberHellFriendly 的行为契约）。

## 2. 设计主题与幻想感

**"黄泉守将·万刃冥王"——一场对决，从"双刃剑客"升格为"万刃归宗的冥将"。**

- 面具是"心"：不动如渊，只在出招时前倾、后仰、侧目——所有重量感从面具的微小反应里来。
- 双刃是"意"：两柄锯齿冥刃以弹簧延迟追随、蓄势时反向收拢、出鞘一瞬 poly(20) 快照、收招余摆——玩家全程围绕"读刃"作战。
- 世界是"渊"：黄泉夜幕（青灰→血红随阶段加深）、鬼火升腾、裂隙开阖（出场自裂隙来、死亡归裂隙去）。
- 体验曲线：P1 精准对决（读线躲刃）→ P2 冥阵压场（刀阵图案+夹击+追猎）→ P3 万刃归宗（全屏刀气风暴与巨刃总劈）→ 死亡：双刃先折、面具引颈、白帧定格、坠入裂隙。

配色纪律（TelegraphColors）：鬼火青绿 + 幽紫为主题色，金为高潮色，**红只出现在即将造成伤害的预警终段与伤害源本体**。

## 4. 招式编排表

时长均为 60fps 帧数；专家/大师缩短前摇 ~10/18%、增加弹幕密度。**红=致命预警只在预告终段出现；所有接触伤害严格门控在爆发帧窗口。**

### A1 CrossLunge 双刃剪杀（P1 起，2~3 循环/次）
- 前摇 44f：双刃飞至玩家两侧翼 470px（弹簧到位），刃口对准玩家预测点；末 12f 沿瞄准线 pow⁸ 反向收拢 150px（"吸气"）；双细预告线蓝→红渐变贯穿玩家；发动前 36f 定拍提示音。
- 爆发 8f+6f：双刃相隔 6f 先后瞬发（92px/f 直线，无转向），轨迹在玩家处交叉成剪；接触伤害仅在速度 >26px/f 时开启；发射帧震屏 5 + 刃光波。
- 收招 34f：×0.72/f 硬刹，角速度冲量余摆衰减归鞘。
- 公平阀：预告线 ≥44f 可读；安全方向=沿面具-玩家轴向；固定 470px 起手距离防贴脸。

### A2 CorpseFan 尸火喷吐（P1 两轮，P2+ 三轮+环）
- 前摇 50f：面具悬于玩家上方 300px，沿远离玩家方向 chargeT²×200px 后仰蓄力；鬼火粒子收束（密度 ∝√charge，76% 处停——嘶吼前的静默）；面具鳞片式放大 1→1.1。
- 爆发：50/66/82f 三轮扇形尸火（7+难度加成，17~22px/f，交替螺旋方向），每轮面具反冲 11px/f + 震屏 4；P2+ 在 96f 追加 10 发环形慢弹（区域封锁）。
- 收招 34f：漂移复位，双刃缓慢护旋（存在感，非压迫）。

### A3 IaiLine 居合·一文字（×2 交替侧）
- 前摇 42f：单刃裂隙闪至玩家侧方 640px、锁定当帧 Y 线（预告即锁线，垂直位移即可躲）；全线蓝→红预告线；刃 pow⁸ 反拉 170px；另一刃留守护面（一压迫一存在）。
- 爆发 10f：沿线 118px/f 居合直斩，接触伤害开，速度门控拖尾/残影全开，震屏 5。
- 收招 24f：减速后裂隙闪回归鞘（闪点双端裂隙光斑掩护）。
- P2+：斩线中点垂直散出 4 发慢尸火。

### B1 ViceClamp 冥狱合葬（P2 起）
- 前摇 58f + 静默 8f：双刃裂隙闪至玩家两侧 560px（水平/垂直轴交替，锁定发动帧圆心），刃口相向；两刃间预告梁增厚蓝→红；地纹环 420→170px 收缩倒计时；隆隆震感 ∝charge²；末 8f 粒子截断、梁光微暗（爆前收势）。
- 爆发 ~12f：双刃 88px/f 相向合拢，穿过后 200px 减速；交会处刃鸣爆发（径向泛光+震屏 8+沿夹击轴 4 发尸火飞散——垂直逃逸方向保持安全）。
- 收招 54f：穿过余摆归位。
- P3：连夹两次，第二次轴向旋转 90°、前摇缩至 46f。

### B2 BladeMatrix 万刃冥阵（P2 三图案，P3 四图案）
- 面具升至玩家上方 360px 重阻尼稳悬（重图案期间少移动——防廉价撞击）；双刃举于面具上方结印绕环。
- 每 85f 释放一个图案（洗牌袋防重复；转场后首图案速度 ×0.75 渐升）：环阵收束 / 十字扫线 / 辐射回扑 / 波状点射——全部走 SaberHell 既有"40f 红线预告→SaberKiller 真刃回扫"机制（预告经 ai[2] 延迟参数同步，修复旧版 localAI 后设的 MP 不同步）。
- 每图案释放帧双刃外弹反冲 + 震屏 4~6。

### B3 FrenzyPursuit 狂暴追猎（P2 三段，P3 四段）
- 每段：裂隙闪至玩家远侧 760px（水平偏置 ±0.45rad，闪出闪入双端光斑掩护；闪现后 8f 无伤宽限）→ 预告 32f（面具→玩家预测点红线渐浓、pow⁸ 反拉 130px、定拍提示音）→ 冲刺 10f（112px/f 瞬发直线，接触伤害速度门控 >30px/f，残影/拖尾仅此窗口开启，震屏 6）→ 硬刹 14f（×0.66/f，双刃松弹簧甩过面具再荡回——次级运动主秀）。
- 传送循环剪掉"飞回"死时间；裂隙闪现即距离栓绳。
- P3：每段冲刺中点掷 2 发螺旋尸火。

### C1 BladeStorm 万刃归宗（P3 签名招，~420f 单次）
- 聚势 80f：面具居中上位，双刃结印；地纹环 0→880px 金→红展开为风暴边界；隆隆 ∝charge³；粒子收束 76% 截断。
- 刀环 240f：12(+2 专家) 柄冥刃绕玩家 540px 成环公转，**错列延迟**（ai[2]=-(50+i×14)）依序脱环收束→各自 40f 红线预告→SaberKiller 真刃依节奏回扫——有节拍的塌缩，可逐线阅读。
- 终章 60f：中心泛光 + 12 辐辐射回扑收尾，震屏 8。

### C2 NetherCleave 黄泉三裂（P3）
- 双刃飞至面具前**合璧成巨刃**（叠绘+刃晕条带）；每裂：预告 46f（贯穿玩家的粗红线、巨刃收势缩 8%——变小再变响）→ 总劈 10f（双刃同线 105px/f，巨幅 SlashBurst 刃光，震屏 8）→ 回收 26f。
- 三裂角度：对准玩家 → ±120° 旋转；裂间 25f 呼吸。
- 收尾双刃弹性分离归位。

### 连接拍 Reposition（≤60f）
- 面具滑向玩家侧上方 340×230px 悬点（速度转向式移动，非位置贴附）；双刃归鞘轻响；到位（<120px）即早退进下一招。

## 5. 入场 / 换阶段 / 死亡三大演出脚本

### 入场 Intro（200f）
1. 0~70f：玩家上方裂隙撕开（YingouNetherRift 贴花 0→1），面具自"深处"贴脸飞来（fake-Z：scale 0.25→1 三次方曲线、透明度渐显），鬼火自隙口倾泻，黄泉夜幕开始渗入。
2. 70~130f：**静止拍 60f**——面具悬停呼吸（±1.5% 缩放），76/96f 两柄冥刃先后自裂隙横刺而出（ElasticOut 过冲），悬于面具两侧。威慑主要是静止。
3. 130f：双目暴亮 + 低吼 + 震屏 12 + 金色径向泛光；裂隙塌缩。
4. 130~180f：双刃同步一记归鞘挽花，面具落位；180f 入 P1。全程玩家无伤、Boss 短无敌（130f 前）。

### T2（70%，150f）
清全部敌方弹幕 → 面具锁停低吼，双刃回收绕面急旋（角速 0.05→0.5 三次方升）→ 天幕转沉、隆隆渐强 → 100f 冲击释放：环形冲击波视觉 + 泛光 + 震屏 10，双刃 ElasticOut 弹回护位 → 150f 入 P2（首图案速度阀 0.6→1/90f）。演出期短无敌。

### T3（35%，170f）
清弹 → 面具震颤、裂纹燃金（40f）→ 天幕血色拉满、六道幻影刃晕自面具后扇形展开（P3 常驻标识）→ 120f 全屏白闪 8f + 震屏 11 + 额上"王"字燃金（StarTexture 加性）+ 高吼 → 170f 直入 BladeStorm（P3 开幕陈述）。

### 死亡 Death（~300f，CheckDead 拦截）
1. 0~70f：双刃飞离失控、悬停一拍，**相隔 26f 先后碎裂**（白闪+EmberShards 尘爆+震屏 6，手部 NPC 就此退场）。
2. 70~180f：面具缓缓上浮，DissolveBurn 裂纹灼烧 0→0.45；**警报音手调加速数列**（22,18,15,13,11,9,8,6,5,4f 间隔、音高渐升，十响全落窗内）；天幕红度封顶、隆隆 ∝t²；粒子向面具收束（吸气）；背后裂隙渐开。
3. 180~192f：**爆前静默**——一切粒子截断，面具收缩至 0.88 余弦闪烁。
4. 192f：**白帧定格 12f**（全屏白 + 面具黑剪影）+ 震屏 14 + 深吼——全场唯一一次 impact frame。
5. 192~290f：面具被拽入裂隙，DissolveBurn 0.45→1，鬼火螺旋外涌，裂隙三次方塌缩。
6. 290f：裂隙咬合，终末小泛光；真实死亡结算（掉落/downed 标记照常）。

## 7. 性能与多人预算

- **同步纪律**：Phase/PhaseTimer/cycleIndex 走 npc.ai[]；轴向、侧别、冲刺角、图案索引等服务器随机 → SendExtraAI 同步；手部姿态完全由 Boss 已同步态确定性推导（Boss whoAmI < 手，帧内先算后用），不额外发包。弹幕仅 `!MultiplayerClient` 生成（修复旧 RingCast 幻影弹）；SaberHell 轨道延迟改经 ai[2]（出生同步）传参，修复旧 localAI 后设 MP 不同步。
- **视觉状态全客户端本地**：染屏/泛光/贴花强度衰减驻留 Draw 路径；服务端零绘制。
- **性能**：着色器/噪声静态缓存一次；条带顶点每刃每帧 ≤ 60；全屏后处理走 RequestFullscreenSlot 名额（径向泛光内建）；染屏 overlay 不读 screenTarget 不占名额；粒子峰值 ≤ 现版（删除了全程侵略粒子噪声）；无每帧 LINQ/new 纹理。
- **弹幕上限**：风暴期 12~14 SaberHell + ≤24 尸火；其余时段显著低于现版。
