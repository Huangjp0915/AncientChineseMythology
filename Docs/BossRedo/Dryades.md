# 树精 Dryades 重做设计文档（Boss 重做工程 V3）

> 单元：`Celestias/Boss/Dryades/`（天界 Boss，进度位 35：毗沙门天 → **树精** → 大椿）
> 题材定位（以 hjson 为准）：`Dryads.DisplayName` = 树精 —— 山林老树成精的"树母/木灵"。
> 主题一句话：**缠绕与蔓延** —— 阴柔、耐心、从脚下与四面八方缓慢收紧的压迫。
> 与大椿（Dazheng，四季巨树 + 结界法阵 + 治疗导管）差异化：树精是**潜地伏击者 + 藤鞭 + 孢子蔓延**，
> 不做季节、不做结界圈、不做"拉线挣断"式治疗——治疗反制改为**可击杀的汲魂灵芽**（打靶式反制）。

## 1. 现状诊断

以 choreography skill 七大本能与失败模式清单为透镜：

1. **本体完全失重（本能 #3 全灭）**：`NPC.velocity = Vector2.Zero` + 位置钉死锚点，单帧贴图零旋转零缩放。
   出招时躯干纹丝不动——攻击"无因而果"（本能 #4：玩家看不到攻击从身体发出）。无呼吸、无前倾蓄势、无冒出后坐。
2. **藤蔓没有"鞭子"**：DryadsVine 是直线飞行的荨麻贴图弹。植物 Boss 的招牌武器（破土预警 → 藤鞭甩击、
   分段弹簧节点鞭物理）完全缺失。
3. **招式表过薄、后期无扣留内容（PACING §1 违例）**：地表只有 RootBurst / SpikeField 两招确定性交替，
   P2 = "P1 + 毒孢区"。1M 血量下十分钟全是同一循环，低血量没有任何新东西可期待。
4. **三大演出节拍缺 2/3**：入场（尘土+震屏）尚可但无着色器时刻；换阶段只有 80 帧尘土收束；**死亡演出完全没有**
   （OnKill 一记镜头 punch 直接掉装备）。
5. **既有 bug/公平性问题**：
   - RootBurst 用 Boss 锚点的地表线近似玩家地表线——坡地上根须从错误高度喷涌；
   - SpikeField 的 `fieldGapAngle += Main.rand...` 在各客户端各自随机 → 安全辐条视觉可能与服务器判定短暂错位；
   - 潜地上升期间接触伤害未关（预警圈外沿站位仍可能被"贴脸怼"）。
6. **视觉全靠共享件**：ArenaRunic 地纹 + ElementalScreenTint 染色，无一个专属着色器；"疯长/蔓生"的幻想
   （绿意吞噬画面）没有落地。

结论：保留"潜地伏击 + 冒出点预警 + 刺球领域 + 毒孢区烧除"这些已验证的好骨架，**全面重做**动作编排、
藤鞭武器、阶段递进、三大演出与专属视觉。

## 2. 设计主题与幻想感

玩家应体验到：**"大地本身在猎杀你"**。树精不追人——她把战场变成她的身体：
脚下随时会裂开（潜地冒出）、地面会长出鞭子抽你（藤鞭）、你站过的地方会烂掉（毒孢区）、
她受伤越重，绿色从屏幕边缘爬进来越深（疯长蔓延）。压迫是阴柔的、持续的、包围式的，
对比大椿的堂皇四季轮转与玄武的重甲工事感。

三条体验支柱：
- **伏击张力**：她一半时间不在场（潜地）。地纹预警 = 心跳加速的读秒。
- **鞭的暴力美**：长蓄势（背挥高高扬起）→ 一瞬抽落（poly(10) 甩击 + 鞭梢炸响）→ 余摆下垂。整个重量感来自波形。
- **蔓延的窒息感**：屏幕边缘 SDF 卷须随血量/事件生长，毒孢区明确边界 + 缓慢扩张，低血量"万藤缠狱"全屏收拢。

## 3. 阶段结构与血量断点

| 阶段 | 血量 | 内容 |
|---|---|---|
| 入场 | — | 地面震裂 → 破土而出（240f，保留并补身体挤压/摆动与泛光时刻） |
| **P1 潜行猎手** | 100%→50% | 循环：潜地 → 地表窗口（表：根须爆发 → **藤鞭横扫** → 刺球领域）→ 潜地… |
| **P2 蔓生** | 50%（一次性转换演出 ~150f） | 潜地留毒孢区；藤鞭 3 连；根须双向夹击；刺球双辐条；每轮循环种一株**汲魂灵芽**（治疗反制） |
| **疯长（P2 内递进）** | <25%（无演出暂停，播报+屏幕事件） | 循环表首位插入**万藤缠狱**（冠层放射鞭阵 set-piece + 力竭破绽窗） |
| 死亡演出 | 0 | ~330f：凋萎 → 心跳加速龟裂 → 收束吸气 → 爆裂returning-to-earth（唯一 shake 16 时刻） |

确定性循环表（PACING §2 手工编排，非随机）：
- P1：`[根须爆发, 藤鞭横扫, 刺球领域]`
- P2：`[藤鞭横扫×3, 根须爆发(夹击), 刺球领域(双辐条)]`
- 疯长：`[万藤缠狱, 藤鞭横扫×3, 根须爆发(夹击), 刺球领域(双辐条)]`

每个地表窗口前后必有一次潜地转移（呼吸拍 + 重新站位），压迫-喘息交替天然成立。

## 4. 招式编排表

时长均为 60fps 帧。红色只在"即将造成伤害"时出现（TelegraphColors 契约）。

### 4.1 潜地转移 Burrow（核心节拍，保留升级）
- 下沉 50f（P2 40f）：树根可见回抽 + 身体下压挤压（squash），无敌；P2 在旧锚点释放**毒孢区**
  （~11s，前 4s 半径 150→210px 缓慢扩张，同屏 ≤3）。
- 地下 85f（P2 65f）：**移动根瘤**——沿地面一条尘土隆起从旧锚点爬向目标点（行踪可读）；
  末 60% 时间在冒出点画 ArenaRunic 根纹圈（绿 → 末段转赤红=致命）。
- 冒出 45f（P2 38f）：back-out 过冲 + 挤压回弹（squash 弹簧），径向泛光闪；上半扇根须飞梭 6/9 枚
  （有重力弧线）+ 刺球陷阱 4/6 枚散布；**上升期间接触伤害关闭**（新公平阀）。
- 收招 25f → 进地表窗口。

### 4.2 根须爆发 RootBurst（升级：行军波）
- 前摇 20f（音效 + 树身前倾）。
- 3 波（P2 4 波），波距 44f：每波 4-5 根**根须柱**从"树精 → 玩家方向"逐波行军推进（波心距 260+w×170px，
  根间距 ~95px）；P2 加反向第二列从玩家身后夹击（半波错相）。
- 每根柱：30f 光束预告（翠绿升起，末 25% 转赤红）→ 8f poly(6) 破土速升（280/340px 高）→ 40f 持续（摆动）
  → 16f 凋落。伤害窗严格 = 竖起期间，判定为根基→顶端线段。
- **每根柱在自己 X 坐标下方采样真实地面**（修复坡地 bug）。
- 公平阀：预告 30f；波间 44f 空隙；行军方向开招即读（第一波位置暴露方向）。

### 4.3 藤鞭横扫 VineLash（新·招牌）
分段弹簧节点鞭物理（16 节 × 34px ≈ 544px 展长），角度链：`angVel[i] += (angle[i-1]-angle[i])*k_i; ×0.85 阻尼`，
根角 α(t) 驱动全鞭，纯确定性（各客户端一致）。
- 服务器在玩家两侧地面选根点（距玩家 ≥170px，≤420px），P1 两根（延迟 0/30f），P2 三根（0/26/52f）。
- 单鞭周期：破土冒芽 12f（根点裂土尘 + 芽升）→ **背挥蓄势 40f**（甩向反方向高高扬起，二次曲线；
  末 27f 沿抽击平面画细红导引线渐显）→ **抽击 9f**（poly(10) ease-out 甩过 ~2.5rad，鞭梢速度爆表，
  梢半段才有判定）→ 定格 8f → 余摆回收 42f（弹簧下垂震荡）→ 缩回地下 16f。
- 抽击瞬间：鞭梢炸响（Item153 鞭声）+ 梢部叶屑爆 + 震屏 3。
- 公平阀：判定仅抽击+定格 17f 且仅鞭梢 8 节；背挥方向 = 抽击反方向（身体语言预告）；导引线红色仅末 27f。

### 4.4 刺球领域 SpikeField（保留升级）
- 保留：收缩刺环 + 安全辐条（翠玉光束）单一规则。
- 升级：辐条旋转量确定性（`±(28°+w·3°)`，方向由 attackCycle 奇偶决定，消灭客户端随机）；
  每波生成时环位尘圈闪现（读出"从哪里来"）；P2 双辐条（对置，半角 22°）；刺球加辉光核。

### 4.5 万藤缠狱 VinePrison（<25% 扣留内容，set-piece）
- 0-50f 拔根蓄势：播报「万藤缠狱」，开台清残弹（刺球/根须弹，毒孢区保留），树身深后仰，
  四方尘埃向树冠收束，屏幕边缘卷须（Overgrowth 着色器）攀升。
- 51-434f 放射鞭阵：**16 记冠层藤鞭**按 45° 步进顺序甩出（每 24f 一记，第二圈错相 22.5°，
  全阵恒顺时针），每鞭自带背挥+导引线预告；同时笼缘（±620px 高空）飘落带毒孢叶。
  应对法：顺旋转方向"跟着钟摆走"。
- 434-540f 凋垂：末鞭余摆收完（~538f），全场归静。
- 540f 起 **力竭破绽窗 100f**：树身前倾瘫软，播报「力竭」，受到伤害 ×1.25（唯一增伤窗），
  无任何攻击——最大压迫紧接保底喘息（波形收束）。疯长阈值触发时循环表指针归零，
  下一个地表窗口即为本 set-piece。

### 4.6 汲魂灵芽 SiphonBud（P2 治疗反制）
- P2 每轮循环表开头的潜地冒出时，在冒出点侧后地面种一株灵芽（ModNPC，血量=树精 2% 上限，无接触伤害，全场 ≤1 株）。
- 存活期间：可见翠绿汲取光束连向树精，每秒回复树精 0.35% 上限血（吃满 12s ≈ 4.2%，回血上限封顶 49% 防相位回退）。
- 击杀 → 汲取中断播报 + 爆浆粒子 + 树身痛苦摆动（打断反馈）；12s 后自行缩回土中。
- 与大椿"冲刺挣断导管"差异：树精版是**转火打靶**的 DPS 权衡题。

## 5. 入场 / 换阶段 / 死亡三大演出脚本

### 入场（240f，保留结构 + 增重）
0-50 地面震裂（渐强震屏 1→5，木屑+绿光尘）→ 50-170 破土上升（三次方缓动，behindTiles）→
170 **爆发帧**：挤压冲击（squashVel -0.22 弹簧回弹）+ 侧倾摆动衰减 + 径向泛光 + PunchCamera 16 + 双吼 →
170-210 余波绿尘 → 240 战吼入战。

### P2 蔓生转换（150f，替换旧 80f）
0-30 定身 + **全场清弹**（公平阀）+ 尘埃向躯干收束 → 30-90 **三记心跳**（30/58/80，间隔递减）：
每记 = 低沉闷响 + 躯干挤压脉冲 + 屏幕边缘卷须泛起（Overgrowth uPulse）→ 90 **绽放帧**：播报「蔓生」、
12 枚灵叶放射、径向泛光、震屏 11、防御+15/伤害×1.2 → 90-150 灵叶飘落收势（120f 前无敌）→ 150 潜地（开始留毒孢）。

### 死亡演出（~330f，CheckDead 拦截）
0：锁血 1、无敌、清弹清芽、低吟 → 0-60 凋萎启动（贴图向枯褐插值，辉光转暗）→
60-200 **五记心跳加速**（60/100/134/160/180）：每记闷响 + 挤压脉冲 + 躯干亮绿裂纹（SlashBurst 加性裂片）+
震屏 3→6 递增，屏幕卷须逐记退潮 → 200-250 收束吸气：生命光尘被吸入躯干（比例拉拽），躯干缓慢压低，
**末 18f 全粒子静默**（爆前留白）→ 250 **爆裂帧**（全场唯一大时刻）：径向泛光满强 + 震屏 16 + 木屑喷泉 +
升天绿魂光尘 → 250-320 躯干淡出、光尘归天 → 322 真死（掉落/downed 照常）。

## 6. 视觉技术方案

新建专属着色器（全部 ps_3_0，Dryads 前缀，在各自消费者代码内 `ModContent.Request` 静态缓存，不进 ACMShaders）：

| 着色器 | 用途 | 技术 |
|---|---|---|
| `DryadsVineRibbon.fx` | 藤鞭/根须柱 TriangleStrip 条带 | s0 共享噪声；沿长树皮纹带 + 汁液流光 + 边缘暗沿 + uTipGlow 鞭梢高亮 + uWither 枯萎褪色 |
| `DryadsSporeField.fx` | 毒孢区贴地декal（替换 ArenaRunic 用法） | 屏幕空间扁椭圆域：漂浮孢子点场（三层噪声阈值点）+ 边界膜辉 + 顶面冒泡 + uBurn 烧除焦蚀 |
| `DryadsOvergrowth.fx` | 全屏"疯长"覆盖（边缘卷须生长） | 自包含程序噪声：四边 SDF 卷须指状生长（uIntensity 控深）+ 叶脉纹 + 生长尖端亮缘 + uPulse 心跳 + uWither 死亡枯化 |

复用共享件：ArenaRunic（冒出点预警圈，保留）、BeamGrad/DrawBeam（安全辐条、根须预告、鞭导引线、汲取光束）、
RadialBloom（冒出/绽放/爆裂）、ACMAsset.SoftGlow/SlashBurst/Sparkle（辉光/裂纹/灵芽花瓣）。

绘制升级：
- 本体改为**基点变换绘制**（origin=树根着地点）：倾斜弹簧（lean）绕根摆动、挤压弹簧（squash，保体积 X 反向补偿）、
  呼吸 0.5Hz；冒出/心跳/受击都打弹簧冲量——"质量即反应"。
- Overgrowth 覆盖走 `DryadsOvergrownSystem.Publish()` 发布-订阅（照 Suzaku/Dazheng ScreenSystem 模式），
  PostDrawTiles 自开合批 overlay，不读 screenTarget、不占全屏名额，受 `MythologyConfig.FullscreenShadersEnabled` 降级。

## 7. 性能与多人预算

- **多人安全**：状态全在 `ai[0..3]` + SendExtraAI（新增 deathStarted 一项）；切换处 `netUpdate=true`；
  弹幕/灵芽仅服务器生成；鞭子节点物理为**确定性函数**（无 Main.rand 参与模拟，弹簧链由同步的 ai 参数 +
  本地计时驱动，各客户端一致）；`Main.LocalPlayer`/Publish/尘土只在非服务器路径。
- **性能**：三个 Effect 静态缓存一次；鞭同屏 ≤8（生成前计数）；毒孢区 ≤3（杀最旧）；根须柱每波 ≤5；
  节点数组按弹幕实例固定分配（16 节），无热路径 LINQ/每帧 new 纹理；全屏 overlay 强度 <0.01 直接 return；
  RadialBloom 走名额契约（DrawRadialBloomAt 内部仲裁）。
- **公平**：预警时长按 TelegraphTicks 档位；上升/潜地接触伤害关闭；换阶段/死亡清弹；每状态有超时保底出口；
  伤害窗与视觉严格对齐（鞭=抽击 17f 梢半段、根柱=竖立线段）。
- **进度**：掉落表（活木 45-60）、`downedDryads`、召唤途径（SoulBanner 35 位）不动。
