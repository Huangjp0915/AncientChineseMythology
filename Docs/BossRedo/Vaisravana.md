# Vaisravana（毗沙门天王 / 北方多闻天王）重做设计文档 · V3

> Boss 单元：`Celestias/Boss/Vaisravanas/`，天界线终局门控 Boss（T35，月后级）。
> 参照：`_SHARED_BRIEF.md` 流程 §3；choreography skill 七大本能；质量标杆 Xuanwu / Dazheng。

---

## 1. 现状诊断

以七大本能与失败模式清单为透镜：

1. **失重的悬浮炮台（本能 #1/#2/#3 全缺）**：所有招式的移动都是 `Vector2.Lerp` 悬停在玩家上方 300~380px，全程没有一次冲刺、一次反冲、一次架招。攻击=悬停+生成弹幕，"武神"读感为零，更像挂在天上的炮塔。
2. **前摇同质化、蓄力语法缺失（本能 #4）**：所有前摇都是 `velocity *= 0.9f` + 几粒尘埃标线（26~55f）。没有汇聚粒子、没有爆发前静默、没有姿态变化，预警可读性差（尘埃线在弹幕海里几乎不可见）。
3. **三大演出节拍残缺（本能 #7）**：入场是 180f 的 lerp 下降 + 两声音效；换阶段只有 dontTakeDamage + 塔转快点 + 尘埃；**死亡演出完全没有**（OnKill 里只有一次镜头 punch）。世界层反馈只有金幕 tint。
4. **枢纽期空转（PACING §9 自检失败）**：Hub 悬停 130~150f，期间只有每 46~50f 一发塔点射——每轮攻击之间都有 2 秒以上"无事可做"的非刻意空窗；Boss 可见地在等自己的计时器。
5. **视觉资产错配**：Boss 战中的四座"宝塔"用 BlankStar 占位星绘制，而专用贴图 `VaisravanaTower.png` 只给了掉落物用；本体无任何专属着色器（仅 ScreenSystem 借用共享件）；无金身质感、无法相演出。
6. **保留价值**：宝塔充能 + 赐福窃取（玩家贴塔偷充能转化安全变体）是好的签名机制；夜叉四方锚点 + 杀序解锁安全道设计合理；三阶段脚本化 A/B/C 三幕轮替结构成立。掉落 / downed 标记 / Items 子系统完善。

**重做力度判定：全面重做 AI 动作编排与视觉（保留签名机制骨架、弹幕类型与掉落），补齐死亡演出，新建 3 个专属着色器。**

## 2. 设计主题与幻想感

**「北天镇库 · 托塔天王」——威严的护法武神，不是妖兽也不是炮台。**

给玩家的体验：面对的是一位**不动如山的战神**。他不追着你满屏飞——他**镇压**你：

- **天王步**：不飘移，要移动就是一步跨出——长架步（金刚沉腰蓄势）→ 雷霆一步（瞬时 46px/f）→ 落地震山（硬刹 + 震屏 + 贴地地波）。每一步都是威慑。
- **宝塔**：镇压法器。塔悬顶环绕、塔光柱镇压区域（"托塔"与"放塔"）；玩家依然可以贴塔窃取赐福（风险换安全变体）。
- **宝伞**：格挡反击姿态——伞盖张开时输出被"劫财反震"，玩家该收手走位。
- **金刚怒目式蓄力**：大招全部是"长架招（汇聚金光、震屏渐强）→ 爆发前一拍静默 → 一击必杀式释放"。
- **佛光视觉**：琉璃金 + 暖白；专属佛纹坛城法阵（莲瓣 + 法轮 + 梵纹环）作为一切大招的地面语言；金身 rim-light 法相质感；换二阶段"显三面六臂法相"变身演出。

## 5. 入场 / 换阶段 / 死亡三大演出脚本

### 入场「天王降世」（180f）
- 0~40f：金幕渐亮（ScreenSystem goldTint 脉冲）；高空金点以 fake-Z 从背景放大逼近（scale 0.1→0.55，cubed）。
- 40~70f：俯冲落场（cubed 收敛），70f 触地拍：震屏 14、金尘环、脚下 mandala 法阵弹性展开（0→420px）。
- 70~130f：**静止凝视 60f**（威严=静止；光轮缓亮，无任何攻击）。
- 130~180f：四座宝塔从身后金光中依次升起就位（每 12f 一座、音阶递升、各带金闪），180f 光轮全亮 + Roar + 金幕脉冲，入战。

### 转阶段 2「显三面六臂法相」（120f，i 帧 + 清弹）
- 0~30f：清弹、定身、金光向体内收拢（吸气）。
- 30~78f：法相展开——本体后方两层旋转虚影（×1.35/×1.7 加性金身）+ 六道臂光从身后扇形展开 + mandala 全阵点亮 + 塔满充能。
- 78~90f：静默收缩（爆发前一拍）。
- 90f：金环冲击波（纯视觉）+ 震屏 12 + Roar + goldTint 跳升。
- 90~120f：缓出 → 夜叉召唤。

### 转阶段 3「库藏开启」（110f，i 帧 + 清弹）
- 0~35f：定身收光；35f 钟声（Item119）。
- 35~70f：身后展开巨型 mandala"天库之门"（ScreenSystem rune 全开 + 金雨粒子上升）。
- 70f：ForceRoar + 震屏 12 + 金幕拉满脉冲。
- 70~110f：缓出 → 金环收束 A 幕。

### 死亡「金身崩解」（CheckDead 拦截，260f）
- 0f：清弹清夜叉、无敌、伞收。
- 0~60f：升至玩家上方定身；光轮高频闪烁失稳、塔轨道紊乱抖动。
- 60~160f：四塔每 25f 一座熄灭爆散坠落（音阶递降）；金身开始龟裂（GoldBody shader uCrack 0→0.7，裂缝发金光）；金尘密度∝进度。
- 160~200f：本体收缩至 40%（cos 颤闪），**一切粒子硬切静默 40f**，只留金幕拉满。
- 200f：金光大爆——白闪 impact frame（全场唯一一次）、震屏 18（全战最大）、mandala 全屏扩散。
- 200~260f：金尘飘散、金幕缓落；260f 真死 → OnKill 掉落照常。

## 6. 视觉技术方案

### 新建专属着色器（Vaisravana 前缀，ps_3_0，Boss 代码内 ModContent.Request 静态缓存，不进 ACMShaders）
1. **`VaisravanaMandala.fx`** — 佛纹坛城法阵（屏幕空间 decal，s0=共享噪声）。层次：中心光核 → 内环梵纹带（反向旋转） → 八辐法轮 → 莲瓣圈（`cos(angle*petals)` 花瓣 SDF） → 外双环 + 符文点阵。`uReveal` 参数支持"逐圈点亮"（蓄力）与"扩散冲击"（落地/爆发）。取代 ScreenSystem 里对共享 ArenaRunic 的调用，成为 Boss 一切大招的地面语言。
2. **`VaisravanaGoldBody.fx`** — 金身光相（本体贴图 pass，s0=本体，s1=噪声）。alpha 边缘 rim 金光 + 体内金纹流动 + `uFlashWhite` 白闪（受击/爆发）+ `uCrack` 龟裂发光（死亡演出：噪声阈值裂缝→发光→挖洞）。
3. **`VaisravanaPillarBrand.fx`** — 宝塔镇压光柱 / 天光垂落（世界矩形绘制）。横向过曝核 + 纵向上升金纹流动 + 底座亮环；`uTelegraph` 两态：预告细线脉冲 / 爆发全宽。

### 复用共享件
- `ACMShaders.DrawBeam`（塔齐射预告线、破军矛路径、镜轴、金环安全道、终极金柱主体保留）；
- `ACMShaders.DrawRadialBloomAt`（占名额的金爆点，仍仅终极金柱与破军出手两处、互斥出现）；
- `ElementalScreenTint` / `RadialBloom` 走既有 ScreenSystem 三 overlay（非 screenTarget，不占名额）；ScreenSystem 增加"白闪"通道（死亡 impact frame 用 ElementalScreenTint 白色大 coverage 一次性脉冲）。
- 宝塔改用专属贴图 `VaisravanaTower.png` 绘制（塔身 + 塔底 SoftGlow + 充能格）。
- 三面六臂法相：本体贴图双层旋转加性虚影 + 六臂光轮（Sparkle/LightShot 组合），仅演出与 P2/P3 常驻低强度。

## 7. 性能与多人预算

- **着色器批次**：mandala decal 同帧 ≤2 次（脚下 + 演出）；光柱 shader 同屏 ≤8 根（天光垂落错峰生成）；GoldBody 本体 1 pass。全屏后处理仍只有 ScreenSystem 3 overlay + DrawRadialBloomAt 名额点，遵守 `RequestFullscreenSlot` 契约与 `MythologyConfig` 开关。
- **纹理/Effect 全部静态缓存**（Helper 内 `Asset<Effect>` 惰性 ImmediateLoad），Update/Draw 零 new。
- **粒子上限**：蓄力汇聚 streak 每帧 ≤6；死亡演出峰值帧 ≤40 dust。
- **多人安全**：弹幕/夜叉仅服务器生成；天王步落点 `dashTarget` 走 SendExtraAI 同步 + 每步 netUpdate；死亡演出由服务器 CheckDead 置 Phase=Death 后 netUpdate 广播，客户端本地跑视觉；`Main.LocalPlayer`/ScreenSystem 只在客户端路径；接触伤害门控用同步的 Phase/SubState 推导。
- **掉落/进度不回退**：ModifyNPCLoot / BossLoot / OnKill / downedVaisravana 原样保留；召唤方式与 Boss 清单兼容不变。
