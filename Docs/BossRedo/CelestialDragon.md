# 天御金龙 CelestialDragon — Boss 重做 V3 设计文档

> 单元: `Celestias/Boss/CelestialDragons/`（天界蠕虫型 Boss, 月球领主后, SoulBanner T42 召唤）
> 定位: **天界神龙 = 金辉 / 云海 / 天威**。与祖龙魂(幻彩残魂)、苍龙(风暴)明确区分。

## 1. 现状诊断

以 choreography skill 七大本能 + 失败模式清单为透镜:

1. **匀速追尾蠕虫病(本能#2 违反, 最重)** — `ApplyMovement` 把速度以 0.05 插值到 17~28 px/f 的常值并强制最小速度, 全程无停顿、无爆发、无刹车。俯冲 38 px/f 对巡航 25 px/f 只有 1.5× 对比, "速度是对比而非数值"完全缺席。
2. **入场/死亡演出缺失(PACING §6)** — 初始化只播一声吼叫, 龙凭空出现; 死亡只有 HitEffect 里一圈 dust + 震屏 16。三大节拍缺二。
3. **无充能语法、预警薄弱(本能#4)** — 所有攻击都是飞行中 `timer % N == 0` 直射, 没有前摇/收招波形; 唯一的路径预警是一串闪烁贴片, 无汇聚粒子、无发射前静默。
4. **招式波形平坦(本能#5)** — 巡天/剑气/敕令/环绕四个状态读起来完全一样: 远航点悬飞 + 周期发弹。没有一招结束时屏幕状态与开始时不同。
5. **龙身失重(本能#3)** — 体节被刚性钉在固定距离上, 无鞭链、无二次运动; 绘制只有平铺贴图 + 一层发光, 没有沿身体的金辉流光。
6. **航点距离过远(失败模式"飞出屏幕绕圈")** — 巡航航点横向 1400px + 纵向 870px, 1080p 视野下龙一半时间在屏幕外。
7. **视觉全靠 GoldFlame dust + 占位贴图**, 零专属着色器, 距玄武标杆(5 个专属着色器)差距明显。
8. **值得保留的好底子**: 三幕规则化轮替(非密度档)、敕令法标可破目标、天命赐福区风险回报、逆鳞拆弹、CelestialScreenSystem 金芒氛围骨架、TelegraphColors 规范、多人安全基本盘(ai[] 状态机 + netUpdate)。

**力度判断: 全面重做** AI 编排与视觉(保留上述机制概念与全部 public 类型), 目标对齐玄武水准。

## 2. 设计主题与幻想感

**"云海之上, 天威巡狩。"** 玩家在云海之上与一条真正有神圣威仪的金龙作战:

- **金辉**: 龙身有一条永不熄灭的金辉流光沿体节铺设(顶点条带着色器), 充能波沿身体行进, 死亡时化作万点金芒升天。
- **云海**: 屏幕下方与四周铺开程序化云海层; 龙破云俯冲时, 云层在穿透点被冲开一圈涟漪(着色器 punch 参数)。
- **天威**: 招式语言是"命令"而不是"扑咬"——腾云盘旋蓄势(长前摇画大弧), 破云俯冲(一瞬爆发), 口含龙珠蓄光(完整充能语法), 天光柱阵(天罚从天而降, 而非从龙口喷出)。
- 节奏感受: **仪式感的慢 → 雷霆般的快**。所有慢都是蓄势, 所有快都不超过 14 帧。

## 3. 阶段结构与血量断点

沿用三幕断点(存档/进度兼容), 幕间过场保留 i-frame 节拍并升级演出:

| 幕 | 血量 | 主题 | 招池(轮替表) |
|---|---|---|---|
| 入场 | — | 天光垂落, 金龙破云而降 | Entrance(一次性, 180f, 无伤害窗口) |
| Act0 巡天 (>60%) | 威仪巡逻 | 破云俯冲 ×2 → 剑气长虹 → 金鳞游曳 → 巡航喘息 | 循环 |
| Act1 敕令 (≤60%) | 天规压场 | 敕令法标(目标战) → 破云俯冲 ×2 → 龙珠·天光柱阵(5 柱) → 金鳞游曳 → 巡航喘息 | 循环 |
| Act2 天罚 (≤25%) | 最高权限 | 敕令法标(破标解锁天罚) → 连环破云冲(×3 连锁) → 龙珠·天光柱阵(7 柱) → [天罚·万剑归宗(解锁后插入)] → 强制喘息 | 循环 |

- 断点跨越瞬间: 清全部敌对弹幕(公平阀门), 进入 75f 过场(无敌 + 演出), 出场 40f 内无接触伤害且弹速 20%→100% 缓升。
- "扣留内容": 天光柱阵只在 Act1+ 出现; 万剑归宗只在 Act2 破标后出现一次/周期。

## 4. 招式编排表

通用公平阀门: 冲刺接触伤害仅在速度 > 24 px/f 时生效(伤害窗口=视觉窗口); 龙距玩家 > 2600px 时拴绳(带金闪的快速拉近, 非瞬移贴脸); 每状态必有完成出口 + 超时出口; 预警色严格 TelegraphColors(金=主题/安全, 红=致命)。

### 4.1 破云俯冲 CloudDive(招牌, 全幕)
- **前摇 75f (≈52%)**: 玩家斜上方 (±680, -640) 画弧蓄势, 速度 24→9 px/f SineInOut 递减(慢=可读); 头部汇聚金色流光粒子(velocity=(head-pos)×0.085); 发射前 30f 锁定俯冲线并生成红色路径预警(CelestialPathWarning, 30f 全红相); 最后 12f 反向抽身 `pow(t/12, 8) × 220px`(迟滞后仰——吸气); 发射前 6f 粒子全部切断(静默节拍)。
- **爆发 ≤24f (早退)**: 一帧 set 速度 64 px/f 直线(预测提前量 = 玩家速度×12, 上限 260px), 冲刺全程零转向; 残影(速度>34 门控)+条带满亮+震屏 6; 越过锁定点 380px 即提前进入刹车(早退计时)。爆发第 7f 向 ScreenSystem 发布 cloud punch(云被冲开涟漪)。
- **收招 ≤90f (超时保底)**: ×0.72/f 硬刹到 12 px/f 以下, 拉起回旋到另一侧, 到位即进入下一循环。
- 循环 ×2(Act2 连环版 ×3, 第 2/3 次前摇缩短到 45f, 远于 1000px 时以 42px/f 高速趋近替代飞回——删除死航程)。
- 阀门: 蜂鸣固定提前 36f(Item29 音调随循环递升); **伤害窗口=视觉窗口**: 头部接触伤害仅在爆发段且速度 >24px/f 时生效(CanHitPlayer 门控), 蓄势弧擦身零伤; 距玩家 >2600px(拴绳) 或 <380px(反贴脸) 时跳过爆发直接转收招。

### 4.2 剑气长虹 SwordSweep(Act0/巡航变奏)
- 8 字形航线但**速度调制**: 弧顶 11 px/f 缓行, 弧底 30 px/f 甩尾; 剑气扇面**仅在快段发射**(速度门控), 慢段完全静默——张弛都在一招之内。
- 体节涟漪: 快段时体节按 `(segIndex×8 + timer) % 90` 依次喷出低速金芒微粒(视觉), 弹幕波沿龙身滚动。
- 时长 300f, 出口: 计时完成。剑气 14 px/f, 预警=发射口 20f 金光聚焦。

### 4.3 金鳞游曳 CoilCharge(体节即机制, 重编排)
- 龙以收缩椭圆绕玩家盘旋(780→560px, 不完全闭合——头尾之间永远留 70° 逃逸缺口, 缺口位置用金白色(Safe)标出)。
- 充能波沿龙身头→尾行进(条带着色器 uChargeWave 可视化), 波过体节 +50% 接触伤害(保留); 波到尾端瞬间尾巴鞭甩(弹簧冲量), 甩出 2 枚逆鳞(保留拆弹机制)。
- 时长 360f; 每 90f 一波, 波前 30f 有渐亮预警 + 提示音(保留)。出口: 计时完成或玩家离开 1500px(反风筝早退)。

### 4.4 敕令法标 EdictSeals(目标战, 保留升级)
- 布标演出化: 龙先升至场顶画一道横贯弧线, 4 枚法标沿弧线像"盖印"一样依次砸落(每枚落点 20f 红线预警), 落定后 BeamGrad 金束把法标连到龙角(视觉主从链)。
- 法标在场期间叉状神雷持续(保留), 龙本体只做高空监察巡弋 + 每 240f 一次单发俯冲(前摇 60f), 压力主要来自法标——玩家目标明确。
- 法标耐久 6→5 击; 超时 1500f→900f(容错强制清标)。破标节拍保留(金芒泛光 + 停雷), Act2 破标解锁万剑归宗。

### 4.5 龙珠·天光柱阵 PearlJudgment(新招牌, Act1: 5 柱 / Act2: 7 柱)
- **结阵 60f**: 龙盘成一个环(航点切到以玩家上方 420px 为圆心的圆轨道, 半径 460px), 口中生成龙珠(专属着色器)悬于圆心。
- **蓄光 110f**: 完整充能语法——金streak 汇聚(密度 ∝ sqrt(charge), 72% 处硬切断) + 切向环流粒子; 珠体积 charge³ 增长; 震屏 charge²×4 隐雷; **最后 24f 静默**, 珠塌缩到 40% + 余弦颤闪。
- **释放**: 珠白闪一帧 → 天光柱阵: 玩家周围横向排布光柱(间距 300px), 每柱 45f 红色细预警线 → 100px 宽金白光柱轰落 50f(伤害窗口=柱体可见期), 奇偶两波错开 40f——永远存在可读安全缝。收尾珠体炸出一圈 10 发金能环(预警已由塌缩给出)。
- **收招 50f**: 龙散圈拉平, 巡航一小段(喘息)。
- 阀门: 光柱不追踪, 布阵以释放瞬间玩家位置为锚; 圆轨道期间龙接触伤害 -30%。

### 4.6 天罚·万剑归宗 FullScreen(Act2 破标后一次性, 重编排)
- 蓄力 90f: 龙珠语法复用(高空定点), 天空金芒染色攀升, 震屏渐强;
- **顿帧节拍**: 释放前 10f 全屏白金闪(ScreenSystem flash, 一场战斗唯一一次) + 全部粒子静默;
- 释放 110f: 诛仙剑雨从屏幕中央**向两侧对称扫出**(明确的移动安全带跟随扫描线之后), 外环 14 道叉状神雷收口(90f 预警保留);
- 结束强制进入 240f 巡航喘息(保留), 喘息中掉一个天命赐福区(保留)。

### 4.7 巡航 Cruise(连接词/喘息)
- 航点距离收敛 1400→950px(修"屏幕外绕圈"), 4 航点 S 形, 速度 19~23 px/f;
- 只保留 4 向低密度辐射弹(90f 一轮)与路径预警; 90f 时掉赐福区(保留);
- 时长 240f。**这是刻意设计的呼吸拍**, 不是填充。

## 5. 入场 / 换阶段 / 死亡三大演出脚本

### 5.1 入场 Entrance(180f, dontTakeDamage + 零接触伤害)
1. 0f: 玩家侧上方一道贯天金光柱(专属柱着色器, 8s 高度)落下, 远雷般低吼(Roar pitch -0.4), 天空金芒染色 0→0.35 攀升, 云海浮现;
2. 30f: 龙从光柱顶端俯冲而出(spawn 位置=柱顶, set 速度 58 px/f 斜向下), 穿云 punch + 金尘瀑布;
3. 30~110f: 横贯屏幕画一个大 S 弧(纯演出, 无伤害), 龙身金辉条带全亮;
4. 110~150f: 减速到 7 px/f 缓慢滑翔的"静止威仪"节拍——什么都不做, 40f 凝视;
5. 150f: 仰天咆哮(Roar 1.4x) + 震屏 8 + 金芒径向泛光脉冲, 天空染色落到常值; 165f 恢复可伤害, 进入 Act0 轮替。

### 5.2 换阶段 ActTransition(75f, 保留时长, dontTakeDamage)
1. 0f: **清全部敌对弹幕**; 吼叫(pitch -0.2);
2. 0~50f: 龙螺旋上升到玩家上方 650px 收拢成环, 金色汇聚流光 + 震屏 2→10 渐强, 条带充能波连发;
3. 50~65f: 环心 RadialBloom 白金爆闪 + 冲击环, ScreenSystem 染色阶跃到新幕常值(0.16 + act×0.14);
4. 65~75f: 散环俯出, 进入新幕首发(敕令); 出场 40f 无接触伤害 + 首轮弹速 20%→100% 缓升 60f。

### 5.3 死亡 DeathAscension(~250f, 金龙升天)
1. 触发: 头部血量归零时截获(`CheckDead` 返回 false 进入脚本), 清全部敌对弹幕, 全体 dontTakeDamage;
2. 0~80f: 龙昂头向上缓爬(阶梯刹车), 警钟音以 40f→6f 递减间隔加速鸣响(音调递升), 每 8 节体节从头到尾依次迸出金尘(排气), 条带 uBreak 金纹裂亮;
3. 80~180f: 收拢成缓慢上升的螺旋, 天空染色攀到峰值, 隐雷 rumble; 体身白热化(条带白金过曝);
4. 180~192f: **12f 全静默**(粒子/音/震全部切断);
5. 192f: 升天爆发——全屏白金闪 + RadialBloom、震屏 18(一场唯一次高震)、每 5 节体节同帧金爆, 龙身自尾向头溶解成上升金芒流;
6. 250f: 头部真正死亡(掉落/downed 标记照常), 天空染色随发布停止自动回落。

## 6. 视觉技术方案

### 新建专属着色器(4 个, 全 ps_3_0, ModContent.Request 静态缓存于 CelestialDragonVFX, 不注册 ACMShaders)
1. **CelestialDragonRibbon.fx** — 龙身金辉流光顶点条带(沿全部体节 BuildRibbonStrip 铺设): 双层噪声流动 + 鳞光闪烁 + uChargeWave(充能波 0~1 沿长度行进的亮斑) + uBreak(死亡金纹裂亮/白热化) + 尾端淡出。头部 PreDraw 收集体节链绘制(位于本体之下)。
2. **CelestialDragonCloudSea.fx** — 屏幕空间云海层(ScreenSystem PostDrawTiles, 实体之下): 双八度 FBM 云卷横向漂流 + 上金下暗的天光照明 + 最多 3 个 punch(俯冲穿透点的展开涟漪, 各带 age 衰减) + uIntensity 总控。
3. **CelestialDragonPearl.fx** — 龙珠: 程序化球体(fresnel 边缘光 + 内部旋涡噪声 + uCharge 驱动生长/白热 + 塌缩颤闪), SoftGlow 占位quad 上绘制。
4. **CelestialDragonPillar.fx** — 天光柱: 垂直条带(TriangleStrip), 噪声蚀边 + 自上而下流光 + uPhase(0 预警细线→1 轰落全宽→2 熄灭), 供入场贯天柱与天光柱阵复用。

### 复用共享件
- `ACMShaders.DrawBeam`(法标↔龙角系带、逆鳞反弹束——保留), `DrawRadialBloomAt`(蓄力/破标/爆发, 内部走全屏名额契约), `ArenaRunic`(赐福区/敕令地纹——保留), `ElementalScreenTint`(金芒底色——保留), `ACMShaders.NoiseTexture`(所有新着色器的 s1 槽)。
- 全屏 flash 走 ScreenSystem 的 ElementalScreenTint 强度脉冲, 不新增后处理, 名额契约不变。

### 绘制升级
- 体节 PreDraw: 保留贴图 + 发光层, 发光强度接充能波/白热参数; 冲刺时头部残影(TrailingMode 已有缓存)。
- 龙珠/光柱/云海全部程序化, **零新增贴图**; 音效全部 SoundID 复用。

## 7. 性能与多人预算

- **多人**: 状态机全部走 `npc.ai[0..3]` + `SendExtraAI`(storedAct/rotIndex/fullScreenArmed 已有, 新增俯冲向量 diveX/diveY 与入场锚点); 状态切换 netUpdate; 弹幕/召唤全部 `Main.netMode != MultiplayerClient` 门控; 体节行为由头部同步状态推导(确定性), 纯视觉字段仅客户端。
- **性能**: 4 个 Effect + 噪声静态缓存一次; 条带每帧一次收集(≤51 节, 静态 List 复用零分配)、细分 2, ≤400 顶点×2 层; 云海=每帧 1 次全屏 decal(受 FullscreenShadersEnabled 降级, 不占后处理名额——与既有 ScreenSystem 同类); punch 上限 3; dust 全部 `NextBool` 节流; 光柱同屏 ≤8, 金能弹 ≤40(生成前计数); 无热路径 LINQ/每帧 new。
- **进度兼容**: 掉落三选一、SoulBanner 召唤、`downedCelestialDragon` 标记、Boss 血条全部不动; 所有 public 类型保留原名。
