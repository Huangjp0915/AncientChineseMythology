# Spectre 怨灵 —— Boss 重做 V3 设计文档

> 单元：`Underworlds/Boss/Spectres/`（阴间 P1 怨念门控 Boss）
> 参照：boss-fight-choreography skill（MOTION/PACING）、`_SHARED_BRIEF.md`、质量标杆 Xuanwu。

---

## 1. 现状诊断

以七大本能与失败模式清单为透镜：

1. **全程失重（本能 #1/#2/#3 全违）**：所有幕的位移都是 `Center += (hover - Center) * 0.04~0.08` 的渐近 lerp 漂移。全场没有一次瞬时 launch、没有刹车、没有反冲、没有收缩-爆发。Boss 是"会放弹幕的气球"。
2. **幽魂题材语言缺位**：作为鬼魂 Boss，没有虚/实相位转换、没有聚散成形的传送语言、残像只是同贴图淡出的 oldPos 拖尾。贴图本身（兜帽骷髅 + 青绿鬼火 + 锁链 + 黄符）的题材潜力完全没被绘制层消费。
3. **招式内部无波形**：缠/怨链按 `AttackTimer % rate == 0` 节拍器匀速发射，无前摇-爆发-收招循环；哀嚎有 90f 蓄力但释放只有单环一拍。攻击之间无连接节拍。
4. **换阶段不清弹**：PhaseShift 只有 46f 定格，场上敌对弹幕原样保留（公平阀门缺失）。
5. **无死亡演出**：`OnKill` 只有一坨粒子瞬间结束。PACING §6 的三大演出节拍缺其一，入场也只是 lerp 上浮 + 单次爆点，无凝形、无静场压迫感。
6. **绘制原语弱**：光环/波纹/拖尾全部是借用黑白无常文件夹的 dust 贴图摆圆点；主体绘制是纯 `sb.Draw` + 呼吸缩放；`SpectreWave.png`（37×76 近白图）撑起哀嚎波与清算波两大签名弹幕，几乎不可见。无一个专属着色器（标杆玄武有 5 个）。
7. **小怪门控节奏平**：附身期间 Boss 无敌但仍然发弹（不诚实——无敌与攻击并存）；杀掉分身除了解锁外没有任何正反馈；无数量上限保护。

**结论**：判定为**全面重做 AI 编排与视觉**。保留：全部 public 类型名、掉落表、downed 标记、UnderworldField 怨念账/魂蚀集成、WraithLantern 武器（Items 子文件夹近期已达标，不动）。

## 2. 设计主题与幻想感

**「怨灯引魂 —— 灯火之间的虚实猎杀」**

怨灵是地府的"冤魂记账者"：兜帽骷髅提着账、拖着锁链、身缠黄符，青绿鬼火是它的血肉。给玩家的体验：

- **虚实转换（诚实开关）**：虚相 = 半透明褪色、**无敌但绝不攻击**（重新站位/威慑节拍）；实相 = 鬼火点燃、**攻击但可被打**。伤害窗口与视觉严格对齐：接触伤害只在实相冲刺的高速帧存在。
- **聚散成形**：远距离不追不飞——散成魂缕在旧位爆开、在新位收束凝形（传送用前后 telegraph 卖出去，绝不裸瞬移）。
- **鬼影残像**：多重延迟残影贴着本体拖出鬼影；P3 残像成为机制——「幻影重演」把 Boss 刚刚冲过的路径原样重演成真实威胁。
- **灯火引魂**：WraithLantern 主题贯穿——灯笼锚点是清账反制装置，也是哀嚎尖啸中唯一的安全灯道（"顺着灯走"）；死亡演出里灯笼逐盏熄灭送葬。

红色只留给致命源（TelegraphColors 契约）：冲刺线末段、清算波高怨形态、幻影突袭末段。

## 3. 阶段结构与血量断点

| 阶段 | 血量 | 幕序列（确定性轮替，无随机轮盘） |
|---|---|---|
| P1 教学 | 100%→50% | 缠 → 相位突袭 → 怨链 → 哀嚎 |
| P2 展开 | 50%→25% | 缠+ → 相位突袭+ → 灵魂风暴 → 怨链+ → 附身 → 哀嚎+ |
| P3 清算 | 25%→0% | **冤魂审判**（每循环开局）→ 相位突袭++ → 幻影重演 → 灵魂风暴+ → 哀嚎++ |
| 死亡 | 0% | CheckDead 截获 → 210f 死亡演出脚本 |

- 内容扣押：相位突袭是 P1 就有的签名，但灵魂风暴 (P2)、附身 (P2)、幻影重演 (P3)、冤魂审判 (P3) 逐阶段解锁。
- 换阶段（50%/25%）：清空本 Boss 全部敌对弹幕 + 60f 定格演出（无敌），P3 相变后 cycleIndex 复位使审判必为第一幕。

## 4. 招式编排表

时长均为 60fps 帧。预警色遵循 TelegraphColors（红=致命）。

### 4.1 缠 Haunting（教学压制，P1 300f / P2 270f / P3 240f）
- 结构：3 个 90f 齐射循环（前摇 30 / 爆发 12~18 / 收招 42），循环间镜像换边。
- 前摇：反向漂移（counter-motion，速度向瞄准反方向积累）+ 爪尖内收魂缕。
- 爆发：扇形 2/3/4 发怨念弹，**逐发间隔 6f 涟漪射出，每发反冲 3px**；弹速 8.6，出膛 24f 内从 40% 速度爬升到 100%（换幕防贴脸阀门）。
- 公平阀门：玩家距离 < 200px 时跳过该次齐射（最小射距，邀请贴身压制）。

### 4.2 相位突袭 VeilRush（签名招，P1×2 / P2×3 / P3×3 加速）
每循环 ~96f：
- **转虚 0–12f**：褪色半透明，无敌 + 停火（诚实开关），低鸣。
- **游标 12–48f**：虚相滑向玩家侧翼 340px 锚位（弹簧追踪，不完美跟踪）；36f 定长冲刺预告线从锚位穿过玩家逐渐变亮，末 10f 染红（致命）。若距离 > 1000px：散形传送到锚位（旧位爆散 + 新位收束，仅虚相期允许）。
- **凝实收缩 48–54f**：pow8 迟滞后仰 90px + 缩放 1→0.86，虚相快速归零——吸气。
- **爆发 54f**：单帧 launch `velocity = dir * 44`（带 9f 提前量预测），定向震屏 5，密集残像；**接触伤害仅在 |v| > 24 时开启**。
- **刹车 72–96f**：×0.70/f 硬刹 + 到位鬼火爆点，魂缕过冲（次级运动）。
- 保底出口：循环数完成或总时长 420f 超时。

### 4.3 怨链 GrudgeChain（区域控制，~280f）
- 30–70f 蓄：锁链绕体盘旋收紧（半径 160→60），体表 ±2px 颤动（质量感），音调爬升。
- 70f 起：3/4/5 条勾魂链**逐条间隔 8f 甩出**，每条反冲 5px + 震屏 2；链体从 Boss 到链头实时绘链。
- 160–220f：镜像角度第二轮。命中挂魂蚀（UnderworldField）。
- 收招：灯笼锚点存量 < 2 时补撒（教学反制）。

### 4.4 哀嚎 Wailing（处决级，P1 190f / P3 200f）
- **蓄力 0–88f**（Execution 档 90f 预警）：魂缕内收密度 ∝ √t，**65f 硬切断流**——最后 23f 全静默，本体缩至 92% 余弦颤抖（尖啸前的吸气）；ArenaRunic 地纹环渐显；震屏 t² 爬升。
- 释放 90f：尖啸——第一环 18/22/26 发；100f 第二环错半步；P3 110f 第三环。单帧径向泛光 + 震屏 11 + 能量波。
- **灯道阀门**：所有环共同跳过朝向最近灯笼锚点的 ±0.34 rad 扇缝（无灯则蓄力开始时自动补一盏）；蓄力期间灯道用鬼绿粒子标出——"顺着灯走"。
- 收招 110–190f：可见的喘息下垂（伤害窗口邀请）。

### 4.5 灵魂风暴 SoulStorm（P2+，320f 规则场）
- Boss 定在竞技场中心（全程可打——静止本身就是伤害窗口）。
- 50f 起每 28f 一环（14/16 发，弹速 7.4，出膛 20f 加速阀门），安全扇区半角 0.45 缓转。
- **内部调制**：170f 时旋转方向反转，提前 30f 扇区标记黄闪告警。
- 安全缝用鬼绿光缕 + 粒子标出（绿=可站）。

### 4.6 附身 Possession（P2 幕，門控 ≤600f）
- 40f 升空转虚：**无敌且完全停火**（诚实交换：威胁转移给分身）。
- 召唤 3 只提灯冤魂（全局存活 ≥3 时不再补），溶解凝形入场，魂链可视连回本体。
- **门控**：击杀 2 只 → 提前破虚：净化脉冲**清空本 Boss 全部敌对弹幕** + 怨念 -6（正反馈）；600f 超时自动破虚。
- 分身死亡：怨念 -3 + 魂缕飞向最近灯笼（清账可视化）。

### 4.7 幻影重演 PhantomReplay（P3 新招，~300f）
- 36f 金色标记预告：冲刺线以暗金轨迹画出（"这条路会被记住"）。
- Boss 沿线执行一次实相冲刺（同 4.2 公平规则）。
- 轨迹残留为渐隐金线；60f 后两道幻影（SpectrePhantomRush 定向模式）沿原路径 ±55px 平行**重演**，各带 36f 标准预告。
- 共录制重演 2 次。鬼影残像的机制化。

### 4.8 冤魂审判 GrudgeReckoning（P3 每循环开局 set-piece，~260f）
- 150f 居中蓄力（无敌，set-piece 不可秒断）：报复来向光束（久留象限）+ 冥雾后处理 + 内收账本魂缕；**108f (72%) 粒子硬切**，末 42f 静默中光束转红。
- 释放：唯一清算波（半径/速度/红度 ∝ 怨念账）+ 2~3 道幻影突袭（久留象限 + 对向各一，各带前摇）；怨念 -35。
- 蓄力开始补 4 盏灯笼（清账反制窗口）。收招 80f 可打。

## 5. 三大演出脚本

### 5.1 入场（200f）
1. 0–60f：天空快速压暗；屏幕边缘魂缕流向玩家上方一点（因果预告）；4 盏灯笼锚点每 15f 逐盏亮起（音阶递升）。
2. 30–110f：本体在灯阵中央**溶解凝形**（SpectreVeil uDissolve 1→0，缩放 1.18→1 沉降）。
3. 110–140f：**全静场 30f**——只有鬼火在飘（威慑=静止）。
4. 140f：尖啸爆点——震屏 12、能量波 ×2、单帧泛光、灯焰齐颤。
5. 140–200f：缓降至战斗高度，锁定竞技场锚点，开打。全程无敌至 140f。

### 5.2 换阶段（60f）
清空本 Boss 敌对弹幕 → 转虚升空 60px → 3 道能量波 + 相位闪光 + 全灯焰爆闪；P3 版天空叠入暗红爬升。仅 60f 无敌，落地立即入幕（P3 首幕=审判）。

### 5.3 死亡（CheckDead 截获，210f）
1. 0–40f：锁链崩断（径向魂缕债），身体踉跄后仰；清弹清分身；音调下坠。
2. 40–120f：**灯笼每 20f 逐盏熄灭**（噗、烟）；本体虚实闪烁按 24→20→16→12→9→7→5→4f 延迟数组加速（心跳变尖啸）。
3. 120–150f：坍缩——缩至 40% + 余弦频闪，亮度反升（爆前变小）。
4. 150f：**唯一一次全场大爆**：单帧强泛光 + 震屏 16 + 80 魂缕漩涡 + 3 道波纹，本体溶解归零。
5. 150–205f：魂缕雨向上飘散、天空回暖；205f 真实死亡（掉落/downed 照常走 OnKill）。

## 7. 性能与多人预算

- **全屏后处理**：每帧 ≤1，全部经 `ACMShaders.RequestFullscreenSlot()`；蓄力冥雾与释放泛光互斥（泛光帧自然占额）；强度 < 0.05 直接 return；尊重 `MythologyConfig.FullscreenShadersEnabled`。
- **批切换**：本体+残像共用一次 Immediate 批（参数逐影 Apply）；地纹环每帧最多 1 个（状态互斥）；分身各 1 次批切换（≤3 只且仅附身幕存在）。
- **分配**：着色器/噪声静态缓存；快照缓冲、扇区数组等全部定长复用；AI/Draw 无每帧 new 纹理/Effect/LINQ。
- **多人**：决策状态全部在 `npc.ai[]` + SendExtraAI（isPhase2/3、cycleIndex、arenaCenter、dashDir、laneAngle、replay 线段、怨念归一）；状态切换 `netUpdate = true`；弹幕/召唤仅服务器生成；虚实相位由 (Phase, PhaseTimer) 确定性推导，天空/粒子/残像纯客户端。
- **弹幕上限**：分身 ≤3、灯笼 ≤4、哀嚎每环 ≤26、风暴每环 ≤16、幻影每波 ≤3。
