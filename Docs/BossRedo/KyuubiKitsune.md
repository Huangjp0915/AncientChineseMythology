# 九尾妖狐 KyuubiKitsune — Boss 重做 V3 设计文档

> 单元: `NPCs/Boss/KyuubiKitsunes/`（KyuubiKitsune.cs / KyuubiTail.cs / KyuubiKitsuneProjectiles.cs / Items/*）
> 进度位: 世纪之花后（召唤物 KyuubiSummonsHairpin 要求 downedPlantBoss），石巨人级数值。
> 方法论: boss-fight-choreography SKILL（七大本能 + MOTION/PACING 配方）。

---

## 1. 现状诊断

以七大本能与失败模式清单过一遍现有实现（V2）：

1. **尾巴攻击没有伤害判定（最重大缺陷）**。KyuubiTail 全部刺/扫/砸/远刺是纯视觉编排：本体只有 120×120 接触伤害，弹幕只有狐火与曼陀罗边墙。九连刺甚至画了"致命红"预警线，然后什么也不发生 —— **假红色预警**反向训练玩家忽略红色，违反预警契约（红=致命且唯一）。
2. **瞬移廉价**（失败模式清单原文命中）：Phase1_Slam 与 Phase2_Teleport 都是 30f 淡出 → 位置瞬设 → 30f 淡入，无旧位残影/新位预告，读起来像 bug。
3. **速度无对比、质量无反作用**（本能 #2/#3）：二阶段冲刺是恒速 25px/f 持续 35f，无后拉蓄势、无一帧点火、无硬刹车、无速度门控的残影；全程 `velocity = lerp` 悬浮，任何发射都没有后坐力；本体是一张永不翻面、永不倾斜的静态贴图（面向都不随目标翻转）。
4. **本体常年在屏幕外**：一阶段悬停点在玩家上方 -340，玩家实际只看到尾巴从天上戳下来，Boss 本身不参与画面。
5. **节奏平直**（本能 #5）：一阶段固定 35f 间隙 + 等速轮替，无连接节拍、无波形；曼陀罗 12 秒里 Boss 挂在圈外上空发呆，圈内除了墙没有任何东西可躲 —— 大段"3 秒以上无事可做"的平坦区。
6. **三大演出残缺**：入场只是滑下来吼一声；换阶段是原地转圈喷尘埃；**死亡演出完全没有**（连 HitEffect 都没写，Boss 原地消失）。
7. **多人隐患**：leadTail / slamTargetPos / illusionPositions 等用 `Main.rand` 在各端各自掷骰且不同步（当前因尾巴无伤害而侥幸无害，一旦尾巴带伤害就是真问题）。
8. **无专属着色器**、无 Sky/滤镜、无世界层反馈；拖尾是 10 张本体贴图叠印。

**结论：全面重做**（AI 编排 + 伤害架构 + 视觉 + 三大演出），保留：全部 public 类型名、掉落表、downed 标记、召唤链路、曼陀罗边墙"本体权威驱动"的好架构、KyuubiTail 的 FABRIK+弹簧骨架（好底子，只调波形）。

## 2. 设计主题与幻想感

**「妖异优雅 — 九尾天狐·妲己」**。玩家要读的不是狐狸本体，而是**九条尾巴的合奏**：扇形展开是蓄势，逐尾点火是倒计时，尾尖所指是死线。狐不笨重 —— 它**滑行**与**闪现**，动作全部是"宫廷舞步 + 毒蛇出击"：长而华丽的前摇（45%），一瞬即至的爆发（poly8+，12%），带弹性回摆的收招（43%）。

色彩语言：一阶段**金焰**（阳、试探、庙堂气派）；二阶段妖力解放转**狐魅紫红**（魅惑、杀意）；预警只用契约红 `TelegraphColors.Lethal`，安全缝用翠玉 `Safe`。

体验曲线：一阶段是"在扇面与灯阵里跳舞"（读几何）；二阶段是"辨真伪 + 躲爆发"（读身份与节奏）；25% 以下给一次万狐朝月终结技（本能 #5：把最好的招押到低血量），死亡以"狐火归天"收尾。

### 终结技（≤25% 一次）「万狐朝月」

90f 大蓄力（九尾光环姿态 + 汇聚粒子 72% 截止 + 16f 全静默 + 脚下法阵盛放）→ 5 轮九方位贯刺（每轮 18f 预告、34f 轮距、基准角每轮转 11° 并向玩家方位偏置），第 3/5 轮附加狐火环 → **60f 力竭喘息**（尾尖冒烟下垂，绝对安全窗 = 奖励输出期）。此后进入狂化计时（P2 各时长 ×0.85、冲刺 +1 段）。

## 5. 入场 / 换阶段 / 死亡三大演出脚本

**入场「狐火聚形」（~210f）**
0-40f 九缕金色狐火尘流从四周螺旋汇入一点（收束 = 因果链的"因"）；40-100f 本体以 CharmVeil 溶解逆放显形（scale 0.3→1, BackOut 回弹），九尾按 6f/条 依次弹簧式展开成孔雀扇；100-160f **60f 全然静止**（只有呼吸缩放与余烬，"威压主要由静止构成"）；160f 仰天长啸：Roar + 径向泛光 + 震 10 + 法阵地纹闪一拍；175f 落入 P1。全程无敌 + 无接触伤害。

**换阶段「妖狐显世」（60%，~240f）**
入场即**清全部敌方弹幕**（公平阀门）；0-90f 尾巴收拢成九尾光环（圆环钉位姿态），金色粒子向心汇聚，72% 截止；90-108f 静默收缩（scale→0.94，一切粒子停止）；108f 爆发：PaletteLUT 短染屏（≤0.15, 10f）+ 狐火法阵全屏地纹闪 + 冲击环 + 震 12 + ForceRoar；尾巴角色三色（刺客橙/术士金/鞭尾紫）在爆发帧一次性点亮，全身辉光金→紫红；140-240f 缓慢恢复姿态，玩家有约 1.6s 呼吸窗。

**死亡「狐火归天」（~300f，CheckDead 拦截）**
即刻清弹 + dontTakeDamage；0-140f 本体缓缓上浮，九尾按 10f/条 依次垂落并以溶解边从尖到根消散（每尾一声轻响）；140-180f 幻纱溶解爬满全身，粒子密度随进度爬升（伤情叙事）；180-210f **30f 全静默**（一切粒子与运动截停 —— 爆发前的收缩）；210f 终响：金紫双色大径向泛光 + 冲击环 + 法阵地纹盛放一拍 + 震 14，九缕狐火余烬向九方位飘散；300f 真正死亡（StrikeInstantKill → 掉落）。

## 6. 视觉技术方案

**新建专属着色器（全部 ps_3_0、Kyuubi 前缀、Boss 代码内静态缓存 ModContent.Request，不注册 ACMShaders）：**

| 着色器 | 类型 | 用途 |
|---|---|---|
| `KyuubiFoxFlame.fx` | 精灵量子（噪声载体 quad） | 灵魂狐火：极坐标泪滴 SDF + FBM 沿轴流动 + 双色温渐变。用于尾尖火焰（9 个一批集中绘制）、狐火弹核心、灯笼 |
| `KyuubiCharmVeil.fx` | 贴图着色（s0=本体贴图, s1=噪声） | 魅影幻纱：RGB 鬼影错位 + 噪声流光 + 边缘辉光 + 溶解烧边。用于幻影绘制、二阶段本体薄纱、入场显形、死亡消散 |
| `KyuubiMandala.fx` | 屏幕空间地纹（同 ArenaRunic 用法） | 九曜狐火法阵：九瓣玫瑰线 SDF + 旋转符环 + 九边形墙基线。用于曼陀罗 set-piece 地纹、转阶段/死亡/终结技的法阵节拍 |

**复用共享件**：BeamGrad（`ACMShaders.DrawBeam`，尾刺贯刺光束与曼陀罗墙）、RadialBloom（关键帧泛光脉冲，走全屏名额）、PaletteLUT（转阶段/死亡短染屏，走名额，≤0.15）、WeaponVFX ribbon（尾巴狐火拖尾/冲刺流光）、ACMAsset.SoftGlow/BlankStar/GlaciateWave（柔光/星芒/狐刃）、ACMScreenShakeSystem（震屏预算）。

**绘制升级**：本体面向随目标翻转 + 速度倾斜 + 呼吸缩放；速度门控残影（>18px/f 才出现）；发射后坐、砸地反弹、尾巴收招余摆（波形冲量沿链传播）。

## 7. 性能与多人预算

- 3 个 Effect 静态缓存一次；尾尖火焰 9 个 quad 在**单次**批切换内集中绘制；法阵地纹每帧至多 1 次全屏 quad（非后处理，不占名额）；全屏后处理（泛光/染屏）全部走 `RequestFullscreenSlot`，同帧 ≤1。
- 弹幕上限：狐火同屏软上限 ~36（曼陀罗风车按节拍出、灯笼分波）；明珠每冲刺段 5 颗；贯刺 ≤9/轮。
- 无每帧 new 纹理/Effect/RenderTarget；无热路径 LINQ；粒子量与速度门控绑定。
- 多人：出招参数（扇面基准角、镜舞中心、坠砸落点、领尾）全部服务器决定 + `SendExtraAI` 同步；弹幕/清弹仅在 `Main.netMode != MultiplayerClient` 执行；`Main.LocalPlayer`、着色器与粒子只在绘制路径；状态切换 `netUpdate = true`。
- 每个状态都有完成或超时出口；换阶段/死亡清弹；伤害窗与视觉严格对齐（贯刺只在光束亮起的 12f 内有判定，墙只在亮起后有判定，接触伤害带速度门）。
