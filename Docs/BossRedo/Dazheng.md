# 大峥（大椿）Boss 重做 V3 —— 提升补强设计文档

> 单元：`Celestias/Boss/Dazhengs/`（天界 Boss，月总里后超级 Boss，固定不动的上古树神）
> 定位判断：该 Boss 近期已完成 V2「四季轮转」重做，宏观结构与视觉栈已是高水准。本轮为**提升补强**，
> 不推倒重来：保留四季框架、G5 门控、诱饵/治疗线互动与全部现有着色器管线，针对短板做外科式升级。

## 1. 现状诊断

以 choreography skill 七大本能 + 失败模式清单审视：

**已经好的（保留不动）**
- 入场「破土升起」290-tick 四段时间轴（预震 → 升起 → 爆发 → 收势），节拍完整、震屏渐强、有留白。
- 四季轮转宏观结构：每季 = 一招 + 一条战场规则；G5 锚点门控让 4.5M 血「挣得起」；击毁锚点主动切季 + 破绽窗口 —— 攻防都有博弈。
- 秋季诱饵树 DPS 谜题、冬季治疗线「冲刺/跳跃挣断」—— 互动型公平阀门设计优秀。
- 视觉栈：专属 DazhengArenaCircle 结界着色器（FBM 藤蔓纹）+ PaletteLUT 四季调色 + ElementalScreenTint 氛围 + 万木神域天幕，层次丰富。
- 网络安全规范：ai[] 同步、服务器权威、client-only 绘制已达标。

**短板（本轮升级点）**
1. **死亡演出完全缺失**（三大节拍缺其一，最大短板）：`OnKill` 只有一记镜头 punch + 尘埃，4.5M 血的超级 Boss 一秒蒸发，没有谢幕。
2. **树身零重量感**（本能 #3「质量即反应」）：本体是钉死的静态贴图 —— 不呼吸、不摇曳、发招无后坐、受击无反应。一切「重」的信息都缺席。
3. **换阶段演出单薄**：100 tick 尘埃收束 + 一轮弹幕环即结束；无静默坍缩拍（本能 #4），且**换阶段不清弹**（公平阀门缺失）。
4. **每季波形扁平**（本能 #5「战斗是波浪」）：每季只有一个循环压力源从头铺到尾（春墙 / 夏叶雨 / 冬冰藤），无季内高潮拍，无季间连接拍 —— 切季只是一闪 + 一震，段落感不足。
5. **金身幻影公平阀门欠缺**：追踪弹全生命周期追踪（无追踪截止、无「熄火」读法），且只在 P2 转换用过一次，素材利用率低。
6. **治疗丝线「斩线」节拍弱**：挣断瞬间丝线直接消失，无回抽鞭甩动画、树身无踉跄反应 —— 玩家最帅的主动反制没有得到演出奖励。
7. **结界无阶段演变**：只会收缩半径；着色器无裂纹/损伤参数，Boss 濒死时结界毫无反应，死亡时凭空消失。
8. **读法细节**：真身与诱饵的微特征差异只有镜像翻转 + 金核脉冲，可再加一条「心跳」声学暗示；锚点与 Boss 的「供养」关系纯靠文案脑补，无视觉连线。
9. 小问题：秋季诱饵超时安全阀分支忘记设 `SubState`，导致超时后瞬切冬季（无余波拍）；破绽窗口音效走服务器权威路径，多人端听不到。

## 2. 设计主题与幻想感

**「你闯入了一位活了亿万年的季节之神的院落。」**
大椿不追你、不扑你 —— 他的攻击方式是**让世界本身换一套规则**。玩家体验的支柱：
- **静的威严**：树不动，但一切都在动 —— 树冠摇曳、根须蔓延、季节流转。补强方向是让「静」有生命（呼吸、摇曳、后坐），而不是让树跑起来。
- **季节即段落**：每一季是一段有起（季语宣告）、承（规则压力）、转（季内高潮拍）、合（收势）的完整乐章。
- **凋零即谢幕**：他不该被「打爆」，而是**归土** —— 与入场破土升起完美镜像：叶落、结界碎、巨躯沉回大地、寂静、然后生命归还山林的一道金绿爆发。

## 5. 入场 / 换阶段 / 死亡三大演出脚本

**入场（保留原 290t 时间轴不动）**，仅在门控期给锚点加「供养根线」：每个锚点向大椿引一条细的绿色 DrawBeam 供养线 —— 目标读法从文案变成画面（毁掉喂养他的锚点）。

**换阶段「四季失序」（100t → 160t）**
- 0t：清除全部敌意弹幕（公平阀门）+ CombatText「四季失序」+ 击杀诱饵/治疗线。
- 0-70t：尘埃收束（保留）+ 树身内压摇曳 + 低频 rumble 渐强 + LUT 向金推。
- 70-82t：**静默坍缩**：粒子硬切、声音停、树身 scale 收缩至 0.985（本能 #4 的吸气拍）。
- 82t：爆发 —— RadialBloom 金爆（占当帧全屏名额，LUT 自动让位）+ Lifeburst 大环 + 藤蔓/幻影双环弹幕（保留）+ 结界收缩指令 + **结界裂纹 0→0.35 跳变 + uFlash 闪光** + 震屏 12。
- 82-160t：收势；160t 恢复可伤、防御/伤害成长（保留），`AdvanceSeason(当前季)` 走连接拍自然回到循环。

**死亡「归土」（CheckDead 拦截，约 300t）**
- 0t（服务器）：清弹、杀锚点/诱饵/丝线/根须场、接触伤害归零、Boss 血锁 1 + 无敌；CombatText「山林俱寂」。
- 0-70t 「寂」：树冠倾泻落叶（密度远超平时）、树身高频颤抖（摇曳冲量噪声驱动）、LUT 饱和度滑向 0.5（褪色）、结界裂纹 0.85→1.0、rumble 2→4。
- 62-70t：结界边缘粒子停（爆前静默）。
- 70t：**结界碎裂** —— 环形玻璃状崩解（uCrack=1 + alpha 塌缩）+ 沿圆周金绿尘环 + 震屏 10 + 木裂声。世界规则先死。
- 90-230t 「归土」：巨躯以三次方缓入沉回大地（纯绘制偏移 + behindTiles，NPC.Center 不动保证掉落物在地表）、根线泥土翻涌、每 ~30t 一声木质呻吟（随机音高）、震屏 3→7、土中升起金色生命光点（渐密）。
- 230-268t 「静」：只剩零星光点上升，接近无声（终爆前留白）。
- 268t 「生」：**全场最大的一拍**（全场唯一的 shake≈17）：Lifeburst 金绿巨环 + RadialBloom 闪光 + 沿地表 ±600px 荡开草绿新芽尘柱 + 低吼与清音双层。生命归还山林。
- 268-300t：余辉衰减；300t 服务器执行真实死亡（掉落、downed 标记；OnKill punch 减弱为收尾标点）。
- 天幕联动：死亡期神光熄灭、树冠漂移减速、落叶转密；终爆帧天幕金色脉冲。

## 7. 性能与多人预算

- 弹幕上限：根刺同屏 ≤6；金叶 nova 单环 30、共 3 环（瞬时 90，寿命 240t 内自然衰减）；幻影同屏 ≤4。
- Lifeburst 环同屏 ≤3，单 Immediate 批内循环绘制（每环一次 fullscreen quad 采样，PS 廉价，仅转换/死亡等瞬时场景出现）。
- 供养线 ≤4 条 DrawBeam（各一次批翻转，仅锚点存活时）。
- 全屏后处理严格走 `RequestFullscreenSlot()`：LUT（常驻）与 RadialBloom（爆发帧）互斥自动让位，每帧 ≤1。
- 多人：死亡演出/换阶段全部由 `Phase(ai[0]) + PhaseTimer(ai[1])` 驱动（已同步）；摇曳/呼吸/光环为各端本地视觉；弹幕仅服务器生成；破绽窗口音效改为客户端对 `defenseDownTimer` 上升沿检测（修复多人听不到的问题）；诱饵超时补 `SubState` 同步语义不变。
- 不新增贴图/音频；噪声用 `ACMShaders.NoiseTexture` 共享件（结界屏障弃用自带重复生成器）。
