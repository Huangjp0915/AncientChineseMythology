# 苍龙真身 AzureDragon —— Boss 重做 V3 设计文档

> 单元：`NPCs/Boss/AzureDragons/`（蠕虫型多节 Boss，SoulBanner T44「苍龙真身」，准圣门槛前置）
> 方法论：boss-fight-choreography skill（七大本能 / MOTION / PACING），共享简报 §3 流程。

---

## 1. 现状诊断

以七大本能与失败模式清单过一遍现有代码，问题按严重度排列：

1. **"永远匀速追尾"的无聊蠕虫 AI（本能 #1/#2 全违）**
   - `Phase1_Orbit` 是 180 帧的利萨如挂机盘旋；`Phase2_StormChase` 是 200 帧恒速（14~18 px/f）追踪 lerp。
   - 冲刺（P1_Charge / P2_RapidCharge）没有反向蓄势（counter-motion）、没有发射瞬间的速度对比（25f 预告 → 30 px/f 匀速 22f）、没有硬刹车与收招——招式波形是平的。
   - 所有招式"结束时的屏幕状态"与开始时几乎相同（本能 #5：波，而非坡）。
2. **完全没有死亡演出**，也没有 `CheckDead`——1200 万血的超后期 Boss 原地消失。入场是 180 帧 lerp 下落+吼叫，无入云出云、无天象配合。
3. **换阶段是"暂停+粒子"**：不清弹、无天空节拍、无新机制宣告；玩家只感到 Boss 卡了 1.5 秒。
4. **绘制层性能与质感双差**：每个体节各自 `End/Begin` 两次（80 节 ≈ 每帧 160 次批次重启）；龙身没有连续的"一条龙"视觉（只有逐节光斑）；头部残影常开、不随速度门控（本能 #7 反例：常开的修饰是噪声）。
5. **状态机隐患**：`Phase3_ThunderTribunal` 的 `ArenaCenter` 未同步；`chargeDirection` 未同步（客户端预告线无从对齐）；律令每 5 秒自主翻转、与招式节奏脱钩（规则变化不在"段落缝"上发生）。
6. **保留价值（V2 已做对的部分）**：`AzureThunderRod` 落雷柱的"标记→渐强→劈下"三要素预警、`AzureBolt` 主题弹、StormSystem 的压暗/天闪/审判庭地纹框架、TribunalWaveCount 限幅。这些保留并升级。

结论：**全面重做 AI 编排 + 绘制层重构**，保留并强化 V2 的预警弹幕与风暴演出层骨架。

## 2. 设计主题与幻想感

**「行云布雨的雷霆之主」**。东方苍龙不是一条会喷弹的蛇，而是一场有身体的风暴：
- **蛇形运动的节奏是灵魂**：盘旋蓄势（盘）→ 直线穿刺（击）→ 甩尾回旋（回）。玩家读的是"龙身收紧的弧度"，躲的是"那一瞬间的直线"。
- **腾云驾雾**：入场自云层深处显形（假 Z），三阶段大招腾入云中消失、再破云俯冲；云雾用程序化 FBM 雾涡着色器 + Smoke 粒子。
- **雷霆天威**：风暴压暗随阶段加深，天闪宣告规则变化，LightningBranch 天雷随节拍劈落；龙身是一条导电的河（顶点条带流光着色器，放电时电荷沿身体推进）。
- **死亡即雨霁**：龙陨落时风暴散去、暖光回归——"雨过天青"是这场战斗的诗意收尾。

## 3. 阶段结构与血量断点

| 阶段 | 血量 | 主题 | 节奏 |
|---|---|---|---|
| 入场 | — | 云中显形→破云而出→凝视 | 电影化 ~4.5s，无敌 |
| P1 苍龙出海 | 100%~60% | 教学：读盘旋、躲穿刺、走雷柱 | 中速，招间连接段长 |
| 转阶段 2 | 60% | 清弹→盘身聚雷→天闪爆发 | ~2.5s 无敌 |
| P2 雷霆震怒 | 60%~25% | 回旋连刺、雷网、风暴合围、龙身放电 | 提速，连接段缩短 |

攻击选择用**手工编排循环**（PACING §2），压制招与场控招严格交替，招间必经 `Glide` 连接段（视觉换段落 + 保底喘息）：
- P1：穿刺 → 吐息扫射 → 穿刺 → 雷柱阵 →（循环）
- P2：回旋连刺 → 雷网律令 → 风暴合围 → 回旋连刺 → 龙身放电 →（循环）
- P3：雷霆审判庭 → 腾云俯冲 → 狂龙缠身 → 腾云俯冲 →（循环，P3 开场必进审判庭）

## 4. 招式编排表

时长为普通模式帧数（专家在括号内）。所有预警遵守 `TelegraphColors`：致命红只在命中前 ~0.3s 出现，其余用苍龙青/雷电青白。

### Glide 游弋（连接段，P1 55f / P2 45f / P3 38f）
- 蛇形波动逼近玩家侧上方锚点（±(500,-230)），波动幅度最大（活的龙）；零弹幕（保底喘息）；就位即早退（PACING §3 不等自己的表）。

### P1-A 盘旋穿刺 CoilPierce（×2，专家 ×3）
| 幕 | 帧 | 内容 |
|---|---|---|
| 盘（前摇） | 50 | 绕玩家收紧圆环 r 420→300，角速 0.045→0.075；雾涡在盘心聚拢；口部电尘汇聚（密度∝√t，75% 处截止） |
| 锁（反蓄） | 26 | 硬刹 ×0.86/f + 尾 8 帧沿-瞄准线 pow(t,6) 后吸；瞄准线细光束（青→末 10f 转致命红）；发射前 20f 固定预警音 |
| 击（爆发） | ≤26 | 一帧设速 62(70) px/f 直线穿刺（LeadTarget 预判），无转向；残影/条带增辉仅此幕开启；行进 >1500px 或越过玩家 500px 早退 |
| 回（收招） | 28 | 硬刹 ×0.68/f；鞭波脉冲注入龙身（次级运动）；短盘 30f 后接下一刺 |
- 公平阀：距玩家 <260px 不发射（后漂延长锁定幕）；玩家 >1900px 时先游弋逼近；头部接触伤害仅在速度 >11 px/f 时结算。

### P1-B 龙息扫射 BreathSweep
- 占位 40f（飞至玩家侧上 ±(520,-180)）→ 蓄 32f（刹停+汇聚粒子+扇形边界细光束渐显，头部后漂 40px）→ 扫 76f：头沿短弧滑移，每 5f(4f) 一发 AzureBolt，扇面 -40°→+40° 扫过，**前 18f 弹速 30%→100% 爬升**（换招防瞬杀阀门），每发 2.5px 后坐 → 收 20f。垂直位移即可脱离。

### P1-C 雷柱阵 ThunderRods（V2 保留+重调）
- 升空蓄力 40f → 服务器布 5(6) 根 `AzureThunderRod`，间距 230px、整体随机偏移 ±115px、逐根 +7f 错相，预告 80f；龙在头顶缓弧巡游（存在感）→ 150f 收。安全缝永远存在。

### P2-A 回旋连刺 ChainPierce（×3，专家 ×4）
- 短盘 30f → 锁 18f（同 P1 预警语法，节奏更快）→ 刺 20f @ 72(80) px/f → **甩尾回旋**：越过玩家 ~640px 后速度以 2π/34f 匀角速转弯（速度衰减至 30），面向拦截点 ±0.16rad 即早退（MOTION §3 loop dash），画出完整的空中回环 → 直接接下一次锁。回环本身就是演出。

### P2-B 雷网律令 LightningLattice
- 入招宣告轴向（横/纵交替，同步计数器）：天闪 + 音效 + 震屏 4。
- 张网 55f：服务器沿轴布 6(7) 条 `AzureThunderRod`（横排/纵列，间距 190px，两小波奇偶错相 26f），细光束渐强预告 → 雷网落：每波激活 12f。龙沿网轴缓慢巡游。安全缝 = 奇偶交替出现。

### P2-C 风暴合围 StormRing
- 逼近 30f → 环布 72f：以 ~55px/f 切向速度绕玩家 r640 高速画圆，沿途匀布 10 颗 `AzureStormOrb`（新弹）→ 悬滞 46f：珠子各自充能（辉光渐强、75% 后静默、发射前坍缩闪烁——蓄力语法 §6），按 i×6f 错相向环心射 3 发扇形雷弹（30%→100% 爬升）。玩家在辐条间隙走位。

### P2-D 龙身放电 BodyDischarge（小型 set-piece）
- 盘场 70f：龙以 r560 绕玩家收拢成环（80 节身体 ≈ 1.35 圈重叠）；电荷沿条带着色器从尾到头推进（uChargePos 扫描），全程可读。
- 放电 ×3 脉冲（每脉冲 20f 白闪预警 + 短预告刺 → 每第 6 节沿法线内外各 1 发雷弹，起始节每脉冲轮转）→ 解环 30f。
- 公平阀：玩家离环 >760px 时提前解环（不围栏、不硬留人）；脉冲间隔 48f 保证走位窗口。

### P3-A 雷霆审判庭 Tribunal（V2 保留+升级）
- 3 波网格落雷（横扫/梳齿/向心三图案，波间 40f 喘息），`ArenaCenter` 服务器同步；波前天闪宣告 + 远雷声；风域横推保留（推力 0.32，风线粒子加密提示方向）；龙在庭上空做高波动 8 字巡游，**审判庭期间头部零弹幕**（可读性阀门）。3 波后强制转移动招。

### P3-B 腾云俯冲 SkyDive（×2）
- 腾云 55f：螺旋加速升天（v.y→-46），透明度→0.25、假 Z 缩小 0.55，雾涡吞没 → 完全隐去。
- 天眼锁定 66f：细竖直光束追踪玩家 x（lerp 0.06 滞后），46f 时**锁死**转致命红 + 预警音；天穹隆隆震感渐强。
- 神龙俯冲 ~30f：龙自锁定线顶端假 Z 破云而出（缩放 0.55→1.15→1 过冲），沿线 80px/f 俯冲，两侧每 5f 一对横向雷弹（爬升弹速）；至玩家高度下方硬刹 + 落点 8 发地面扇 + RadialBloom + 震屏 10。
- 回正 26f 接第二次。隐身期间不加无敌（召唤物仍可命中，公平）。

### P3-C 狂龙缠身 FurySpiral（≤260f 保底出口）

## 5. 入场 / 换阶段 / 死亡三大演出脚本

- **入场（250f）**：风暴滚入（压暗 0→0.5 冲高再回落）→ 0-140f 龙在云层深处绕大圆巡游（假 Z：缩放 0.35→1 立方收敛、低透明度、被压暗轮廓化），30/90f 两声远雷 + 微弱天闪 → 140f **破云**：天闪 1.0 + 吼叫 + 雾环炸开 + 震 12，以"行进的快移"（非瞬移）降至玩家前方 → 140-230f 骄傲 8 字巡游 + **30f 凝视静止**（威压=静止）→ 230f 入 P1。200f 前无敌。
- **换阶段 2（150f）**：清己方弹 → 龙飞至玩家上方盘成一圈，雷光沿身聚拢，风暴涌高 → 50f 吼叫+天闪+环沿 LightningBranch 落雷（视觉）→ 解环时 8 发慢速雷弹新星（弹速爬升阀门）→ 30f 缓冲后入 P2。
- **换阶段 3（170f）**：清己方弹 → 龙腾至高空，全屏风暴拉满（0.72）、审判庭地纹自地面亮起 → 双重天闪 + 最低沉的吼叫 + 震 10 → 直接接审判庭第一波（开幕即 set-piece）。
- **死亡**：见 §4 死亡演出表。全程 `CheckDead` 拦截，结算不回退。

## 6. 视觉技术方案

**新建（AzureDragon 前缀，ps_3_0，自缓存，不注册 ACMShaders）：**
1. `Effects/AzureDragonRibbon.fx` —— 龙身流光条带（招牌）。沿全身节点（头+80 节，CatmullRom 细分）铺 TriangleStrip；双层绘制（宽外层+窄芯层）。特性：双向鳞纹流动（两套噪声反向滚动）、头→尾行波脉冲、边缘衰减、`uChargePos/uChargeGlow`（放电电荷扫描带）、`uStrikeBoost`（穿刺瞬间过曝，速度门控）。顶点契约与 BeamGrad 相同（屏幕像素 + GameViewMatrix）。
2. `Effects/AzureDragonMist.fx` —— 云雾涡旋屏幕空间贴花。FBM 双八度旋转涡 + 软圆遮罩；用于入场显形、盘旋聚雾、腾云吞没/破云、死亡雨霁。经 `ACMShaders.DrawScreenSpaceDecalStandalone` 风格的自开合批在 StormSystem.PostDrawTiles 消费（雾在实体后，龙行雾上）。

**复用共享件：** `ACMShaders.DrawBeam`（瞄准线/雷柱/天眼锁定/扇界）、`DrawRadialBloomAt`（俯冲落点/死亡终爆，内含全屏名额）、`ElementalScreenTint`（风暴压暗/天闪/雨霁暖光，不占名额）、`ArenaRunic`（审判庭地纹）、`ACMAsset.LightningBranch/ElectricArcSheet/SoftGlow/Smoke/BlankStar`、共享噪声。

**绘制重构（AzureDragonDraw.cs 统一承担）：** Body/Tail 的 `PreDraw` 一律 `return false`；头部一次收集全链（按 SummonCount 排序），按 尾→头 顺序绘制：条带（1 次批）→ 体节贴图（带蛇形波动+鞭波视觉偏移 ≤18px，主批内完成）→ 全部辉光（1 次加性批）→ 头部电弧/星芒/残影（速度门控）。每帧批次重启从 ~160 次降到 ~4 次。

## 7. 性能与多人预算

- 条带每帧 1 组顶点（~320 verts×2 层），绘制路径分配可接受；辉光合并单批；尘埃按速度密度门控、上限意识。
- 全屏后处理：仅 `DrawRadialBloomAt` 走名额契约（内置）；ElementalScreenTint/ArenaRunic/Mist 为 overlay/decal 不读 screenTarget；全部受 `MythologyConfig.FullscreenShadersEnabled` 降级。
- 多人：状态机全走 `ai[0..3]` + `SendExtraAI`（补同步 `ArenaCenter/chargeDirection/latticeAxis/pierceCount` 等）；转移必 `netUpdate`；弹幕/落点仅服务器生成；`Main.LocalPlayer`、雾/震屏/天闪全在客户端路径；风域每端只推本地玩家（原设计保留）。
- 体节接触伤害下调（身 55% / 尾 45%），头部接触伤害带速度门控——盘绕表演不啃人。
