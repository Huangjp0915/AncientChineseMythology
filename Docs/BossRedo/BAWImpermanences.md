# 黑白无常 (BAWImpermanences) 重做设计 V3

> 单元: `Underworlds/Boss/BAWImpermanences/` — 阴间双 Boss 组合战 (黑无常·范无救 / 白无常·谢必安)。
> 方法论: boss-fight-choreography SKILL (七大本能) + PACING §5 多 Boss 分工/角色轮换 + 共享简报硬性约束。
> 质量标杆: `Celestias/Boss/FourSacredBeasts/Xuanwus/`。

## 1. 现状诊断

1. **状态机原始且完全可预测**: 数字 `ai[3]` + if 链, 每使固定 0→1→2 循环, 无反重复/无递进; 协同触发条件 `ai[0] % 300 == 0` 只在招式重置帧偶然为真, 语义混乱。
2. **动作失重失速**: 冲刺是 `velocity *= 1.15` 的爬坡而非瞬发 (违反"launch is a set"), 无反向蓄势、无硬刹 (0.95 慢漂 60 帧); 淡出→贴脸瞬移无 portal 遮掩 ("teleports feel cheap"); 白无常全程一条 lerp 悬停, 零后坐力零次级运动; 协同技每 15f 直指玩家的机枪式冲刺, 无预警节拍。
3. **不可读与不公平**: 冲刺中每 4 帧向随机方向喷 2 条锁链 (RotatedByRandom 0.8), 弹幕雨不可读; 传给锁链的 `p.ai[0]=-timeScale*60`、`p.ai[1]` 是死参数 (弹幕从不读取); 白无常二阶段**永久** 500px 减速域跟身, 与黑无常近身压迫叠成双向夹击; 汲魂 `player.Hurt()` 直接扣血 (多人双重结算), 牵引链每帧改写玩家速度无上限; BAWPlayer 隐藏的"双半血全伤 +30%"每次受击扫全 NPC 表。
4. **多人不安全**: 大量 `Projectile.NewProjectile` 无 `MultiplayerClient` 判定; `Main.LocalPlayer` 出现在 AI 路径; 编排状态 (hasRespawned/伙伴索引) 无 SendExtraAI。
5. **演出缺失**: 入场只有 180f 上飘+粒子, 且双使各自每帧劫持镜头 (SetScreenPos 硬控) 互相打架; **换阶段零演出**; 双使先后阵亡**无死亡演出**; 唯一亮点是 V2 加的 DissolveBurn 出场重凝与 PaletteLUT 阴阳分屏 (触发条件苛刻, 几乎见不到)。
6. **视觉低级**: 本体 = 原图 + tint + 1.08x 放大发光; 锁链 = 贴图段 + 正弦假波动 (无物理); 幽魂 = dust 贴图叠层; 减速域指示在 **PreDraw 里每帧 spawn 36 个 dust** (绘制阶段产生实体)。

**力度判定: 全面重做** AI 编排与视觉。保留全部 public 类型名 (两 NPC、8 弹幕类、BAWPlayer/BAWHelper/BAWFX/3 Dust)、掉落表、downed 标记、复活机制骨架、UnderworldField 怨念账接入点、DissolveBurn 重凝语汇。

## 2. 设计主题与幻想感

**"一见生财, 犯者无救 —— 勾魂双吏的阴阳对偶"**。

- **黑无常 (范无救)** = 阴·刚: 锁链与镰, 近身压迫, 动作**重** (深蓄势、瞬发、硬刹、锁链甩尾)。主题色: 幽蓝紫 `NetherViolet` + 暗铁。
- **白无常 (谢必安)** = 阳·柔: 幽魂与引魂灯, 飘忽控场, 动作**飘** (无重力浮沉、瞬步对穿、幡带拖尾)。主题色: 暖白 + 青白魂光。

玩家要学的核心: **读阴阳两仪的轮转**。任一时刻恒有一使贴身缠斗 (压迫)、一使远程布景 (存在感), 两使按节拍**阴阳易位** (换岗对穿是全场最可读的标点); 高光是黑白分屏的协同技「阴阳勾魂」— 屏幕被两使连线剖成阴阳两域, 分界缝是安全走廊; 一使先死, 另一使吞魂化「孤使」强化形态 — 黑白合于一身, 弹幕样式黑白双色化。

配色语言 (TelegraphColors): 致命 = `Lethal` 纯红; 黑侧主题 = `NetherViolet`; 白侧主题 = 暖白/青白; 安全缝 = `Safe` 翠玉。

## 5. 三大演出脚本

**入场** (~200f, 无镜头劫持, 只用统一震屏):
0f 玩家左上/右上两处各起一团魂火收束粒子 (converging streaks) → 20f 双使 DissolveBurn 重凝 (threshold 1→0, 110f, 黑紫边/青白边) → 130f 全静止对视 40f (只有身上 Verlet 锁链/幡带余摆 — 静止即威压) → 170f 同帧: 双啸 + 震屏 9 + 分屏 0→0.35→0 快闪 30f + 魂火迸发 → 200f 入 Duet (黑缠斗白控场), 首招弹速 60f 内 20%→100% 爬升 (转场防贴脸)。

**P2 阴阳易位·仪** (~150f, 一次性, 触发即清弹, 全程可被伤害):
先至 60% 者怒啸 → 双使向场地中点合流 (30f) 背靠背 → 黑白双色粒子太极互绕 (60f, 转速渐快) + 分屏强度 0→0.5→0 脉冲 → 同帧对穿分开 (交错白闪 1f + 震屏 8) 各归新岗位 → 播报「阴阳易位」。

**复活·引魂** (~180f): 死者化魂 (不可伤不可见, 悬于原地); 幸存者停手举链/举幡, 魂链 (DrawBeam) 连向尸位, 期间幸存者受伤 +30% (可打的演出, 打死引魂者=双杀); 150f 后死者 DissolveBurn 重凝复活至 40%, 冲击波清近身自家弹 + 震屏 8 + 播报「引魂续命」。

**孤使怒** (~140f, 清弹): 亡者残魂从尸位化流光飞入幸存者 (60f 粒子流) → 幸存者体表明灭 3 次 (DissolveBurn threshold 抖动) → 怒啸: 震屏 10 + 分屏 0→0.4→0 闪 + 体色换装 (黑镶白边/白泛黑蕊) → 播报「孤使怒·无救 / 必安」。

**死亡** (最后一使, ~170f, 清弹): 踉跄 (24f 随机小抖) → 锁链/幡坠地一声 → 缓缓坠飘 + 体表 DissolveBurn 明灭 ×3 递强 → 100f 仰天长啸: 体内魂焰柱涌出 (BAWSoulFlame) + 分屏骤闪 0.5 → 150f **白闪 2f (本战唯一冲击帧) + 震屏 14** → 本体 threshold→1 消散成魂火雨 → 真死结算 (掉落/downed 不变)。

## 6. 视觉技术方案

**新建专属着色器** (BAW 前缀, ps_3_0, 各自代码内 ModContent.Request 静态缓存, 不注册 ACMShaders):
1. `Effects/BAWYinYangSplit.fx` — 全屏后处理 (签名): 增强版阴阳分屏。相对共享 PaletteLUT 分屏新增: 分界呈水墨噪声波动缝、缝心太极双色描边呼吸、阴域压暗降饱和+幽蓝紫+漂浮魂点、阳域提亮+暖白+浮光魂点。用于 C1/入场/P2 仪/孤使/死亡的分屏节拍。走 `ACMShaders.RequestFullscreenSlot()` 名额契约, 强度 <0.01 直接 return。
2. `Effects/BAWSoulFlame.fx` — 世界空间 quad 程序魂火: SDF 泪滴形 + 噪声侵蚀边 + 内核, 用于双使体表魂焰罩 (各 1)、引魂灯充能焰、死亡魂焰柱 (调用点 ≤8/帧, Immediate 开合批可控)。

**复用共享件**: DissolveBurn (重凝/消散), ArenaRunic (W4 摄魂帷屏幕空间结界, `DrawScreenSpaceDecalStandalone`), BeamGrad `ACMShaders.DrawBeam` (引魂链/锁线预警), ACMAsset (SoftGlow/BlankStar/LightShot), `ACMShaders.NoiseTexture`。

**锁链链节物理**: BAWHelper 新增 `BAWVerletChain` (保留跨帧 prev 数组的真 Verlet, 支持双端钉扎 + 冲量注入 + 阻尼) — ChainProjectile 全系、双使体表垂饰 (黑腰链 ×2 / 白幡带) 全部用真物理链; 甩链/命中对链头注入冲量, 波沿链传播 (MOTION §4)。绘制: 逐节 Chain.png 朝向下一节 + A=0 发光底层。

**速度感层**: 残影仅冲刺爆发帧启用 (speed-gated); 冲刺帧沿速度向拉伸的 LightShot 流线; 硬刹帧反向尘爆。

**世界反馈**: 屏幕震动全部走 `ACMScreenShakeSystem` 统一预算 (入场/死亡 ≤14, 大招 8~10, 普通 ≤6); 全屏分屏走名额契约; 阴间雾 (UnderworldFogEffect) 既有联动保留 (`UnderworldPlayer.UnderworldEffect`)。

## 7. 性能与多人预算

- 弹幕/召唤生成一律 `Main.netMode != NetmodeID.MultiplayerClient`; 编排字段 (岗位轮拍/换岗计数/didP2/hasRespawned/unleashed) 走 SendExtraAI; 状态切换 `netUpdate = true`; `Main.LocalPlayer` 只出现在绘制/本地视觉路径。
- 拉拽/牵引只对 `Main.myPlayer == player.whoAmI` 的本地玩家施加速度 (客户端权威), 拉力限幅 ≤1.3px/f; 删除 `player.Hurt()` 直伤 (汲魂改为魂蚀叠层 + Boss 回血)。
- Verlet 总节数 ≤120/帧 (帘 6×12 + 体表 3×8); 全屏后处理仅演出/协同期激活且同帧 ≤1; Immediate 开合批 ≤10 对/帧; 无每帧 new 纹理/Effect (链节数组随弹幕实例一次分配); dust ≤60/帧, 弹幕类各设上限。
- PreDraw 不再 spawn dust (旧减速域指示移除, 由 ArenaRunic 结界替代)。
- 掉落/召唤方式/downed 标记/怨念账不回退; 删除 BAWPlayer 隐藏 1.3× 增伤 (强化改为显式演出驱动)。
