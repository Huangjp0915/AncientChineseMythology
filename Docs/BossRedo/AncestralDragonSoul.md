## 1. 现状诊断

该 Boss 已经历一轮 V2 作者化（16 态状态机、半血真分裂双子、残血合体终曲循环、专属天空着色器、
屏幕演出系统、预警配色接入），骨架不差。因此本轮定位为**深度补强**而非推倒重来：保留状态机拓扑，
重做动作质感、补齐三大演出节拍、落实"虚实对比"核心视觉。以七大本能与失败模式清单为透镜的问题清单：

1. **失重（本能 #1/#2/#3 全缺）**：所有机动几乎都是 `FlyToward`（方向 lerp + 加速度封顶）的匀速飞行。
   冲锋（RakingCharge / EnrageUltimate）虽有瞬时 set-velocity，但**无反向蓄力**（reel-back）、
   **无硬刹车**（×0.995/f ≈ 不刹车，38px/f 冲过头后飘出屏幕）、**无速度门控的残影/粒子修饰**。
   一切都是"漂"，没有"扑"。
2. **入场演出名不副实**：Intro = 120 帧原地上浮 + 少量白尘 + 一声吼。"从星空中凝聚成形"的核心幻想
   完全没有落地；已有的天空着色器在入场时也毫无反应。
3. **死亡演出缺失**：OnKill = 100 颗尘 + 一个音效。80 节的幽魂长龙死亡时应当是全场最大的一拍
   （PACING §6：蠕虫分段死亡配方），现状是"啪的一声消失"。
4. **核心视觉课题未实现**：龙身是不透明贴图 + 三层加性光晕。没有半透明流光、没有溶解/星辉边缘、
   没有相位穿行的虚化读法。"幽魂"只体现在颜色偏白。
5. **无相位穿行机制**：幽魂龙没有任何"虚体"玩法，接触伤害全程常开——包括分裂/回拢过场与
   谜题窗口期间（公平性缺口：过场里撞到隐身机制外的龙身照样掉血）。
6. **状态机实际 bug**：`PickNextAttack` 把"上一招"记在 `StateData`(ai[3]) 里做防重复，
   但 SpiralDive 等招式把 `StateData` 当角度累加器使用 → 防重复读到的是弧度垃圾值，形同虚设。
7. **弹幕读法参差**：DragonBeam 零预警直接展开并持续追踪 120 帧（最恶劣的一条）；尾巴每 120~150 帧
   无预警甩五连波，且在过场/喘息拍期间照发（破坏喘息与电影拍）；MistBolt 出膛即全速（换招瞬间可 telefrag）。
8. **道之碎片**：机制成立（8 节点谜题→受创窗口），但演出干瘪——同帧全部出现、无与本体的视觉联系
   （看不出"它们在护盾我"）；本地化把"道"写成了"刀"（刀魂碎片 → 道之碎片）。
9. **性能小账**：80 节身体每帧每节独立 SpriteBatch 绘制 4 层 + 独立粒子逻辑；双子期两条 80 节长龙
   ≈ 640 次 sprite draw + 海量 dust。有优化空间（合批渲染顺带解决着色器接入问题）。

## 2. 设计主题与幻想感

**「星海归墟 · 祖龙之魂」** —— 上古始祖龙（Archosaur，生前形态是另一个 Boss）陨落后，魂魄升上天界，
由亿万星辰重新聚形。玩家面对的不是一条肉身巨龙，而是一段**会呼吸的星空**：

- **虚实对比是唯一视觉纲领**：龙身常态微微半透明、体内有一道流光沿脊椎传向尾梢（BeamGrad 脊线 +
  体节着色器流光波）；蓄力/喘息时整条龙"散"成星尘轮廓（透明度骤降 + 星辉边缘 + 星点剥离），
  出手瞬间"凝"回实体。玩家用**龙身的实感**读它的威胁等级——透明=无害，凝实=会撞死你。
- **相位穿行**是该纲领的机制化身：虚化状态龙身无接触伤害、可以大摇大摆穿过玩家；凝实的一瞬
  就是猎杀线。读法 = 透明度 + 魂线预警。
- **世界反馈**：专属天幕全程叙事——入场星辰汇聚、分裂后星座龙在背景巡游、死亡时天幕熄灭再爆发。

## 3. 阶段结构与血量断点（保留 V2 拓扑，重排招池）

| 断点 | 阶段 | 招池 / 事件 |
|---|---|---|
| 100% | 入场演出（~4.5s，无敌+无接触伤害） | 星辰汇聚 → 逐节显形 → 静止凝视 → 咆哮开战 |
| 100%→70% | P1 基础 | ScaleBarrage / SpiralDive / RakingCharge / DragonBeam |
| 70%→50% | P1.5 扩池 | + SigilEruption / YinYangBind / **PhaseStrike（新·相位穿行猎杀）** |
| 50% | 分裂过场（3s，无敌+无接触） | 真分裂双子，脚本化开场：双链 → 交叉火力 |
| 50%→25%(合计) | 双子协同 | 主龙=场控（Sigil/YinYang/Beam/Pressure），副龙=机动（Barrage/Crossfire/Spiral/Raking/**PhaseStrike**） |
| <25%(合计) | 双魂回拢过场（6s，无敌+无接触，X 扫线仍需走位） | 合体「太初真身」，**白屏顿帧**（全场唯一一次） |
| 终曲循环 | 确定性循环 | 道之碎片场（谜题）→ 喘息 → 阴阳超载 → 喘息 → 编排终极（螺旋+双掠袭）→ 喘息 → 循环 |

## 4. 招式编排表（60fps；预警色遵守 TelegraphColors：红=致命专用）

### 4.1 PhaseStrike 相位穿行猎杀（新，P1.5 起）
- 循环 62f × 2：**虚化蓄力 0–29f**（ghost→1，接触伤害关闭，减速漂移到玩家侧上方；6f 起画贯穿玩家的
  魂线预警=Lethal 红线，24f 锁定方向=玩家位置+速度×12 预判；24–29f 粒子全部剪断——爆发前的静默）
  → **穿行 30–39f**（velocity=锁定方向×58 一帧点火，接触伤害开启，速度门控残影全开，10f 直线）
  → **收魂 40–61f**（×0.68/f 硬刹，42f 帧沿垂直方向撒 2×3 颗星屑弹，ghost 回落）。
- 公平阀门：虚化期零接触伤害（穿过玩家无害）；红线在点火前 24f 可读；刹车硬停不绕圈。
- 结束 → Recovery。

### 4.2 RakingCharge 掠袭冲锋（重做）
- 循环 84f × 3：**入位 0–39f**（飞向玩家侧翼 ±780px；26–39f 反向蓄力：沿冲刺反方向
  `pow(t,3)×160px` 后吸——扑击前的深吸气）→ **锁定 40–53f**（velocity×0.85 缓停=慢启动阀门，
  Lethal 红线沿预判方向拉直）→ **点火 54f**（46px/f 一帧 set + 吼声 + 震屏 6）→ 直线 12f
  → **硬刹 66–83f**（×0.75/f，58f 帧垂直撒雾弹一对）。
- 阀门：锁定期近乎静止；红线固定 14f 预告；刹车杜绝"冲出屏幕绕圈"。

### 4.3 SpiralDive 螺旋俯冲（补强）
- **快速入轨 0–25f**（直飞最近切点，提前到位则跳表——不等自己的钟）→ **收缩螺旋 26–170f**
  （半径 600→150、角速 0.05→0.13，每 10f 沿切向对撒星屑）→ **盘蓄 170–184f**（×0.8/f 缓停，
  粒子剪断=静默拍）→ **破圈 185f**（切向 44px/f 爆冲 + 8 星屑环 + 震屏）→ 刹车 → Recovery。

### 4.4 ScaleBarrage 鳞爆弹幕（重排为三波节奏）
- 波循环 50f × 3：0–25f 龙首汇聚星尘（蓄力语法轻量版）→ 26f 五连扇形 DragonScaleShard
  （出膛后悬停 90f 再裂解，原空间封锁机制保留）+ **发射后座**（头部沿反方向 -7px/f）→ 漂移拉开。

### 4.5 DragonBeam 祖龙吐息（重做读法）
- 头部 20f 入位侧翼 → 弹幕自带 **55f 预警**（细 Holy 金白线沿锁定角拉直，最后 18f 转 Lethal 红）
  → **喷息 110f**：光束展开，扫速上限 0.011 rad/f 缓慢追向玩家（不再 lerp 锁头），
  喷射期间头部持续受后座缓推 + 近乎悬停（慢启动阀门）→ 收束。判定严格 = 喷息期 & 宽度>40%。

### 4.6 SigilEruption / YinYangBind / Twin 系（微调保留）
- Sigil：75f 预警 + 60f 立柱机制保留；尾摆收短 40f。
- YinYang：三波双珠（40/95/150f），双珠间新增可见灵链线（读分离方向）。
- TwinLink / TwinCrossfire / TwinPressure：保留 V2 协同结构；Crossfire 弹速前 12f 半速热身。
- 尾部扫击：仅当头部处于作战态才发（过场/喘息/死亡静默），TailSweepWave 出膛 35% 速度
  14f 内爬满全速（防 telefrag）。

### 4.7 终曲三件套（保留机制，套用新动作质感）
- 道之碎片场：8 碎片**逐颗显形**（每 6f 一颗），每颗与真身之间拉星辉护盾链（读"先破我"）；
  全破 → 解锁受创窗口（泛光 + 天幕亮拍）；720f 超时 → 引爆成雾弹环（原惩罚保留）。
- 阴阳超载：机制保留；安全缝从单点 sparkle 扩为翠玉弧带（5 颗 Safe 色光珠铺满缝）。
- 编排终极：螺旋（子拍0）→ 双掠袭（子拍1）保留，掠袭套用 §4.2 新配方（52px/f、×0.7 硬刹、红线已有）。

## 5. 入场 / 换阶段 / 死亡三大演出脚本

### 5.1 入场「星海凝形」（270f，无敌+无接触）
1. 0–80f：天幕点亮，**星辰汇聚层**（天空着色器新 uniform `uConverge`）——全天星光化作向 Boss
   汇聚的辐向星流；龙头以溶解着色器从 0 显形（阈值 1→0），随后每节身体在生成时各自 36f 显形
   （长龙本就逐节生成，天然形成"从头到尾编织成形"）。
2. 90f / 150f：两声低音水晶脉冲，各带 0.4/0.6 天幕亮拍——心跳渐近。
3. 200–255f：**静止凝视**（一切粒子剪断，龙眼亮起）——威压主要来自静止。
4. 258f：咆哮 + PunchCamera + 震屏 10 + 天幕亮拍 1.0 + 环形星尘爆 → 270f 入 Patrol。

### 5.2 换阶段（补强既有两拍）
- **半血分裂**（180f 无敌+无接触）：保留 V2 脚本；分裂帧加白青星尘对轰 + 天幕亮拍。
- **双魂回拢**（360f 无敌+无接触，X 形处决扫线保留=过场仍可玩）：合体帧（210f）为**全场唯一
  白屏顿帧**——屏幕系统白闪 12f + 震屏 16 + 天幕亮拍 1.2；合体后龙体放大 1.2×（保留）且体节
  流光转太初金。
- 换阶段均**清空本 Boss 弹幕**（公平阀门补齐）。

### 5.3 死亡「归墟」（300f，无敌+无接触+清弹）
1. 0–40f：梯级硬刹（三档 ×0.925），头颅缓缓昂向天空；低吼。
2. 40–240f：**星散波**从尾梢向头部传导——每节身体按 `(尾距×2.2f)` 错峰把溶解阈值推向 1，
   越过半程时爆出星辉玻璃音 + 小星爆（每 8 节一声，音高渐升）；震屏随进度 1→4 缓涨；
   天幕新 uniform `uDeathDim` 把云海压暗——世界在熄灭。
3. 240–270f：**全静默**（粒子/声音剪断，龙头辉光坍缩到 40%——爆前先变小）。
4. 271f：终爆——120 向星辉环爆 + RadialBloom + 天幕亮拍 1.5 + 震屏 16；272f 服务器结算真死亡
   （掉落/旗标不变，掉落表原样保留）。

## 7. 性能与多人预算

- **绘制**：合批后整龙 = 1 脊线批 + 1 着色器主体批（~82 draw）+ 1 加性光晕批（~90 draw），
  较现状（~320 独立分批 draw）更省；双子期 ×2 仍在预算内。全屏后处理仍只有 GenericWarp
  一路走 `RequestFullscreenSlot()`。着色器/噪声全部静态缓存，Draw/Update 零 new。
- **粒子**：体节连接粒子隔节生成（segmentIndex%2），死亡星散按节错峰上限可控；
  弹幕 dust 频率维持或降低。
- **多人**：状态/计时/锁定角全部走 `ai[]`+`SendExtraAI`（新增 lastAttackId/deathStarted 入包）；
  切换处 `netUpdate=true`；接触伤害窗口由同步状态纯推导（`ContactDamageActive`）；
  弹幕/召唤仅服务器生成；ghost/溶解/天幕/屏幕演出为各客户端本地确定性推导（由同步 StateTimer 驱动）。
  阴阳超载的本地玩家结算机制保留。
