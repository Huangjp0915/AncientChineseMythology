# CelestialOverseer（天庭观察者 / 天庭监察者）重做设计文档 — Boss 重做工程 V3

> 单元：`Celestias/Boss/CelestialOverseers/`（天界 Boss，SoulBanner T43 召唤）
> 主题定位：**天庭机关监察者 = 机械精密 + 全知监视**（"天庭的机械法眼在审计你"）。
> 力度判定：V2 机制骨架（监视槽 / 窥视相位 / 陪审团 / 全知循环 / 签名十字）概念成立、**保留机制身份**；
> 动作编排、三大演出、专属视觉层全面重做。
> 参考标杆：Xuanwu（专属着色器矩阵）、Dazheng（场地/天幕系统）；方法论：boss-fight-choreography（七大本能 / MOTION / PACING）。

## 1. 现状诊断（V2 版问题清单）

以七大本能与失败模式清单为透镜：

1. **运动完全失重，与"机关造物"题材相反**（本能 #1/#2/#3 全缺）：所有位移是 `Vector2.Lerp(NPC.Center, ...)` 果冻悬浮；所有开火零后坐力；DivineDash 是全 Boss 最弱冲刺（25f 预告 + 恒速 30px/f、无 lead、无硬刹、无速度门控拖影）；天眼 6 只全程匀速圆轨，机械仪式感为零。
2. **攻击缺"演算-执行"对比**（本能 #4）：预告线有了，但蓄力期没有 converging 粒子、没有最后 1/4 的 pre-silence、没有 charge 曲线；开火帧只有 shake+音效。
3. **三大演出节拍残缺**：入场 = 180f lerp 下落 + 一声吼；换阶段原地放尘且**不清弹**（公平阀门缺失）；**死亡演出完全没有**（直接爆尸 + PunchCamera）。
4. **多人视觉不同步**：`crossAngle`/星陨落点在 `PhaseTimer==1` 用 `Main.rand` 各端各摇 → 客户端预告与服务器弹道错位。
5. **接触伤害常开**：悬浮法阵盘全程 150 接触判定，伤害窗口与视觉不对齐（本能 #6）。
6. **追踪弹与承诺冲突**：HolyOrb / CelestialEyeBeam 带追踪，与"安全扇区"承诺矛盾。
7. **视觉层单薄**："监察"主题最该有的扫描线 / 锁定框 / 演算法阵全无；无任何专属着色器（对比玄武 5 个）。
8. 状态机出口完备（各攻击均有 timeout）——此项良好，保留框架。

## 2. 设计主题与幻想感

**"天庭的机械法眼，精确得可怕。"** 与生物 Boss 的曲线运动彻底反差：

- **几何运动语汇**：位移是"计算好的"——伺服直线移动（恒速 + 近点减速斜坡 + 到位死停 `ServoMove/ServoBrake`）、量化悬停档位（左/中/右三档，拒绝 sin 摆动）、静止期每 ~45f 一次 1~2px 伺服校正微抖、一帧 set-launch 冲刺 + ×0.62 硬刹。
- **天眼台阵构型系统（部件展开变形）**：六眼不再挂匀速圆轨，而是在 **巡航环 / 收拢护体 / 十字阵 / V 形炮列 / 星位扇面 / 窥视外扩** 六种构型间弹簧-snap 变形；换构型每眼延迟 5f 依次就位，就位帧机械 click（音阶递升）+ 白闪；本体与眼间绘制细金**机关连杆线 + 关节点**。开火时单眼反冲（质量 = 反作用）。
- **演算-执行节奏**：每招前摇 = 静止"演算"（OverseerCalcRing 法阵：60/36 刻度双环 + 雷达指针余辉 + 阶段签名多边形线框，转速 t³ 加速；**最后 ~22% 骤停熄灭 = pre-silence**）+ 吸入尘（密度 ∝ √progress、72% 处骤停收气）→ **爆发（多为一帧全弹）+ 反冲** → 短收招。
- **锁定扫描（监视主题核心演出）**：双探照锥（OverseerScanCone）搜索 → 锁定冻结 → 机关齐射；锥内玩家监视槽额外上升 —— 信息与威胁同源。
- **被系统注视（世界层）**：OverseerScanline 全屏介质氛围（CRT 细扫描线 + 周期下扫亮带带内折射 + 两缘数据字符雨 + 窥视假预告 glitch + 审判红化 + 入场开机自上而下点亮）；对本地玩家的**锁定框 UI**（四角括号随监视槽收紧、伺服抖动、冷蓝→金→审判红咬合）。
- **天网恢恢（P3 高光）**：光线网格张开收拢、快门开合留缝，"疏而不漏"却总给你一条缝。
- **色彩语言**（TelegraphColors 契约）：金=权柄预告；冷钢蓝=搜索扫描；金亮=锁定；翠玉=安全；**纯红只留给致命**（审判射线 / 缉拿冲刺锁定线）。

## 5. 入场 / 换阶段 / 死亡三大演出脚本（已实现）

### 入场（~285f，无敌）
1. f0–30「接入」：屏幕自上而下**开机点亮**（OverseerScanline uBoot：未点亮区近黑+静态噪声，点亮行亮带）。
2. f30–75「降临」：fake-Z 从 z=7 立方收敛冲向镜头（绘制缩放 1/(1+z) + 透明度），f75 到位硬定帧 + shake6 + 尘环。
3. f75–135「静默注视」：完全静止全暗，锁定框缓缓咬合到玩家（f100 一声相机快门）—— 威压来自静止。
4. f135–215「台阵启动」：六眼每 13f 依次弹出（机械 click 音阶递升 + 白闪 + 弹簧就位），halo BackOut 展开。
5. f215「定音」：Orbit 构型锁定 + CombatText 播报"天庭监察，尽收眼底" + 吼声 + shake12 + 泛光 + 演算环满亮。
6. f285 进入 Observe。

### 换阶段（65%/30%，150f 无敌）
1. f1 **清空本体全部弹幕**（公平阀门）+ 眼阵收拢护体。
2. 过载演算：环 t³ 加速 + 吸入尘 + 渐强 rumble（∝ progress²）→ ~100f 骤停熄灭（pre-silence）。
3. f115 重构爆发：吼声 + shake12/14 + 泛光 + 眼阵重新展开为 Orbit（依次 click 就位）。

### 死亡（CheckDead 截获锁血 1，~370f）
1. f0–70「系统故障」：本体量化故障错位（每 6f snap 一次的数字信号损坏感）+ 电弧尘 + 失谐 click + 屏幕 glitch 0.9。
2. f70–190「天眼连环坠毁」：每眼间隔 20f 失控（侧向弹出冲量 + 重力抛物线坠落 34f 后爆毁，音调逐眼递升 + shake4）。
3. f190–270「核心过载」：演算环转速拉满 + 吸入尘 + halo 收缩 + rumble ∝ t²。
4. f270–285「完全静默」15f：一切熄灭 —— 尖叫前的吸气（glitch 骤降至 0.05）。
5. f285「终爆」：全场唯一 shake16 + 泛光满档 + 齿轮碎屑（带重力抛物线, 机关解体的实体感）+ 80 尘爆 + 信号中断 glitch 1.0。
6. f285–370「余韵」：本体隐藏、烟雾上飘 → `StrikeInstantKill` 真实死亡（掉落 / downed 旗标不变）。

### 复用共享件
`ACMShaders.DrawBeam`（BeamGrad：十字/审判/天网线/预告线全部顶点条带）、`RadialBloom`（开火/处决泛光, PreDraw 名额优先）、`ArenaRunic`（窥视扫描环/陪审眼穹）、`ElementalScreenTint`（监视暗角）、ACMAsset 遮罩粒子、`ACMUtils.SpringDamp2D`（眼阵弹簧）。

### 屏幕系统与全屏名额仲裁（每帧 ≤1）
- `OverseerSurveillanceScreenSystem`（PostDrawTiles，非 screenTarget）：监视暗角 + 全视法阵 + **锁定框 UI**（四角括号随槽收紧/伺服量化抖动/审判高频咬合变红 + 中心测微十字，纯 CPU 线段零着色器依赖）。

## 7. 性能与多人预算

- 3 个 Effect 全部 static `Asset<Effect>` 惰性缓存（Unload 置空）；扫描锥同屏 ≤2、天网线 ≤7、全屏后处理每帧 ≤1；尘埃循环全部有界；无热路径 LINQ/每帧 new。
- **多人安全**：
  - 决策随机全部 `Derive01`（synced seed × attackIndex × salt 哈希）确定性派生，或服务器决定后经弹幕 `ai[]` 随生成包同步（扫描锥锁定角、冲刺锁定线）—— 消灭"客户端预告与服务器弹道不一致"。
  - 弹幕/NPC 生成全部 `Main.netMode != MultiplayerClient`；同步字段（eyeFormation/reallyDead 等）并入 SendExtraAI；blink 位移后 netUpdate。
  - 扫描锥：照住计时服务器权威（localAI），锁定瞬间 netUpdate 冻结方向；锁定后计帧（ai2 递增）各端本地推进。
  - 纯视觉（扫描线/锁定框/演算环/眼阵弹簧/故障抖动）全部由已同步状态派生，服务端零绘制。
- 掉落/进度不变：掉落表、SoulBanner 召唤、`downedCelestialOverseer` 旗标、Boss 头图均保留。
