# Argus（天目·追魂弧）重做设计文档 — Boss Redo V3

> 单元：`Celestias/Boss/Arguses/`（后月球领主天界弓将，约 200 万 HP）
> 方法论依据：boss-fight-choreography SKILL/MOTION/PACING；执行约束：`_SHARED_BRIEF.md`
> 本文档为实施后收敛版（与代码一致）。

## 1. 现状诊断

以"七大本能 + 失败模式清单"为透镜通读 V2 代码后的结论：**视觉层有过一轮 V2 补强（BeamGrad 预告线、RadialBloom、ScreenSystem 染色、Sky 巨眼），但 AI 编排整体仍是 V1 水平，判定为"AI 编排全面重做 + 专属着色器补齐 + 三大演出节拍补全"。**

1. **动作全程失重（本能 1/2/3 全违反）**：唯一的移动语言是 `MaintainDistance` 匀速 lerp 悬停；射箭没有拉弓前摇、没有一次后坐力（弓将无 recoil）、没有 anticipation→burst→recovery 波形；攻击全是 `Timer % N == 0` 的均匀机枪流。
2. **瞬移全是廉价 snap（失败模式#3）**：`CheckFlashRetreat`/`FlashStepVolley` 均为 `NPC.Center = xxx` 瞬间置位 + 一圈尘埃，无前后预告。
3. **选招纯随机且各端独立掷骰（PACING §2 违反 + 多人隐患）**：`Main.rand.Next` 服务器/客户端各自掷，可连续重复同招，无法编排强弱波形。
4. **三大演出缺二**：入场 130f 淡入完毕瞬间即朝玩家射 12 向箭（无准备窗）；换阶段站桩吸尘 + 36 发全向爆发且**不清弹**；死亡完全无演出（OnKill 仅震屏）。
5. **"百目"题材浪费**：名为百目，全场只有天上一只装饰巨眼；"凝视"只有两招里的一条尘埃线；没有"众目锁定"机制，没有"被看见"反馈。
6. **弹幕不可读不几何**：箭/球生成即带伤害零淡入；星系球是"随机角度撒一把"；预判箭追打当前位形同追身。

保留资产：Sky 分层星空（小幅增强）、ScreenSystem 架构、掉落/召唤/downed/BossChecklist、玩家武器（Items 不动）、全部 public 类名。

## 2. 设计主题与幻想感

**"你不是在与一个弓手对射——你是被整片星空盯上了。"**

- **凝视语法**（全场统一电报，`GazeStep` 推进器）：细紫视线**游移**追踪（摆幅渐收）→ **锁定**（服务器裁定预判角，弹道就此冻结，红线增粗发亮 + 高音）→ **熄灭一拍**（爆发前的黑暗）→ 星箭齐射 + 弦震荡 + 实体后坐。玩家学会"锁定之后动即是生"，一切死亡可自述。
- **光弓重量**：BeamGrad 程序化光弓常驻（弓身曲带 + 双弦 + 搭箭流光），拉弦=弹簧、放箭=弦回弹震荡+后坐视觉偏移；大威力射击必先看见满弦。
- **百目机制化**：星瞳哨兵（`AetherealWingblades` 哨兵模式）= 战场上睁开的分体之眼，各自执行完整凝视语法（错相波纹）；P3 万目凝射 + 屏幕边缘"被看见"警示（`ReportGazeThreat`）。
- **星阵秩序**：星系球全部走**轨道运动学**（切向初速 + 每帧速度旋转 ω + drift 螺旋），等分圆周留对称缺口，成形延迟内是幽灵态（压暗无伤害）。
- **世界层**：天幕巨眼常驻注视本地玩家（微视差），域内锁死拉满；Boss 光环眼眨眼与天幕联动（SkyBlink）；死亡时巨眼缓缓闭合 + 星辰坠落（SkyDeathClose）。

## 5. 三大演出脚本（实施版）

**入场（~252f）**：远景微星 40f → 天目睁开（泛光+震5）→ fake-Z 立方曲线从深空冲向镜头 70f（双臂星尘螺旋收拢）→ **静止凝视 60f**（威压=静止，瞳孔追玩家）→ 教学第一箭（全场最长凝视语法 40/10/6，白闪处决线）→ 题名节拍（吼声+泛光+震12）入战。110f 前无敌。

**Trans2「睁目」（~150f，无敌清弹）**：定格 + 光环眼高频闪烁 40f → 碎裂闪（Sparkle 迸射+震6）→ 眨眼闭合 30f（天幕巨眼经 SkyBlink 同步眯合）→ 闭眼静默 30f → **骤睁**（泛光+吼+震10）+ 自 Boss 展开慢速压力星环（双缺口）。

**Trans3「天幕锁定」（~190f，无敌清弹）**：升空 → DomainSignal 0.8（天幕巨眼骤然睁大锁定玩家）→ 屏幕边缘 6 只竖瞳预热（0→1→0 睁闭脉冲）→ 汇聚星尘密度渐升 → 130f 竖瞳觉醒闪（泛光+吼+震11），此后 Boss 光环眼常驻竖瞳化。

**死亡「星坟」（CheckDead 拦截 → Death ~266f，无敌零伤害）**：弓垂落 30f → **灯将熄** 110f（光环眼闪烁频率渐升占空比渐降 + 音阶下行 + DissolveBurn 溶解剥落 + 星尘上飘 + SkyDeathClose 巨眼开始闭合星辰坠落）→ **反向收缩** 40f（QuadIn 缩至 0.25，末 8f 完全静默——星爆前的吸气）→ **星爆**（白泛光 0.36 + 震16 + 70 星尘 + 死亡音）→ 悬念留白 85f（星尘漂散，天幕合眼）→ 真死（`NPC.life=0; checkDead()` 放行，掉落照常）。

## 6. 视觉技术方案

**新建专属着色器**（ps_3_0，各消费点 `static Asset<Effect>` 缓存，不注册进 ACMShaders）：
1. `Effects/ArgusEyeIris.fx` — 程序化星瞳：杏仁眼睑开合（uOpen）、星云 FBM 虹膜+旋转环纹、瞳孔暗核视差（uPupilShift，quad 旋转=凝视朝向）、竖瞳化（uSlit）、锁定警戒环+增辉（uNova）；顶点色 rgb=主题色（紫→红=充能）。用途：Boss 光环巨眼 / Trans3 边缘预热眼 / 星瞳哨兵（哨兵单批集中绘制）。
2. `Effects/ArgusGalaxy.fx` — 程序化星系盘：对数螺旋双臂 + 星点闪烁 + 核心辉光 + 吸积缘环；顶点色 a=成形进度。用途：星系球"首球一次切批"全体绘制（逐球零切批）。

**复用共享件**：BeamGrad（凝视线队列单批冲刷：uniform 白 + 顶点色调色，一次 Apply 画 N 条；光弓曲带/弦/搭箭；处决白闪线）、DissolveBurn（死亡溶解）、PaletteLUT（终审第三击 impact frame 黑白顿帧）、GenericWarp·rift（全视之域折射）、RadialBloom（离散节拍泛光）、ElementalScreenTint（"被注视"底染 + 狙击聚焦暗角）、ArenaRunic（域虹环）、共享噪声。

**批切换预算**：凝视线队列 1 批（≤12 条）+ 光环眼 1 批 + 光弓 1 批 + 哨兵眼集中 1 批 + 星系球集中 1 批 + 全屏名额互斥链（impact frame > 径向泛光 > 域折射，每帧 ≤1 占名额）。着色器不可用时星系球退化为原贴图绘制。

**屏幕系统**：`Publish(tint, domain, gazeFocus, domainCenter, time)`；新增 `ReportGazeThreat`——Boss 锁定线/哨兵锁定线/悬停箭亮线/扫射线的"走廊检测"命中本地玩家时，屏幕四缘 SoftGlow 半出屏紫红高频呼吸（升快落慢，同帧取 max 不叠爆，零着色器）。

**天空**：新增 `Argus.SkyBlink`（Boss 眨眼 → 天幕巨瞳纵向眯合联动）与 `Argus.SkyDeathClose`（死亡闭目 + 星辰坠落熄灭 + 凝视射线归寂）；巨眼瞳孔常态微视差追踪本地玩家（"一直被看着"），域内大幅锁定。

## 7. 性能与多人预算

- **实体上限**：哨兵眼同屏 ≤8；星系球单招 ≤26；箭按凝视节拍成组发射（无逐帧机枪流）；凝视线队列 ≤12 条/帧。
- **多人安全**：状态机走 `npc.ai[]` + ExtraAI（cycleIndex/flashStep/windup/gazeAim）；选招确定性循环零掷骰；锁定角服务器裁定 + netUpdate 纠偏（客户端同式预测消除延迟）；弹幕仅服务器生成；扫射角度为纯时间函数全端一致；视觉状态（弓/眼/泛光/警示）全部由同步计时器各端确定性推导，不入网络。
- **性能**：着色器/噪声静态缓存；绘制零 LINQ、热路径零分配（凝视线 List 复用）；星球轨道=速度旋转运动学（无锚点查找）；全屏后处理走名额契约并受 `MythologyConfig.FullscreenShadersEnabled` 降级。
- **掉落/进度不回退**：掉落表、召唤方式、downed 标记、BossChecklist、public 类名全部保留。
