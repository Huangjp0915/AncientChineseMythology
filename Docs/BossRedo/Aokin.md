# 敖钦（南海龙王）重做设计文档 — Boss 重做工程 V3

> 单元：`Celestias/Boss/Aokins/`　主题：火 / 炎狱 / 沸海　参考质量标杆：Xuanwus
> 差异化立场：四海龙王中的**暴烈火王**——短蓄势高频爆发（burst 节奏激进档），与东海（水幕流转）/北海（风暴蓄能）/西海（寒潮凝滞）形成脾气对比。
> 本文档与最终实现同步（含协调期并行迭代合并后的定稿）。

## 1. 现状诊断（V2 遗留问题）

以 choreography skill 七大本能 + 失败模式清单为透镜：

1. **动作全程"弹簧追逐"，没有蓄势-爆发-收招波形**（本能 #1/#2 全违）。所有移动都是 `velocity = Lerp(...)`：巡游匀速椭圆；狂怒冲刺蓄力 25f 只做 ×0.85 减速（无反向蓄势、无 late-snap），冲刺 30f 匀速无硬刹车；龙蛇盘绕恒定 lerp 收紧 200+ 帧。
2. **失重**（本能 #3）。射弹零后坐力；蛇形身体纯 follow-the-leader，无游动波/甩鞭——爆发后身体不"反应"。
3. **三大演出节拍残缺**（本能 #7）。入场 = 3 秒缓慢下移 + 一声吼；两次相变 = 原地悬停 + 尘环；**死亡演出完全缺失**（未拦截 CheckDead 直接暴毙）。签名一次性时刻（冲击帧/shake16+/天空骤变）不存在。
4. **公平阀门缺口**（本能 #6）。冲刺沿途甩弹（侧闪撞弹的廉价命中）；冲刺预警只有 3 粒静止尘；俯冲每帧重瞄 = 全程追踪 32~38px/f；龙息 180~200f 匀速压力墙无波次；**身体接触伤害全程常开**——巡游喘息期照样伤人，伤害窗口与视觉不对齐。
5. **状态机与网络**：`subState`/`attackTimer` 私有字段不入 `ai[]`（ai[1]/ai[3] 闲置）→ 多人子阶段漂移；段接触伤害对目标玩家跨端调 `Hurt`（应只判本地玩家）；升空段无超时保底。
6. **视觉底子薄**。本体无着色器；火柱用共享 DrawBeam 观感是"光束"而非熔岩；封路龙卷 162 段/帧贴图叠绘；天空纯色矩形；无专属着色器。
7. **值得保留的资产**：余烬温度 EmberHeat（升温→满温泄压炼狱茧）、带缺口火环反制、劫火印记顺序火柱、熔潮安全缝、场地收缩龙卷、HeatScreenSystem 标量发布架构。判定为**全面重做动作编排与演出层、保留并强化机制骨架**。

## 2. 设计主题与幻想感

**「赤炎怒涛」——把南海烧沸的龙，火是他的脾气。**

- **暴烈**：与敖广的威仪蓄势相反——短蓄势、高频压迫、贴脸暴烈。所有爆发均为"**反向拖拽（pow⁴~pow⁸ late-snap）→ 单帧 set → 硬刹车**"的速度对比波形；每次喷吐/齐射都带机体后坐（重量感）。公平阀门同步加强：预警更亮（冲刺线/垂直红线/缺口金门柱）、逃逸窗口明确（波间间歇/停顿走位窗/转速钳制可绕背）。
- **沸海**：环境即武器——沸海间歇泉（蒸汽柱齐鸣）、炎龙卷、熔金雨（抛物线熔球+存留熔池）、龙焰洪流、焚海劫熔潮。世界层：热浪蜃景扭曲、火烧云天幕、余烬飘浮。
- **双压迫资源曲线**：
  - **余烬温度 EmberHeat**（环境）：火招累积 = 全屏热浪强度条，满温强制炼狱茧泄压（无敌 + 带缺口扩张火环，钻缝反制）→ 清零再来；
  - **逆鳞怒气 Rage**（行为，P2+）：受击积怒 → 满怒插入「逆鳞爆气」（清弹 + 无伤推离波 = 送玩家喘息的公平阀门）→ 6 秒狂暴（攻速/连冲数提升、熔鳞泛白）。打得越狠仗越暴烈，清弹兜底公平。

## 5. 三大演出脚本（最终实现）

**入场「南海沸腾」（~170f，无敌至咆哮）**
1. 0-50f 水下蓄势：本体隐匿于玩家下方 620px（绘制层跳过），海面赤光渐涨 + 上升余烬 + 周期微震。
2. 50f **破空跃出**：单帧 set -55px/f + 蒸汽浪花 + shake 8；身体段归位成破水长龙。
3. 越过 -300px 即 ×0.62/f 硬刹 →静止瞪视（仅呼吸浮动 + 龙眼渐亮，menace is stillness）；80f 两翼封路龙卷落位。
4. 140f 咆哮：shake 12 + 熔岩泛光 + vent 冲击环 + 龙焰环爆 → 170f 入巡游。

**相变2「沸海蒸腾」（50%，~110f，清弹）**
40f 向心蒸汽聚气（密度 ∝ sqrt(t)）→ 30f 静默收缩（光环回收=爆前吸气）→ 70f **蒸汽爆发**：无伤推离冲击波（AokinShockwave 蒸汽档）+ shake 11 + 全屏扭曲拉满 + vent + 封路龙卷点燃 + 场地收缩；温度充至 40%。

**相变3「焚海劫」（25%，~130f，清弹）**
咆哮（shake 12 + 泛光）→ 80f 铺设第一波熔潮裂隙（留安全缝）→ runic 地纹常驻 + 场地收 540 + 温度充至 50%。

**逆鳞爆气（P2+ 满怒插入，~65f）**
45f 聚气（红缘脉冲渐强 + 低鸣，80% 静默）→ 爆气 1 帧：**清挥发弹幕 + 无伤推离波**（公平阀门）+ shake 10 + vent → 6 秒狂暴（攻速/连冲+1、熔鳞泛白、天幕泛红、呼吸加速）。

**死亡「逆鳞崩解」（CheckDead 拦截，~230f）**
1. 0-90f 失控乱飞，身体自尾至头**每 3f 迸裂一段**（熔鳞着色器逐段焦黑镂空 + 音高上扬的逐段爆音 + shake 4）。
2. 90f 残躯冲天（单帧 set -24px/f + Roar）。
3. 140-205f **空中寂静**：粒子全停、屏幕压暗 0.65（deathDim）、只余龙眼渐亮。
4. 205f **金红新星**：全场唯一 shake 16 + 全屏白闪（whiteFlash，天空联动泛白）+ vent + 龙焰/蒸汽双爆。
5. 230f 服务器真结算（OnKill 掉落/downed 标记照常）。

## 6. 视觉技术方案（最终实现）

**专属着色器（6 个，全部 ps_3_0，Aokin 前缀，`AokinHelper` 静态缓存，不注册 ACMShaders）**
1. `AokinFirePillar.fx` — 程序化熔火/蒸汽柱（uMode 0=熔火 1=蒸汽 2=金白；FBM 上涌焰体 + 焰舌撕裂 + 白热芯 + 生长前沿/侵蚀消散）。接管劫火印记 / 熔潮裂隙 / 间歇泉 / 熔池 / 龙焰洪流（横置）的柱体绘制。
2. `AokinFireTornado.fx` — 程序化火龙卷（双螺旋条纹 + FBM 边缘撕裂 + 轴向伪体积 + uIgnite 点燃闪）。封路龙卷双层 quad（取代 162 段贴图叠绘）与炎龙卷舞共用。
3. `AokinHeatHaze.fx` — 专属全屏热浪蜃景（垂直对流位移 + 色散 + 余烬亮点 + uVent 冲击环 + 焦黑暗角）。走 `RequestFullscreenSlot` 名额契约，仅签名时刻生效；着色器缺失回退 GenericWarp(heat)。
4. `AokinBreathCone.fx` — 龙息锥形火舌（TriangleStrip 条带，噪声焰缘 + 芯-中-边三色）。
5. `AokinShockRing.fx` — 屏幕空间 SDF 冲击火环（角向火焰噪声 + 白热前缘；uMode 0=炼狱缺口火环 1=无伤蒸汽波；缺口翠玉安全芒）。
6. `AokinMoltenScale.fx` — 龙身熔鳞 emissive（噪声裂纹自发光；uHeat 温度呼吸 / uRage 狂暴泛白 / uDeath 逐段焦黑镂空 + 余烬烧边；Immediate 批逐段设 uSegPhase/uDeath）。

**复用共享件**：ElementalScreenTint（温度条底色 + 逆鳞红缘脉冲档）/ ArenaRunic / RadialBloom（HeatScreenSystem 三件套）、BeamGrad（洪流白热芯）、共享噪声、TelegraphColors、ACMAsset 遮罩（Smoke 火烧云 / GlaciateWave 热霾 / SoftGlow / LightShot 预警线）。

**绘制升级**：身体游动波（速度驱动振幅/频率，盘绕收紧、狂暴放大）；熔鳞着色器身体批；速度门控残影（>12px/f 渐显）；口部聚焰 / 龙眼演出（瞪视/死亡渐亮）；冲刺线与垂直红线预警（LightShot 双层）；AokinSky 六层天幕（底色/火烧云对象池/热霾横漂/呼吸/沸海映照/余烬飘浮 + 白闪联动 + GetCloudAlpha）。

**屏幕系统通道**：tint（=温度条）/ runic / bloom / **ragePulse**（逆鳞红缘）/ **deathDim**（死亡寂静压暗）/ **whiteFlash**（死亡冲击帧，本战唯一）。

## 7. 性能与多人预算

- 全屏 screenTarget 后处理仅 AokinHeatHaze 一处走名额契约（强度 <0.01 且无 vent 即早退）；氛围层走非 screenTarget overlay；全部受 `MythologyConfig.FullscreenShadersEnabled` 约束。
- 着色器绘制每实例 1~2 quad；熔池全场 ≤6（超限熄最旧）；封路龙卷粒子从 8/帧收敛到 4/帧（着色器接管主体）。Effect/噪声全部静态缓存，无每帧 new。
- 多人安全：attackTimer→ai[1]、subState→ai[3] 走 NPC 常规同步；温度/怒气/冷却/巡游时长走 SendExtraAI；决策与弹幕生成仅服务器；段接触伤害只判 `Main.LocalPlayer` 且**仅攻击窗口激活**（NPC.damage 窗口外归零）；死亡演出由服务器结算真死。
- 掉落 / downed 标记 / SoulBanner 召唤兼容不变；public 类型全部保留（AokinMeteor/AokinFlameVortex 兼容保留），枚举只追加不重排。
