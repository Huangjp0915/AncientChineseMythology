# 敖顺（北海龙王）Boss 重做设计文档 — V3

> 单元：`Celestias/Boss/Aoshuns/` ｜ 元素身份：**风暴 / 雷云**（四兄弟中的狂风骤雨型）
> 差异化核心：**臂段（AoshunArms）作为独立编排单元** —— 双臂挥风刃、聚拢压掌造龙卷、张臂唤雷。

---

## 1. 现状诊断

以 choreography skill 七大本能 + 失败模式清单为透镜：

1. **全程匀速、零速度对比（本能 #2 违背）**：`WormMovement` 是原版蠕虫钻地 AI 的翻版，巡逻 16~22 px/f 恒速追踪；没有一次"爆发-刹车"，八个攻击里有五个（雷链/龙鳞/天雷印/风暴之眼/怒啸后半）就是"边钻地追人边刷弹幕"，观感全部同质。
2. **无前摇波形（本能 #1 违背）**：所有攻击共用一个 40 帧的通用 `PreAttack`（转圈粒子），无各招专属的蓄势后仰 / 反向运动 / 收招；打击感面目模糊。
3. **臂段是纯摆设（本能 #3 违背）**：`AoshunArms` 与 `AoshunBody` 代码逐字相同（仅贴图不同），没有任何弹簧延迟、独立挥击、发射职责——而"臂"正是该 Boss 与三兄弟差异化的钥匙。
4. **三大演出节拍缺失**：入场 = 60 帧普通移动；死亡 = 直接掉落 + `OnKill` 一撮粒子；换阶段有粒子和震屏但无清弹、无天空联动、无地标性瞬间。
5. **攻击选择纯随机 + 巡逻死时间**：`rand.Next(maxType)` 仅防复读；巡逻 180~360 帧（最长 6 秒）内玩家无事可躲（PACING 自检 #2 不及格）；`AttackAbyssalAmbush` 是永不执行的死代码。
6. **公平性硬伤**：龙卷风最多 7 个、全程追踪、200px 内每帧无衰减 `player.velocity += pull`（推挤位移无预警无抗性）；风暴之眼直接 `p.Hurt`（用了过时 API 且伴随每帧位移干扰）；雷霆连环冲无冲刺线预警。
7. **视觉**：V2 屏幕系统（压暗/法阵环/泛光）与天空已是好底子，但"风暴"只有"雷"没有"风雨"——无雨幕、无风场卷动、无全屏扭曲；龙卷风用顶点圆环叠 Smoke，读感松散。

**重做力度判定**：屏幕系统 / 天空 / 部分弹幕绘制（雷柱、电网顶点弧）达标可保留改良；**AI 编排、臂部系统、三大演出、攻击公平性全面重做**，并补两枚专属着色器。

## 2. 设计主题与幻想感

**"你不是在打一条龙，你是在一场活着的风暴里求生。"**

- 敖顺本体（蠕虫链）是**风暴的眼壁**：绝大多数时间在地下/云雨间穿行，露面即是攻击。
- **臂是风**：所有"风"类攻击由臂段执行——蓄势后仰（弹簧延迟）→ 骤然挥出风刃；聚拢压掌 → 龙卷落地；张臂朝天 → 唤落雷。玩家通过读臂的剪影预判攻击。
- **雨是幕布**：二阶段起持续斜向雨幕 + 风场扭曲（全屏着色器），风暴之眼内部无雨无扭曲——"平静的眼"既是叙事也是可读性装置。
- **雷是标点**：致命瞬间（雷柱落点、冲刺线、终幕自戕之雷）全部走 `TelegraphColors.Lethal` 红色契约，其余时刻只用青白电弧色。

## 5. 三大演出脚本

### 5.1 入场「破土升天」（约 210f，全程无接触伤害）
1. 0–40f：玩家脚下远处地面开始隆隆（震屏 1→3 渐强），一条扬尘线从远处贴地冲向玩家（地面尘 + 声音渐近）。
2. 40–46f：扬尘线止于玩家侧方 400px，一拍静默。
3. 46f：**破土** —— 46px/f 冲天，Roar + 震屏 10 + 雷击泛光；天空系统在此刻起振（风暴强度快进）。
4. 46–120f：空中大弧线横越玩家头顶（转向率钳制 0.045rad/f，全身展示），臂做 Tremor 微颤。
5. 120–210f：俯冲回土，尘柱四溅，进入 P1 巡逻。

### 5.2 换阶段 T2「雷暴降临」（约 240f，无敌 + 清弹）
1. 清除全部敌方弹幕；蠕虫盘成环于屏幕中央上方，双臂 SpreadOut。
2. 0–120f：汇聚流光（密度 ∝ √t，75% 处骤停静默），震屏随 t³ 爬升，屏幕压暗至 0.72。
3. 120f：**一道巨雷自天贯落击中敖顺本体**（DrawBeam 粗雷柱 + PulseBloom(1.0) + 震屏 12）——从此雨幕与全屏风场扭曲常驻。
4. 120–240f：身段电网满亮，怒啸，缓慢展开回到战斗；蓄电置满。

### 5.3 换阶段 T3「坠入眼中」（约 180f，无敌 + 清弹）
1. 清弹；敖顺垂直深潜消失，屏幕压暗至 0.75，雨声与扭曲短暂减弱（风暴屏息）。
2. 60–120f：以目标玩家为中心，风暴之眼边界环自外向内收拢显形（ArenaRunic + 眼外扭曲/眼内平静的对比在全屏着色器上生效）。
3. 120f：敖顺从眼壁外破雨而出沿壁盘旋，怒啸（P3 开场 KingRoar 演出化衔接）。

### 5.4 死亡「风暴葬礼」（约 330f，接管击杀）
1. `CheckDead` 拦截：血量锁 1、无敌、清弹、进入 Dying。
2. 0–90f：挣扎攀升——速度渐衰，臂 Tremor 震颤 + 逐段电火花外泄（损伤叙事 ∝ 进度²）；风暴之眼随 Boss 坍缩消散。
3. 90–150f：**静默拍** —— 雨止、扭曲退潮、天空亮度下探（Sky 死亡调光），只剩身段电网明灭。
4. 150f：**万雷加身** —— 三道巨雷同时贯中本体（全场最大的一次 PulseBloom + 震屏 16，全战唯一）。
5. 150–300f：从尾到头逐段爆裂（每 6f 一段，段位置雷爆 + 龙鳞飞溅），头部最后。
6. 300–330f：真正死亡、掉落、`downedAoshun` 置位；天空在 10s 内自然退场。

## 6. 视觉技术方案

### 新建专属着色器（前缀 Aoshun，ps_3_0，自缓存不入 ACMShaders）
| 名称 | 类型 | 用途 |
|---|---|---|
| `AoshunStormWarp.fx` | 全屏后处理（走 `RequestFullscreenSlot` 名额，`Aoshun.PostDraw` 施加） | 风场卷动 UV 扭曲（FBM 沿风向）+ **程序化斜向雨幕**（双层流速噪声条纹）+ 雷闪白 + 风暴之眼内部"平静区"抠除 + 轻微蓝紫分级 |
| `AoshunCyclone.fx` | 局部四边形绘制（龙卷弹幕 PreDraw，Immediate 批） | 程序化龙卷漏斗：柱面明暗、双向滚动云带、边缘湍流、内部电闪 |

### 复用共享件
- `ACMShaders.DrawBeam`（BeamGrad）：雷柱本体与细预警线、冲刺线、身段电网（既有）、终幕巨雷。
- `ElementalScreenTint` / `ArenaRunic` / `RadialBloom`：既有屏幕系统三件套照旧（压暗 = 电量条、眼界环、雷击泛光）。
- `ACMAsset`：LightningBranch（天空闪电/雷柱纹）、ElectricArcSheet（电弧帧动画）、GlaciateWave（风刃本体）、LightShot（风线/风刃拖尾）、Smoke/SoftGlow/Sparkle/EmberShards/SlashBurst 照旧。
- 屏幕系统 `AoshunStormScreenSystem`：雷闪白经 `CurrentBloom` 供 StormWarp 复用；天空 `AoshunSky` 新增 `TriggerBolt`（演出定调雷）/`SetDeathDim`（死亡调光）/`CurrentFlashWhite`（雨幕雷闪同源）。

### 风场粒子池（AoshunWindField，"风的可见化"）
- 固定 96 槽零分配池（风线 = 沿速度拉伸的 LightShot 亮条，碎屑 = 旋转 EmberShards 小块），`AoshunStormScreenSystem.PostDrawTiles` 驱动，位于实体层之下不遮挡躲避信息。
- 五种模式由头部每帧发布（只读同步状态）：Ambient 环境风 / **Converge 汇聚 = 前摇预警** / Ring 环流 / Burst 爆散 / Collapse 坍缩（深潜与死亡）。**风向即预警**：风开始向龙汇聚 = 它要出手了。
- 环境风向与 StormWarp 雨幕倾角同源 —— 风线、雨幕、扭曲是同一场风。TrailQuality：Med 半量、Off 关闭。

### 臂部弹簧编排（AoshunArms）
- 手势通道：头部暴露 `ArmGesture`（None/ReelBack/Slash/FoldIn/SpreadOut/Tremor）+ 手势计时器 + 段错相；臂段读头部状态求目标偏转/伸展，`ACMUtils.SpringDamp` 弹簧追踪（刻意欠阻尼→机械顿挫感即角色感）。
- 绘制层偏移（不动碰撞链），Slash 帧配挥击残影与风尘；死亡 Tremor 用角速度冲量 + 指数衰减（余摆）。

## 7. 性能与多人预算

- **全屏后处理**：仅 `AoshunStormWarp` 一个，走名额契约，强度 <0.01 直接 return，受 `MythologyConfig.FullscreenShadersEnabled` 约束；屏幕系统三件套均为非 screenTarget overlay（不占名额，既有结论）。
- **弹幕上限**：风刃每波 ≤8、龙卷同屏 ≤2、电痕全局 ≤24（生成前计数）、雷柱每轮 ≤8、电网节点 ≤8。
- **绘制**：着色器/Effect 全部静态缓存（参照 Xuanwu `??=` 写法）；无每帧 new 纹理/RT；顶点带段数固定上限。
- **多人**：状态机走 `internalAI[0..3]` + `NPC.ai[1]`（计时器改用 ai[1] 自动同步）+ `SendExtraAI`；弹幕/Buff 只在非 MP 客户端生成；`Main.LocalPlayer`、屏幕系统、天空、臂弹簧全部只在绘制/客户端路径；风暴之眼伤害服务器端结算（`PlayerDeathReason` 用 NetworkText 版 API）。
- **蠕虫链兼容**：段生成逻辑保持（Arms/Body 交替 + Tail），新增段索引写入段 `ai[2]`（自动同步）供臂错相使用；`realLife` 共享血池不变。
