# 旱魃 (Hanba) 重做设计 V3

> 单元: `NPCs/Boss/Hanbas/` — 上古大旱之神 / 僵尸始祖 (月后"四大僵尸"首位, 红木棺材召唤)。
> 方法论: boss-fight-choreography SKILL (七大本能) + MOTION/PACING 配方 + 共享简报硬性约束。

## 1. 现状诊断

1. **全套弹幕零伤害 (致命 bug)**: `HanbaFireBall` / `HanbaLaser` / `HanbaBigLaser` / `LocustSet` 全部只设 `friendly=false`, 从未设 `hostile=true` — 任何弹幕都打不到玩家, 整场战斗实际只有本体接触伤害。`LocustSet` 画 4400px 红色预警带, 真实判定却是一个隐形 32×32 方块; `HanbaLaser` 的判定同样是贴在 Boss 身上的 32×32 小盒而非光束本身。"蝗灾"与"射线"全是纸老虎。
2. **无入场 / 无阶段推进 / 无死亡演出**: 出生即进入悬停循环; 解封后 4→5→6→7→4 无限轮换, 与血量完全无关 (唯一 HP 反应是本地粒子爆 `PhaseBeat`); 死亡直接掉 gore, 三大演出节拍缺其二强其零。
3. **失重失速**: 冲刺 = lerp 0.1 到匀速 32px/f 的漂移, 无反向蓄势、无硬刹、无后坐力、无速度门控残影 (残影常开且不随旋转); `TeleportNearTarget` 瞬移零遮掩 ("teleports feel cheap"); 状态 6 直接 `NPC.Center = target.Center` 把 Boss 瞬移到玩家身上 — 接触伤害 telefrag。
4. **可读性/公平缺失**: 冲刺伤害 95 全程常开 (含蓄力/收招期); 蓄力半程无预兆甩 8 发追踪火球; 大激光张开后追踪 0.02rad/f 且持续 470f 无喘息; 火球 100f 后 1.4 倍加速追踪 (代码注释自嘲"恶心人")。
5. **多人隐患**: 出生偏移角每帧 `Main.rand.NextFloat` 扰动 → 目的地各端不同且每帧抖动; `HasTalisman` 仅服务器为 true, 客户端血条/无敌表现不同步; `Talisman.OnKill` 中 `Hanba` 可能为 null (NRE); 符纸血量写死不随人数缩放。
6. **视觉低配**: 本体 = 原图 + 定角残影; `HanbaSky` 焦日写死屏幕坐标 (1447, 80) 不随分辨率, 天幕每帧 `Main.rand` 抖动; 无专属着色器 (V2 只接了共享牢笼贴花与 BeamGrad 射线)。

**力度判定: 全面重做** AI 编排与视觉。保留全部 public/internal 类型名 (`Hanba`/`Talisman`/`HanbaFireBall`/`HanbaLaser`/`HanbaBigLaser`/`Shockwave`/`LocustSet`/`LocustPRT`/`HanbaSky` 及其注册名)、掉落表、downed 标记、红木棺材召唤、符纸封印机制 (升格为签名机制)、鬼域牢笼 (升格为 set-piece)。

## 2. 设计主题与幻想感

**"赤地千里"** — 《山海经》: 黄帝之女妭, 所居不雨, 赤地千里; 同时是僵尸始祖之一, 额上符纸即封印。

双重身份 = 两套运动语言, 解封是全场戏剧轴:

- **封尸期 (符纸在)**: 僵尸的僵直 — 躯体锁死竖直、长时间静止、瞬间僵跳直线突进、硬停, 动作机械分段, 色调灰败 (封印压制)。玩家的目标不是 Boss 而是符纸。
- **旱神期 (解封后)**: 大旱之神 — 热浪上升般的漂浮 + 烈日爆发式突进, 每招伴随蒸发/焦痕/蝗祸; 世界随战斗持续枯竭 (天幕烧红、大地干裂、焦日增辉 — 纯视觉氛围)。

配色语言 (TelegraphColors): 致命=Lethal 纯红 (只给真伤害源); 主题=Flame 焦橙 + Gold 烈金 + 灰烬黑; 安全缝=Safe 翠玉; 封尸期点缀极少量灰绿尸气。
一句叙事收笔: **旱魃死, 天将雨** — 死亡演出中天幕红量断崖回落。

## 5. 三大演出脚本

**入场 (~200f)**: 0f 尸气 (灰绿烟) + 灰烬向出生点汇聚, HanbaSky 快速烧入, 焦日在天幕显形 → 40~100f 躯体 DissolveBurn 反向显形 (threshold 1→0, 灼烧边焦橙), 竖直僵尸姿态零动作 → 100~160f **完全静止** (符纸摆动, t=120/140 双主眼先后点亮 + 轻响) → 160f 低吼 (Roar 低音) + 震屏 8 + 尸气外爆 → 进 P1。符纸 NPC 在 160f 生成 (服务器)。

**解封 (~150f, 符纸死触发)**: 0f 清弹 + `HanbaLaser/BigLaser.AllVanish` → 0~40f 符纸就地 DissolveBurn 烧尽 (Boss 绘制层接管), Boss 垂首静默下沉 (×0.9/f) → 40~130f 每 11f 点亮一只眼 (8 眼, 各伴小爆+音阶递升) — 蓄力语法: 最后 20f 静默 → 130f 尖啸 (ForceRoar 高音) + 震屏 12 + 热浪 warp 脉冲 (0.55) + RadialBloom 爆发 + 天幕跳档 → 150f 进 P2。全程可被伤害 (playable drama), 本体不攻击。

**蚀日 (≤60% 一次性, ~140f)**: 清弹 → 20f 后仰升空 → 20~90f 焦日增辉 (天幕日轮 flare 0→1) + 8 眼全燃 + 灰烬上腾 (蒸发感) → 90f 干雷裂响 + 震屏 10 + Shockwave 双环 + 大地干裂场 (ScorchGround 大印记) 自 Boss 正下方地面扩张 → 140f 落回进 P3。

**死亡 (~180f, CheckDead 拦截)**: 0f 清弹 + 定格 (×0.85/f) + 长尾音效止 → 10~122f 每 14f 熄灭一只眼 (与解封互为镜像) + 躯体裂纹渗焰 (DissolveBurn 边缘) → 60~168f 躯体自下而上灰化 (uDirection 向上 sweep), 灰烬随风粒子密度 ∝ 进度 → 140f 天幕红量断崖回落 (旱魃死, 天将雨) → 168f 轻白闪 (0.5) + 震屏 10 → 178f 真死 (gore + 掉落 + downed)。

## 6. 视觉技术方案

**新建专属着色器** (ps_3_0, Hanba 前缀, `HanbaVFX` 静态缓存, 不注册 ACMShaders):
1. `Effects/HanbaScorchGround.fx` — 干裂焦土贴花: 屏幕空间世界锚定 (WorldDecalParams 坐标约定), 共享噪声驱动的细胞裂纹 (双层噪声 max 交线) + 裂缝内焰光脉动 + 外缘灰烬渐灭; `uProgress` 裂纹自中心生长, `uRingMode` 切环带模式 (干渴汲取三环) / 实心场模式 (坠日焦土场、蚀日扩张)。廉价装饰层, 不读 screenTarget 不占名额。
2. `Effects/HanbaScorchSun.fx` — 焦日日轮: 程序化太阳盘 (白热核心 + limb darkening + fbm 焰舌舔动 + 日冕射线), `uFlare` 爆发强度, `uAsh` 灰蚀度 (死亡时日轮熄灭)。用于: HanbaSky 天幕焦日 (替换贴图日)、坠日 set-piece 巨日本体、灼柱蓄力日核。Additive overlay, 不占名额。

**复用共享件**: GenericWarp(heat, uMode=0) — 解封尖啸/坠日冲击/P4 常驻低强度 (Boss `PostDraw` 走 `RequestFullscreenSlot` 名额契约, 参考 Aokin 写法); DissolveBurn (`WeaponVFX.ApplyDissolveBurn`) — 入场显形/符纸烧毁/死亡灰化; `ACMShaders.DrawBeam` — 冲刺预警线/8 眼激光/灼柱 (保留现 BeamGrad 管线); ArenaRunic — 焦笼 (uShape=1 方形); `DrawRadialBloomAt` — 解封/坠日泛光 (内部自动抢名额); ElementalScreenTint — 旱情氛围底色; ACMAsset (SoftGlow/Smoke/EmberShards/SlashBurst)。

**新建 `HanbaScorchScreenSystem`** (ModSystem, PostDrawTiles, Publish 模式, 参考 AokinHeatScreenSystem): ① 旱情底色 (ElementalScreenTint, 上焦橙下灰烬, 覆盖 ≤0.26, 强度=旱情标量); ② 焦土印记环形缓冲 (≤6 个: 汲取三环/坠日场/蚀日场, HanbaScorchGround 绘制, 随 age 淡出); ③ `FlashWhite` 全屏白闪 (MagicPixel 直画, 本战 ≤2 次: 坠日冲击帧 1.0 / 死亡 0.5)。

**HanbaSky 重制** (类名/注册名不变): 焦日改为屏幕相对定位 (0.74w, 0.16h) 且用 HanbaScorchSun 着色器绘制动态日轮 (着色器缺失时回退旧贴图); `PublishSunState(flare, ash)` 静态桥与战斗联动; 移除每帧 rand 抖动 → 正弦低频漂移; OnTileColor 遮蔽上限收敛 (≤0.4), 死亡时快速退红。

**本体绘制升级**: 速度门控残影 (仅 \|v\|>20, 随 rotation, 暖色 additive); 8 眼状态化绘制 (SoftGlow 眼位点, 各眼独立亮度数组, 蓄力呼吸); 封尸期躯体降饱和灰化 + 2px 高频尸抖, 解封后恢复暖色 + 体表热浪微光 (双层偏移采样); 蜃景 = HanbaMirage 弹幕用本体贴图 + 正弦 UV 偏移三重采样半透明。

## 7. 性能与多人预算

- 状态承载: `ai[0]`=状态, `ai[1]`=状态计时, `ai[2]`=全局计时, `ai[3]`=段计数/子状态; `otherAI[0..3]` (SendExtraAI) = 循环游标/一次性演出位掩码/上一招 (抗重复)/预留; `HasTalisman` 加入 SendExtraAI 同步。状态切换与弹幕生成仅服务器 (`!VaultUtils.isClient`), 切换时 `netUpdate=true`; 眼亮度/热浪/蜃景闪烁等由同步计时器在各端确定性推导, 不联网。
