# 敖闰（西海龙王）重做设计文档 —— Boss 重做工程 V3

> 单元：`Celestias/Boss/Aoyuans/`　主题：冰霜/寒潮 · "静与刹那"的剑意
> 参考标杆：玄武（同为冰水系，但玄武=厚重巨兽守势；敖闰=凌厉剑客攻势，必须差异化）

---

## 1. 现状诊断

以 choreography skill 七大本能与失败模式清单为透镜：

1. **速度没有对比（本能 #2 违反）**：全程使用原版蠕虫栅格追踪（`WormMovement`）以 12~15 px/f 匀速游动，从不停顿、从不爆发。一条"剑客龙"却没有一次冲刺；巡逻 150~300 帧的死巡航占了战斗大半时间（自检问题："Boss 是否在等自己的计时器"——是）。
2. **前摇不编码信息（本能 #1/#4 违反）**：`PreAttack` 对所有攻击复用同一个 45 帧减速+旋涡粒子，玩家无法从身体语言读出下一招是什么；除张嘴动画外没有任何蓄势姿态，蠕虫身体从不"盘蜷蓄力"。
3. **冲击链缺失（本能 #3/#5 违反）**：没有一次发射后座、没有刹车顿挫、没有方向性震屏（仅绝对零度有震屏）；粒子密度不随动能变化；绝对零度蓄力汇聚粒子密度恒定，没有"尖叫前的静默"硬切。
4. **三大演出节拍残缺**：入场是 60 帧普通追踪+渐显粒子（零演出）；换阶段仅 90 帧粒子喷发（有 i-frame 与"打滑"规则改变，底子尚可）；**死亡完全没有演出**——`OnKill` 一次冰尘爆了事。
5. **视觉无冰晶身份**：所有弹幕（冰弹/冰柱/冰束/雪墙）都是 SoftGlow 圆形光晕叠层，没有任何着色器、没有晶体/折射/棱面语言；永冻地痕每 7~10 帧铺一个，把屏幕铺成噪声（"常开的修饰读作噪声"）。
6. **选招是纯随机**：`Main.rand.Next` + 一次防重 + 25% 概率绝对零度，没有洗牌袋、没有强弱交替的作者化编排；攻击彼此在屏幕状态（位置/剪影/节奏）上几乎无差别。
7. 状态机本身健全（每态有出口）、多人同步框架（internalAI + SendExtraAI）和"弱点打断绝对零度"机制是好底子，予以保留强化。

**结论：全面重做 AI 编排与视觉**，保留：蠕虫身体链、AoyuanFrostPlayer 冰冻叠层/打滑系统、绝对零度弱点机制、掉落/召唤/downed 标记、全部 public 类型名。

## 2. 设计主题与幻想感

**"西海静渊 · 刹那冰锋"** —— 四海龙王中最冷静克制的一位。它不是咆哮的暴风，而是一柄收在鞘中的冰剑：

- **静**：长时间的盘蜷静滞蓄势——龙身盘成一圈"剑鞘"，寒气凝结，粒子向内收束，时间仿佛冻结（屏幕晶化去饱和）。菜单级的安静就是它的威压。
- **刹那**：拔剑只有 9~12 帧。整条龙就是剑身，沿预警线以 90+ px/f 贯穿屏幕，身后留下一线冰封航迹，慢半拍凝晶成伤害墙——"剑过之处，海水成冰"。
- **镜**：西海之水澄澈如镜。冰镜阵折射冰束、镜界瞬狱借镜转移——传送全部用"入镜/出镜"卖出因果（失败模式清单：瞬移必须有前后电报）。
- 与玄武的差异：玄武是拿盾的山，敖闰是拿剑的水。玄武的冰是覆盖与守御（冰域/护罩），敖闰的冰是切割与定格（航迹线/冻结陷阱/时滞）。

配色沿用 `AoyuanHelper` 色板（深海蓝/寒冰青/冰晶白/西海碧/深渊黑蓝）+ `TelegraphColors`（Frost/DeepFrost/IceWhite；致命伤害预警唯一用 Lethal 红）。

## 3. 阶段结构与血量断点

| 阶段 | 血量 | 内容 |
|---|---|---|
| 入场演出 | — | ~292f 电影化入场（§5），不可受击、零接触伤害 |
| P1 剑意一段 | 100%→50% | 招式池 {刹那突刺, 冰镜折光阵, 寒潮席卷, 冰封困龙局, 霜刃回旋} |
| 破境演出 | 50% | ~170f "时滞破境"（§5），清弹 + i-frame，场地结冰打滑（保留规则改变） |

| 死亡演出 | 0 | ~300f 晶化升天→碎裂（§5），期间锁血 1（CheckDead 接管） |

节奏波形：每招内部 2~4 个循环（压迫）→ 收剑连接拍 25f（段落句号，专属冰铃）→ 巡逻 46~80f（P2 30~60f）→ 下一招。最强的两招（绝对零度/镜界瞬狱）只在 P2 出现——"把内容扣作人质"。

选招：**洗牌袋 + 防重**（PACING §2）。每袋 = 当前阶段全招式池 Fisher-Yates 洗牌；袋首 == 上一招则与中位交换；绝对零度不排袋首（换阶段后先给喘息）。服务器权威，破境时清袋立即以 P2 池重开。

## 4. 招式编排表

通用公平阀门：攻击伤害窗口与视觉严格对齐——**头/身接触伤害仅在突刺帧（Attacking 且速度 > 30 px/f）为 135%，静滞/巡逻降至 45%，演出状态归零**；每次突刺预警剑鸣固定提前 36f（MaxMana 音色常数，玩家可内化）；锚点距离玩家 > 1250px 时先瞬时收拢再蓄力（防脱屏开打）；所有攻击有 900f 超时保底出口。

### 4.1 刹那·冰封突刺 InstantThrust（签名招）
- 循环 ×2（P2/低血 ×3），单循环 92f。每循环：
  - **盘蜷蓄势 44f**：头部绕锚点（玩家侧上方 560px，逐循环换边）螺旋收紧（半径 200→95 QuadOut，角速度 0.055→0.125），龙身肉眼可见地盘成剑鞘；预警线从锚点穿过玩家预测点（前置量 14f），跟踪率 0.15→0.02 衰减（"看得见地锁线"）；汇聚流光 ∝ 进度。
  - **锁线静默 14f**：完全死停（×0.70/f），预警线定格转白（IceWhite），粒子供给硬切——出剑前的静默。
  - **出剑 1f**：velocity = dir × 95 一帧点火（set 不是 ramp），SlashBurst 爆闪 + 震屏 5 + 双层出剑音。
  - **贯穿 12f**：沿途每 30px 落 1 段冰封航迹；速度门控残影（头/身全链）。
  - **硬刹收剑 22f**：×0.78/f 撞停。
- **冰封航迹**（AoyuanPermafrostTrail 重铸）：落下 25f 内是无害寒雾（逃逸窗+预告），凝晶脆响后成伤害冰棱线（细判定 30px），存续 150f 后碎裂。
- 阀门：锁定后线不再跟踪；预警线用 Lethal 红芯 + Frost 缘（契约: 冲刺线属致命预警）。

### 4.2 冰镜·折光阵 MirrorArray
- Boss 退至远侧 730px 缓游（presence 不 pressure）；玩家周围 520px 弧线生成 4（P2 5）面冰镜。
- 每面镜：22f 结晶成形 → 45f 蓄光（镜面亮度 = 蓄力进度，"VFX 即状态广播"）→ 依序（index×14f 波纹式）射出**折光冰束**（AoyuanFrostBeam 重铸：26f Lethal 预警线锁定 → 30f 成束 → 8f 消散）→ 镜面 Shatter 碎裂成冰晶雨。
- 阀门：束按序不齐射；预警线固定 26f；镜间角距 0.58 rad 保证有缝。

### 4.3 寒潮·冻土席卷 ColdWave
- 俯冲至玩家下方低空锚点（30 px/f 可读中速；**提前到位则跳时间**，不等自己的计时器），触底 6f 顿挫定格 → **寒潮沿地面蔓延**（AoyuanFrostGround 着色器：枝晶生长 + 亮色生长前沿，0→900px / 70f）；霜面存续 240f，站上叠加冰冻层（复用 AddChill，纯 CC）。
- 触地即派生左右两道**冰脊波**（高 90px 可跳，12 px/f）；随后 2~3 波**冰晶尖刺**（30f Lethal 落点预警 → 12f 喷发判定）。
- 阀门：霜面只 CC 不伤血（冰蓝）；尖刺红色预警只因它真造成伤害。

### 4.4 冰封·困龙局 FreezeTrap
- 玩家脚下 + 两翼 ±420px 放置 3（P2 4，第 4 个在头顶）个冻结区（r=170）：**外环标界 + 内缩倒计时环 90f**（AoyuanFrostGround mode1，Frost→IceWhite 渐亮；纯控制零伤害 → 全程冰蓝，不占用红色）。
- 到时 flash-freeze：区内玩家 frozen 50f；区内立起冰晶簇（纯视觉）；P2 各区错拍 20f 依次引爆（节拍舞步）。
- 期间 Boss 绕 640px 外圈快游放牧 + 每 40f 一发微追踪冰晶飞棱（80f 后失去跟踪，可甩）。

### 4.5 霜刃·回旋连斩 FrostBlades（压力节奏招）
- 3（P2 4）次短突刺，单循环 54f：盘蜷 22f + 锁线 8f，速度 58、行程 ~700px，锚点按预置角度表交替成 V/X 交叉线；每循环起点高音短鸣（低威胁档常数音色）。
- 短航迹（凝晶 18f / 存续 60f）；终斩后 4f 完全定格 — 段落句号。

### 4.6 绝对零度 AbsoluteZero（P2 大招，保留弱点机制）
- 30f 盘成紧螺旋（锚定玩家上方偏侧）→ **吸气蓄力 190f**：汇聚流光密度 ∝ √charge、**72% 处硬切进入静默**；身体段弱点晶簇外露（承伤 ×0.6，累计 ≥ 2.5% 最大生命值即打断）；Lethal 预警环半径 ∝ charge³（140→640px）；屏幕晶化爬升 + 震屏 charge³×4 + 五记渐急渐高冰铃。
- **打断**：直接跳到释放帧放削弱版——踉跄 60f（承伤 ×1.3 输出窗奖励）+ 寒潮环（冰蓝，仅叠冰冻零伤害）。
- **未打断**：12f 预塌缩（粒子熄灭、预警环收缩至 40%——收束即将爆发）→ 冻爆：Lethal 快环（伤害+冻结 60f）+ 10f 后慢速寒潮余波环（叠层），freezeBloom + 晶化尖峰 + 震屏 12。
- 释放后 40f 脱力慢滑——明确输出窗。

### 4.7 镜界·瞬狱连突 MirrorRealm（P2）
- 6 面冰镜六角形围绕玩家（r=600）成形 → Boss 冲入最近镜面（Shatter 碎入口镜 + 龙身隐没不可受击）→ ×3 跳跃，每跳 66f：隐没 40f（**出口镜 = 距入口最远的存活镜**，白亮渐起 + 出射 Lethal 预警线 + T-36f 剑鸣）→ 从出口镜爆出 82 px/f 贯穿（带航迹）→ 硬刹 12f → 入下一镜。
- 终幕：剩余存活镜齐充能 45f（可见）→ 齐射折光束（各自带 26f 预警）→ 全部碎裂收场，Boss 上浮旁观。
- 传送全部用"入镜碎镜、出镜白亮"卖出因果；隐没期间玩家专心读出口。

## 5. 入场 / 换阶段 / 死亡三大演出脚本

### 入场：破镜现身（~292f，无敌 + 零伤害）
1. t0-40：天幕迅速入夜结霜（Sky 强度爬升 + 晶化着色器边缘结霜 0→0.4），远方低吼。
2. t40-130：**天际剪影**——AoyuanSky 绘制龙形剪影两次掠过（远景右→左小、近景左→右大，正弦游动的头+12 段身链），冰铃渐高。
3. t130-170：玩家侧上方凝出一面冰镜（复用 AoyuanIceMirror intro 模式，40f 结晶生长）；Boss 在镜后隐身盘蜷成环。
4. t170：**破镜现身**——Shatter + 冰片喷泉 + 震屏 4，龙已盘成完整"剑鞘"姿态直面玩家，**48f 完全静止凝视**（威压=静止，只有下沉的呼吸寒气）。
5. t218-258：试剑瞄准（满额预警线 40f + T-36 剑鸣）→ t258 试剑突刺（80 px/f，无航迹）→ 硬刹 → t292 入巡逻。

### 换阶段：时滞破境（50%，~170f，清弹 + i-frame）
1. t0-20：清空全部敖闰弹幕；低吼；移至玩家上空 400px。
2. t20-90：**时间冻结**——盘蜷紧环；晶化着色器 uStill 升至 0.85（画面去饱和、全屏棱面化）；空中凝滞悬浮的冰尘（velocity=0）；天幕额外压暗（Sky 读 StillFxFactor）；万籁只余稀疏冰铃。
3. t90：一声高音剑鸣 + 白亮泛光脉冲（freezeBloom 0.55）。
4. t92：**碎境**——Shatter + 双重冰爆 + 镜片喷泉 + 震屏 10；场地结冰打滑 30s（保留规则改变）；放出一道诚实的寒潮环（冰蓝，仅叠冰冻）。
5. t92-170：恢复滑行，龙身解锁 P2 棱光冰甲（错相位冷辉），清袋以 P2 招式池重开。

### 死亡：晶化升天（~300f，CheckDead 接管锁血 1 + 清弹）
1. t0-40：踉跄——速度衰减 + 随机顿挫抽搐 + 低吼。
2. t40-210：**螺旋升天**——绕缓慢上升的锚点盘旋；身体段**从尾到头逐段晶化**（变白 + 棱面星辉），每段一声冰铃且**间隔从 14f 递减到 4f、音高上行**（加速的死亡节拍）+ 轻震铺垫。
3. t210-250：**顶点全静止 40f**——velocity→0，粒子硬切，uStill→1，唯余寂静。
4. t250：**碎裂**——冲击帧 12f（晶化着色器 uFlash 黑白高对比，全场唯一一次）+ Shatter + 死亡吼 + 震屏 16（全场最大唯一一次）+ freezeBloom。
5. t250-285：身体段尾→头每 2f 连锁冰爆消散（StrikeInstantKill，HitEffect 冰爆）→ t285 头部 StrikeInstantKill → OnKill（downedAoyuan + 掉落，原逻辑不动）。

## 6. 视觉技术方案

### 新建着色器（全部 Aoyuan 前缀、ps_3_0、AoyuanShaders 静态缓存，不注册进 ACMShaders）
1. **AoyuanCrystalline.fx**（全屏后处理，s0=screenTarget，s1=共享噪声）：
   - Voronoi 冰晶棱面折射（F1/F2 棱线 + 每晶胞随机方向 UV 偏移 + 沿棱向色散）——与玄武 FrostDistortion 的"径向裂纹+雾"明确区分（敖闰=镜面棱角语言）。
   - uStill：时滞去饱和（向冰蓝白灰收敛 + 轻暗角）——破境/死亡的"时间冻结"。
   - uFlash：黑白高对比冲击帧（死亡碎裂唯一一次）。
   - uFrost：屏幕边缘细晶结霜（入场/二阶段低值常驻）。
   - 使用点：`Aoyuan.PostDraw`，走 `ACMShaders.RequestFullscreenSlot()` 名额契约，全部标量 <0.01 早退。
2. **AoyuanFrostGround.fx**（屏幕空间地纹 decal，s0=共享噪声）：
   - uMode 0 = 寒潮冻土：压扁椭圆（y×3.4）的枝晶晶脉 + 生长前沿亮环 + 内部时间闪晶。
   - uMode 1 = 冻结陷阱：uniform 数组 ≤4 合批——外环标界 + 内缩倒计时环 + 六瓣晶花绽放 + 末 22% 整盘渐白。
   - 使用点：ColdField 的 PreDraw（活动批版 `DrawScreenSpaceDecal`）；陷阱采用**帧守卫合批**（每帧第一个陷阱统一画全部）。
3. **AoyuanMirror.fx**（冰镜面板 decal，s0=共享噪声）：
   - uniform float4 数组 ≤6（xy=屏幕UV、z=朝向、w=生长/蓄光，>1 编码出口白亮）；菱形 SDF 透镜 + 内部视差微光 + glint 扫掠 + 蓄光瞄准线；帧守卫合批一次 pass 画全部镜面。

## 7. 性能与多人预算

- **全屏后处理**：仅 AoyuanCrystalline 一个，严格走名额契约 + `MythologyConfig.FullscreenShadersEnabled`。
- **开合批预算**：每帧至多 crystalline 1 + 冻土 decal 1 + 陷阱合批 1 + 镜面合批 1 + DrawBeam 若干（同帧预警线 ≤3）；陷阱/镜面均为帧守卫合批（uniform 数组一次 pass）。
