# 阴天子（酆都大帝）重做设计文档 — Boss 重做工程 V3

> 单元：`Underworlds/Boss/YinEmperors/`（阴间压轴 Boss，T52 · G7 准圣门控）
> 主题：**帝王的审判** —— 威仪而非狂暴。稳、缓、决。

---

## 1. 现状诊断

以 choreography skill 七大本能与失败模式清单为透镜：

1. **动作失重、无速度对比（本能 #1/#2/#3 全违反）**。本体全程 `velocity = Lerp(velocity, (target - Center) * k, m)` 软插值悬浮；唯一位移招"龙气横扫"是 35 px/f 的中速冲刺，无反向蓄势（counter-motion）、无一帧 set 式发射、无硬刹车（×0.92 太软）、无任何后坐力。帝王气场完全没有落到运动曲线上——它只是一张飘来飘去的贴图。
2. **招式外包给冥眼，本体存在感稀薄**。除横扫外所有输出都由 `ArenaEdge`（冥眼）阵列完成，本体动作只剩"悬浮 + 定时喷弹"（`RunImperialWrath` 每 60 帧 3 连弹 + 每 110 帧环形弹，匀速无波形），违反"fight is a wave"。
3. **"审判"主题缺少标志性动作**。冥律标记只在被弹幕命中时被动叠层（惩罚已经被打中的玩家），不存在"点名 → 宣判倒计时 → 执行 → 给足反制窗口"的主动审判循环；`NetherDecreeMark` 只是个图标 buff。
4. **入场/死亡演出远低于标杆（Xuanwu/Dazheng）**。入场 = 升起 + 停顿 + 吼 + 一批 Dust；死亡 = `OnKill` 单帧 250 粒尘 + 8 根粒子雷柱同时爆完，没有任何多秒死亡弧线（减速 → 挣扎 → 崩解 → 静默 → 终爆）。无一个专属着色器，法环/光柱全部用 `BAWHelper.DustTexture` 点阵拼接。
5. **"场地边界"名不符实**。`ArenaEdge` 实为冥眼弹幕（7 种模式复用同一个类），真正的"酆都法庭结界"演出不存在——镇魂狱只有屏幕空间 ArenaRunic 遮罩，无实体结界层、无仪式感。
6. **节奏固定轮替、无连接节拍**。三幕各自固定循环，每招 230~300 帧定长，无 connector beat、无 early-exit；招式间的屏幕状态几乎一致（都是悬浮位）。
7. **保留良好的骨架**（不回退）：三幕 HP 门结构、镇魂狱鬼门关钥弱点机制、阴阳半场判罚（PaletteLUT 分屏）、终诏 4s 预告、G7 处决幻象、幕过场清弹 + i-frame、掉落/召唤/downed 标记。

**重做力度判定**：全面重做 AI 编排、动作曲线与三大演出，新建专属着色器；保留并强化上述骨架与全部 public 类型 / 进度物品。

## 2. 设计主题与幻想感

**"你不是在与怪物搏斗，而是在酆都法庭上受审。"**

- 帝王几乎不屑于亲自移动——他以**诏令**统治整个场地：点名审判、开鬼门放阴兵、颁诏分阴阳。
- 但当他亲自出手（帝袖横扫 / 玉玺压顶），就是**极长的蓄势换毁灭性的一击**（MOTION §1：anticipation ~45%，burst ~10% 配 poly(20) 级锐利缓出，recovery ~40%）。
- 场地即法庭：开战即落下"酆都法庭"结界，六杆冥幡围场而立；幡旗是战斗状态的可视化（死亡时逐杆熄灭）。
- 世界层：天地变色（Sky 幡旗剪影 + 低血量泛红）、审判节拍全部有钟/磬声阶、全场唯一一次顿帧留给死亡终爆。

## 4. 招式编排表

所有帧数按 60fps。**接触伤害只在帝袖横扫的爆发窗口与玉玺下砸窗口开启**（`npc.damage` 其余时间为 0 → 视觉与伤害严格对齐）。

### 4.1 帝袖横扫（幕一/幕二穿插；本体唯一水平位移招）
| 段 | 帧数 | 内容 |
|---|---|---|
| 前摇 | 50 | 悬停减速 ×0.9/f；后 20 帧按 `pow(t,8)` 反向吸气 260px（late-snap reel-back）；锁定预测点（`target.Center + target.velocity * 14`）；36 帧处预警钟音（固定 buffer） |
| 爆发 | 9 | 一帧 set `dir * 130` px/f 直线，无转向；沿途帝袖罡风 2 道（横向弧形弹，可跳/可下潜）；接触伤害仅此窗口 |
| 刹车 | 14 | ×0.68/f 硬刹（slam into position 读感），落点震屏 5 |
| 收招 | 24 | 转身面向玩家，法环回稳 |
- 循环 2~3 次（血量 <80% 时 3 次），第二次起蓄势缩短至 38 帧（内部递进）。
- 公平阀门：发射前 0.6s 固定钟音；冲刺距离上限 1150px（距离栓绳）；爆发后伤害立即归零。

### 4.2 冥诏点名（新 · 签名审判机制）
| 段 | 帧数 | 内容 |
|---|---|---|
| 抬手 | 30 | 帝王后仰抬手，金光向袖口汇聚（converging streaks），一声镇尺 |
| 落印 | 1 | 对每名存活玩家**当时位置**落下"冥诏印记"（`YinEmperorDecreeSeal`，无伤害，位置锁死不追踪） |
| 宣判 | 96 | 印记金环从 320px 收缩到 140px 执行圈；30/60/85 帧三声递进磬音（音高上行）；末 24 帧环体收拢加速 + 颤动 |
| 执行 | 26 | 天降审判柱（`YinEmperorJudgmentColumn`，宽 = 执行圈直径，8 帧展开 + 12 帧持续 + 6 帧消退）；命中→高伤 + 叠 2 层冥律 |
| 余韵 | 18 | 柱底金尘余烬，Boss 收手 |
- **反制方式唯一且清晰：离开 140px 执行圈即完全安全。**
- 幕二双印（第 45 帧补落第二枚于玩家新位置）、幕三三印（45/90 帧补落）；印与印执行错拍，形成"逐步驱赶"的走位压力。
- 公平阀门：印记不追踪；执行柱预警形状=伤害形状；多人时每人一印不叠罚。

### 4.3 鬼门开阖（新 · 召阴兵）
| 段 | 帧数 | 内容 |
|---|---|---|
| 挥袖 | 30 | 帝王侧身挥袖指向两翼，袖口幽光 |
| 开门 | 40 | 玩家两侧 ~760px 各裂开一扇竖直鬼门（`YinEmperorGhostGate`，专属着色器：门洞深渊 + 边缘金符），由细缝到全开（ElasticOut 过冲） |
| 涌兵 | 150 | 每扇门 3 波 × 5 发阴兵魂弹（`YinEmperorBolt` 阴兵模式：横向直线、轻微正弦漂移、速度 8→13 渐升 wind-up），波间隔 25 帧留穿行缝 |
| 阖门 | 30 | 门收拢熄灭，末帧一声闷响 |
- 幕二强化版：第三扇门开在头顶，魂弹改为壁帘式下压（留 2 个可读缺口）。
- 公平阀门：首波弹速 8（transition wind-up）；门位置固定后不再移动；波间隔即安全窗。

### 4.4 冥谕列阵（保留 `ArenaEdge` 冥眼阵，预警强化）
- 幕二使用：列阵激光（模式 0，左右两批）与环形激光阵（模式 3）。
- 保留 80 帧蓄力 + ArenaRunic 落点预告；伤害数值不变。

### 4.5 镇魂狱（保留强制阶段，视觉重做）
- 结构保留：60 帧蓄力 → 封印激活（冥眼收缩环模式 6 + `GhostGateLock` 弱点）→ 360 帧收缩窗口。
- 破锁成功 → **帝王失仪节拍**：Boss 被震退 + 半跪 130 帧（受击特效增强，输出窗口奖励）。
- 超时 → 处决性合击（保留）。
- 视觉：ArenaRunic 牢笼罩之上叠加法庭结界的 `uCollapse` 收缩形变 + 幡旗转为冥蓝。

### 4.6 玉玺压顶（新 · 幕三大招，本体唯一垂直强击）
| 段 | 帧数 | 内容 |
|---|---|---|
| 升天 | 22 | 一帧 set 向上 26 px/f 冲出视野上沿（拖尾拉满） |
| 悬印 | 55 | 于玩家上方 360px 显形，地面浮现印玺投影预警（ArenaRunic 落点，宽 300px）；后 24 帧按 `pow(t,8)` 再上抬 130px（吸气） |
| 下砸 | ~10 | 一帧 set 向下 78 px/f，命中地面/预定高度即停；接触伤害仅此窗口 |
| 触地 | 1 | 震屏 10、左右各一道地面冲击波（可跳）、金尘喷泉 |
| 半跪 | 45 | **帝王半跪于地，唯一近身输出窗口**（fairness reward），随后起身回位 |
- 公平阀门：投影预警 55 帧；冲击波离地高度 ≤90px 可跳过；下砸横向无追踪。

### 4.7 阴阳诏书（保留 + 增强）
- 保留 165 帧 × 3 轮安全半场切换 + PaletteLUT 阴阳分屏 + 站错灼魂 DoT。
- 增强：危险半场天降金符雨（阴兵模式竖落，视觉密度为主、低伤），换场预警改"翻页"钟音 + 分界线闪烁（已有 warning 逻辑保留）。

### 4.8 终诏（保留，一次性 4s 预告十字激光）
- 结构保留（240 帧预告 → 8 向激光 + 弹环）；预告线由 Sky 像素线升级为 BeamGrad 渐亮光带；发射瞬间 shake 12 + 泛光（已有）。

### 4.9 connector（新 · 招式间连接节拍）
- 每招结束 → 24 帧"换手势"：法环转速短暂提升、一声木磬、袖口粒子重置。屏幕得到段落感，下一招预警从干净底噪开始。

## 7. 性能与多人预算

- **弹幕上限**：审判柱同屏 ≤4、鬼门 ≤3、结界 1、冥眼沿用现有数量；魂弹波次生成总量 ≤ 30/招。
- **绘制**：新着色器静态缓存（`??= ModContent.Request`），不在 Update/Draw new 资源；幡旗为 Boss 本体 PreDraw 内 6 次 quad 绘制（一次 shader 切换批完成全部 6 杆）。
- **多人安全**：`arenaCenter`（法庭中心）经 `SendExtraAI` 同步；状态切换 `netUpdate = true`；弹幕/印记仅服务器生成（对每名存活玩家各落一印）；`Main.LocalPlayer`、Dust、shader 强度只在客户端路径。
- **配置降级**：所有 shader 绘制尊重 `MythologyConfig.FullscreenShadersEnabled`（幡旗/门/结界为世界绘制仍显示低成本像素回退——直接跳过 shader 层，保留 Dust 提示，保证玩法可读）。
