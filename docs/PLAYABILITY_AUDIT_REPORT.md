## 一、执行摘要

**Ancient Chinese Mythology**（展示名 **Primordial / 洪荒**）是一个以中国神话为题材的 tModLoader 大型模组。它并非按单一历史朝代线性叙事，而是构建了一套**垂直宇宙观**：

| 层级 | 主要来源 | 模组表达 |
|------|---------|---------|
| 先天/洪荒 | 盘古、混元、祖龙、庄子·大椿 | 祖龙、大椿、傲世神木、开天阵法 |
| 上古灾厄 | 旱魃、僵尸始祖、刑天、山海经 | 四大僵尸（**月后**）、红木棺材线 |
| 青铜/名剑 | 商周青铜、吴越八剑 | 青铜/赤铜、承影/鱼肠/干将 |
| 天庭秩序 | 封神演义 | 截教余波、天将、天庭入侵 |
| 西游英雄 | 西游记 | 唐僧、金箍棒链、黑熊精、四海龙王 |
| 冥府秩序 | 酆都/地府 | 黑白无常、阴天子、地府入侵 |
| 修仙框架 | 网文修仙 | 16 阶 cultivation、渡劫云、丹药/阵法 |

**核心问题：** 内容量庞大（~130 武器、40+ Boss），但**进度管理严重滞后**——大量 Boss 无掉落、万魂幡 tier 止于敖顺、Boss 击败标记在 world load 时被重置、`description.txt` 仍写「2 Boss、18 武器」。

### 设计勘误（v3.3.1 · 与 `PROGRESSION_DESIGN_SPEC.md` §1.4 同步）

**四大僵尸**（旱魃、后卿、赢勾、将臣）在初版审计/设计中被误标为 **Pre-HM～HM（Plantera 邻接）** Boss。权威设计已更正为 **月灵之后早期 Boss**：

| 维度 | 旧审计表述 | 更正后 |
|------|-----------|--------|
| 进度位 | Tier 1 含赢勾/四灾；HM 棺材线 | **ML 后**；天柱降临后可选挑战 |
| 召唤 | 鬼面具/棺材无 ML 区分 | `RedwoodCoffinGenSystem` **已实现** ML 门控；鬼面具 **待补** ML 检查 |
| 万魂幡（代码） | T7 赢勾、T15/T17/T21 三灾 | **目标** T24–27（`SoulBannerPlayer.cs` 仍旧序，Phase 2） |
| 推荐顺序 | — | 旱魃 → 后卿 → 赢勾 → 将臣 |
| 妖气 | 四灾作前期脊柱 | 地表 1/10 **保留**；Boss 妖气为月后补充 |

## 五、进度设计评估

### 5.1 现有进度系统

| 系统 | 作用 | 问题 |
|------|------|------|
| **修仙 16 阶** | 杀怪 EXP → 境界 → 属性 scaling | 与 Boss 进度无联动 |
| **万魂幡 tier** | 击败 Boss 解锁灵魂上限 | 止于敖顺，后续 10+ Boss 未纳入 |
| **唐僧棍链** | NPC 引导早期武器 | 完整 ✓ |
| **月后天门** | ML → 天柱 → 天极矿 | 完整 ✓ |
| **Boss Downed 标记** | 门控/追踪 | **WorldLoad 重置 bug** |
| **Boss Checklist** | 图鉴 | 仅 2 Boss，Archosaur 回调错误 |
| **阵法系统** | 独立成长线 | 与主进度平行 |

### 5.2 隐含 Tier 阶梯

```
Tier 0  木棍/青铜/林地          ← 开局
Tier 1  黑熊精/牛头马面         ← Pre-HM ~ HM（妖气地表经济，无四僵尸）
```

## 八、结论

洪荒模组在**内容广度**上已接近中大型模组规模（130 武器、40+ Boss、双 endgame 线），神话主题**识别度高**，中文本地化** lore 丰富**。核心叙事以**封神余波 + 西游主线 + 冥府镜像**为骨架，修仙系统提供 meta 成长。

当前最大短板是**可玩性管理**：
- 大量 endgame 内容处于「有 Boss 无掉落 / 有武器无来源」状态
- 进度系统（万魂幡、downed flags）未覆盖全部内容
- 盔甲/工具/消耗品生态不完整
- 商店文案与代码严重脱节

**建议下一步：** 以本文 §6 优先级清单为 roadmap，先打通 Boss → 掉落 → 合成 → 下一 Boss 的最小可行循环，再扩展盔甲/工具/门控系统。
